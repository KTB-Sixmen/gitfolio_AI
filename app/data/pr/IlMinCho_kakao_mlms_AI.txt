Summary:
### 프로젝트 요약: Elastic Search DB 구축 및 모델 평가 성능 향상

#### 관련 이슈
- 응답 속도의 지연 문제 해결.

#### 작업 내용
1. **Elastic Search 기반 DB 구축**: API 연결을 통해 실시간 데이터 접근을 가능하게 함.
2. **쿼리 처리 로직**: 사용자 쿼리가 DB에 존재할 경우 즉시 평가 진행, 없을 경우 기존 크롤링 방법으로 처리.
3. **KcELENTRA 모델 배치 처리**: 여러 리뷰를 동시에 평가할 수 있도록 배치 처리를 적용.
4. **모델 운영**: 서버나 로컬에서 모델을 직접 운영할 수 있도록 Git에 업로드.
5. **토크나이저 경고 해결**: 작동 중 발생하던 경고를 수정.
6. **성능 개선**: 처리 시간이 220초에서 26초로 단축. 

이 프로젝트를 통해 데이터베이스의 성능을 극대화하고, 사용자 쿼리에 대한 응답 속도를 획기적으로 개선하였다.
