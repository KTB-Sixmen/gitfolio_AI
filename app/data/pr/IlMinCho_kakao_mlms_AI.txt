## 프로젝트 요약: Elastic Search DB 구축 및 모델 평가 성능 향상

### 주요 내용
1. **문제 해결**: 기존 답변 속도가 느린 문제를 해결하기 위한 작업 진행.
2. **Elastic Search DB 구축**: Elastic Search를 기반으로 데이터베이스를 구축하고, API를 연결하여 사용자 쿼리 처리.
3. **쿼리 처리 로직**: 사용자 쿼리가 DB에 존재할 경우 즉시 평가를 진행하고, 없을 경우 기존 로직을 통해 크롤링.
4. **모델 배치 처리**: KcELENTRA 모델이 여러 리뷰를 동시에 평가할 수 있도록 배치 처리 적용.
5. **모델 업로드**: 서버 및 로컬 환경에서 작동할 수 있도록 모델을 Git에 업로드.
6. **토크나이저 경고 해결**: 토크나이저 관련 경고 문제를 해결.
7. **성능 개선**: 처리 시간이 220초에서 26초로 대폭 단축됨.

### 기대 효과
- **응답속도 개선**: 쿼리 응답 시간 단축으로 사용자 경험 향상.
- **효율적인 데이터 처리**: 배치 처리를 통해 여러 리뷰에 대한 평가 효율성 증가.

이 프로젝트는 Elastic Search를 활용하여 성능을 개선하며, AI 모델의 효율적인 운영을 목표로 하고 있습니다.
