Summary:
### 프로젝트 요약: Elastic Search DB 구축 및 모델 평가 성능 향상

#### 관련 이슈
- 기존 시스템의 답변 속도가 느린 문제.

#### 작업 내용
1. **Elastic Search 데이터베이스 구축 및 API 연결**: 효율적인 데이터 검색을 위한 기반 마련.
2. **사용자 쿼리 처리**: 
   - 쿼리 데이터베이스에 존재할 경우 신속하게 평가 진행.
   - 데이터베이스에 데이터가 없으면 기존 크롤링 로직대로 진행.
3. **KcELENTRA 모델 배치 처리**: 여러 리뷰를 동시에 평가하도록 설정.
4. **모델 호스팅**: 서버나 로컬 환경에서 모델을 가동할 수 있도록 Git에 업로드.
5. **워닝 수정**: 토크나이저에서 발생하던 경고 문제 해결.
6. **성능 개선**: 처리 시간이 220초에서 26초로 단축됨.

### 결과
- 전반적으로 시스템 성능이 크게 향상되어 사용자 경험이 개선됨.
