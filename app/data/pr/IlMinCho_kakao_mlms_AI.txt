## 프로젝트 요약: 엘라스틱서치 DB 구축 및 모델 평가 성능 향상

### 문제점
- 답변 속도가 느려서 사용자 경험 저하.

### 작업 내용
1. **엘라스틱서치 기반 DB 구축**: DB를 엘라스틱서치를 사용하여 구축하고 API 연결.
2. **쿼리 처리 개선**: 사용자 쿼리가 DB에 존재할 경우 즉시 평가 진행. 없을 경우, 기존 방식으로 크롤링 수행.
3. **KcELENTRA 모델 배치 평가**: 여러 리뷰를 함께 평가하도록 배치 프로세스 적용.
4. **모델 호스팅**: 모델을 서버 또는 로컬에서 실행할 수 있도록 Git에 업로드.
5. **워닝 해결**: 토크나이저에서 발생하던 경고 문제 해결.
6. **성능 개선**: 처리 시간이 220초에서 26초로 단축.

### 결과
- DB 구축과 쿼리 처리 최적화를 통해 성능이 대폭 향상되어 사용자 대기 시간을 줄임. 

이 프로젝트는 효율적인 데이터 처리와 사용자 만족도를 높이기 위한 기술적인 개선을 목표로 하였습니다.
