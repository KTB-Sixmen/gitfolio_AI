### 프로젝트 요약

이 프로젝트는 카카오맵 데이터를 이용한 리뷰 크롤링, 클러스터링 및 모델 평가를 중심으로 많은 개선을 이루었습니다. 주요 내용은 다음과 같습니다:

1. **주소 리턴값 수정**:
   - 주소가 짤리지 않도록 처리하고, 추천 레스토랑 개수가 10개 이하일 때 중복 리턴 문제를 해결했습니다.

2. **HDBSCAN 기반 클러스터링 적용**:
   - 리뷰 클러스터링을 HDBSCAN을 통해 구축하고, API 리팩토링을 통해 성능을 향상시켰습니다. 크롤링량 조절로 응답 시간을 1~3분으로 단축했습니다.

3. **키워드 기반 식당 추천**:
   - 키워드에 기반한 리뷰 평가 시스템을 구축하였지만, 키워드에 대한 퀄리티와 추천의 정확도 간의 딜레마가 존재합니다.

4. **모델 앙상블 기법**:
   - BiLSTM 모델의 API 평가 코드와 KcELECTRA 모델을 앙상블하여 식당 평가 API를 구축했습니다.

5. **KcELECTRA 모델 변경**:
   - KcELECTRA-base 모델로 변경하고, 데이터 레이블링을 수정하여 성능을 개선했습니다. (F1 스코어 71로 개선 시도)

6. **AI 모델 API 엔드포인트 구축**:
   - AI 서버와 연동되는 API 엔드포인트를 구성하고, 데이터 전처리 파이프라인을 구축했습니다.

7. **KoBERT 모델 구축**:
   - KoBERT 모델을 프리트레이닝 후 성능을 개선하기 위해 데이터 레이블링을 수정했습니다.

8. **크롤링 시스템 개선**:
   - 병렬 크롤링을 통해 속도를 개선하고 중복 크롤링 문제를 해결했습니다. 리뷰 CSV 저장 API를 추가하여 데이터 저장 방식도 개선했습니다.

9. **사용자 정보 평가 크롤링 기능**:
   - 각 리뷰어의 평점을 크롤링하는 기능을 추가하여 데이터의 깊이를 더했습니다.

### 결론
본 프로젝트는 카카오맵의 리뷰 데이터를 효과적으로 크롤링하고 분석하는 데 중점을 두어, 머신러닝 모델의 성능을 향상시키는 다양한 방법을 모색했습니다. 각 단계에서 발생할 수 있는 문제를 해결하며, 최종적으로는 사용자에게 더 정확하고 신뢰성 있는 식당 추천 서비스를 제공하는 것을 목표로 하고 있습니다.
