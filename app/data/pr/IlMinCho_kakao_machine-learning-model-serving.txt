### 프로젝트 요약

이 프로젝트는 다양한 기능을 바탕으로 한 AI 기반 식당 추천 및 리뷰 분석 시스템 개발을 목표로 하고 있습니다. 여러 가지 이슈를 해결하고 성능을 개선하기 위해 다양한 접근 방식과 기술을 적용하였습니다. 주요 내용은 다음과 같습니다.

1. **주소 및 추천 레스토랑 이슈 해결**
   - 주소 반환 오류 수정 및 중복 추천 로직 개선.

2. **HDBSCAN 클러스터링**
   - 리뷰 클러스터링 기능 구현 및 API 리팩토링, 크롤링 수량 조절로 모델 속도 향상.

3. **키워드 기반 추천 시스템**
   - 리뷰에 키워드를 기반으로 가중치를 부여하는 방식으로 식당 추천 방식을 개선했지만, 여전히 퀄리티와 키워드 사이의 딜레마가 존재.

4. **모델 앙상블 및 평가 API 구축**
   - BiLSTM 및 KcELECTRA 모델을 앙상블하여 식당 평가 API를 구축.

5. **KcELECTRA 모델 변경 및 성능 개선**
   - KcELECTRA-base로 모델 변경, 데이터 레이블링 및 성능 테스트 후 결과 개선.

6. **AI 모델 API 엔드포인트 구축**
   - 백단 API 연동 및 데이터 전처리 파이프라인 구축.

7. **KoBERT 모델 구축**
   - KoBERT 프리트레이닝 및 성능 개선을 위한 데이터 수정 작업.

8. **데이터 수집 및 전처리**
   - 중복 크롤링 이슈 해결 및 데이터 레이블링, 전처리 후 데이터셋 분할 완료.

9. **리뷰 및 사용자 정보 크롤링 추가**
   - 리뷰 내용과 함께 사용자 정보를 크롤링하는 기능 추가.

10. **병렬 크롤링 및 성능 개선**
    - 병렬 크롤링 추가로 성능 향상, 응답 속도 개선.

11. **카카오맵 API 연동**
    - 카카오맵에서 특정 키워드를 기반으로 리뷰를 크롤링하는 기능 구현.

### 결론
이 프로젝트는 다양한 데이터 처리 및 AI 모델링 기술을 활용하여 식당 추천 및 리뷰 분석 시스템의 성능을 지속적으로 개선하고 있습니다. 특히, 클러스터링, 모델 앙상블 및 API 구축 등의 접근 방식이 성공적으로 실행되어 사용자에게 더욱 정확한 추천 서비스를 제공하고 있습니다.
