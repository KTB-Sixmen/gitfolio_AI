### 프로젝트 요약

1. **주소 리턴 및 추천 레스토랑 이슈 해결**
   - 주소가 잘리는 문제 해결 및 추천 레스토랑 수가 10개 이하일 때 중복 리턴 문제 수정.

2. **HDBSCAN 클러스터링 및 모델 속도 향상**
   - 리뷰 클러스터링 구축 및 API 리팩토링 완료. 크롤링 속도를 개선하기 위해 크롤링 페이지 수를 줄임 (5페이지에서 3페이지로 감소).

3. **키워드 기반 식당 추천**
   - 키워드에 맞는 식당 추천 시스템 개발. 리뷰에 키워드 가중치를 부여하였으나 여전히 추천 품질에 한계 존재.

4. **모델 앙상블 기법 API 구축**
   - BiLSTM 모델 API 및 KcELECTRA 모델과 앙상블하여 식당 평가는 API 구축 완료.

5. **KcELECTRA 모델로 변경**
   - KcELECTRA-base 모델로 변경하고, 데이터 레이블링 수정하여 성능 개선.

6. **AI 모델 API 엔드포인트 구축**
   - AI 서버와 연동되는 API 엔드포인트 구성 및 데이터 전처리 파이프라인 구축 완료.

7. **KoBERT 모델 구축**
   - KoBERT 모델 성능 개선을 위한 데이터 추가 크롤링 및 레이블링 수정.

8. **데이터 수집 및 전처리**
   - 85,000개 리뷰 수집 완료 후 레이블링 및 전처리 수행, 데이터 시각화.

9. **사용자 정보 크롤링 추가**
   - 리뷰어의 평점을 크롤링하는 기능 추가 및 크롬 버전 이슈 해결.

10. **병렬 크롤링 및 중복 크롤링 이슈 해결**
    - ThreadPoolExecutor를 사용한 병렬 크롤링 추가 및 중복 크롤링 문제 해결.

11. **모든 리뷰 크롤링 및 자동화 API**
    - 크롤링 속도 개선 및 사용자가 필요로 하는 모든 리뷰를 긁어올 수 있도록 자동화 API 구축.

12. **KakaoMap 데이터 크롤링**
    - 특정 키워드로 카카오맵에서 리뷰를 크롤링하는 API 생성.

### 최종 노트
이 프로젝트는 주로 데이터 크롤링, 전처리, AI 모델링 및 API 구축에 중점을 두었으며, 성능 향상과 사용자 요구 사항을 반영하는 방향으로 진행되었습니다. 각 요소는 기존의 문제를 해결하고 최적화를 위한 지속적인 개선을 통해 성공적으로 완수되었습니다.
