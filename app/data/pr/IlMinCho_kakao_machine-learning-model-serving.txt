### 프로젝트 요약

#### 주요 내용 및 해결한 이슈

1. **주소 및 추천 레스토랑 문제 해결** 
   - 주소가 잘리는 문제 해결.
   - 추천 레스토랑이 10개 이하일 때 중복 반환 문제 수정.

2. **모델 속도 향상**
   - HDBSCAN을 이용해 리뷰 클러스터링 적용.
   - API 리팩토링 및 크롤링 속도 개선으로 처리 시간 대폭 단축.

3. **키워드 기반 식당 추천 기능 구현**
   - 키워드를 기반으로 한 리뷰 평가 시스템 도입, 하지만 여전히 추천의 질에 대한 한계 존재.

4. **모델 앙상블 기법 적용**
   - BiLSTM 및 KcELECTRA 모델을 활용한 식당 평가 API 구축.

5. **KcELECTRA 모델로의 전환**
   - 성능을 개선하기 위한 데이터 레이블 조정 후 모델 버전 업데이트.

6. **AI 모델 API 엔드포인트 완성**
   - AI 서버와 데이터 전처리 파이프라인 구축 및 모델 성능 평가.

7. **데이터 수집 및 전처리**
   - 데이터 크롤링 및 레이블링, 전처리 과정을 통해 85,000개 리뷰 데이터 확보.

8. **사용자 정보 크롤링 및 구조 재조정**
   - 사용자 정보와 리뷰 평점 크롤링 추가 및 코드 리팩토링.

9. **메인 서버 파일 및 기능 연결**
   - 위치정보를 개선하고 카카오 API와의 연결로 기능 통합.

10. **크롤링 성능 개선**
    - 병렬 크롤링 기능 추가로 크롤링 속도 향상 및 중복 크롤링 문제 해결.

11. **카카오맵 리뷰 크롤링 API 생성**
    - 특정 키워드를 이용한 리뷰 크롤링 기능 완성.

#### 결과 및 성과
- 데이터 수집 및 처리 속도 개선으로 전체 리뷰를 더 빠르고 효율적으로 수집 가능.
- API 리팩토링과 모델 성능 강화로 사용자 맞춤형 서비스 제공.
- 다양한 문제 해결을 통해 시스템의 안정성과 신뢰성 향상. 

이 프로젝트는 데이터 크롤링, 클러스터링, 머신러닝 모델 적용 및 API 설계를 통한 식당 추천 시스템의 전반적인 품질과 성능을 개선하는 데 중점을 두고 진행되었습니다.
