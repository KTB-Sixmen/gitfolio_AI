### 프로젝트 요약

**프로젝트 목표**: 카카오맵을 활용한 리뷰 수집 및 추천 시스템 개선

**주요 작업 내용**:

1. **크롤링 및 데이터 처리**:
   - 크롤링 중 중복 데이터 문제 해결
   - 리뷰어별 평점 추가 크롤링
   - 데이터 전처리 및 레이블링 수정
   - 성능 개선을 위해 크롤링 속도 최적화 및 페이지 수 조정
   - 병렬 크롤링 도입으로 시간 단축 (5분에서 1분으로 개선)

2. **모델링 및 평가**:
   - HDBSCAN을 통한 리뷰 클러스터링 및 BiLSTM, KcELECTRA 기반 모델 구축
   - 모델 앙상블 기법을 적용하여 식당 평가 시스템을 강화
   - 키워드 기반 추천 시스템 구현, 고품질 리뷰에 가중치 부여

3. **API 및 엔드포인트 구축**:
   - AI 모델을 통한 레스토랑 평점 자동화 API 구축
   - API 변경 및 리팩토링을 통해 데이터 반환 방식을 개선, 클러스터링된 결과 추가

4. **이슈 해결**:
   - 주소 리턴 시 잘림 문제 해결
   - API 리턴값을 상위 및 하위 5개로 수정

**결과**: 
- 성능이 개선된 추천 시스템과 크롤링 자동화로 사용자 경험 및 데이터 정확성이 증가.
- API 효율성 향상 및 중복 제거로 보다 빠르고 신뢰할 수 있는 데이터 수집 가능.

**추가 요구사항**: 새로운 모델과 API에 대한 지속적인 오류 확인 및 데이터 정합성 체크 필요.
