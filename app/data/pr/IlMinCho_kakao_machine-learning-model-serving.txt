2. **클러스터링 및 API 개선**:
   - HDBSCAN을 활용하여 리뷰 클러스터링을 구축하였고, API 결과를 리팩토링하여 속도를 향상시켰습니다.
   - 크롤링 양을 줄여 응답 속도를 1분에서 3분으로 개선하였습니다.

3. **키워드 기반 식당 추천**:
   - 키워드 기반으로 식당 리뷰를 평가하고 가중치를 부여하여 추천 시스템을 강화하였습니다. 그러나 여전히 품질 문제에 대한 딜레마가 존재합니다.

4. **모델 앙상블 기법**:
   - BiLSTM 모델을 활용한 API 평가 코드를 구축하였으며, KcELECTRA와 BiLSTM 모델들을 앙상블하여 식당 평가를 수행하는 API를 완성하였습니다.

5. **모델 성능 개선**:
   - KcELECTRA를 도입하여 모델을 변경하고, F1 스코어 개선을 통한 성능 향상 작업을 진행하였습니다.

6. **AI 모델 API 엔드포인트 구축**:
   - AI 서버와 연동하는 API 엔드포인트를 구성하고, 전처리된 데이터를 기반으로 랭킹화하여 감성 분석을 수행하였습니다.

7. **KoBERT 모델 구축**:
   - 기존 모델의 폴더 구조를 재정리하고, KoBERT 프리트레이닝 파일을 통해 성능 개선을 위한 데이터 레이블링을 진행하였습니다.

8. **데이터 수집 및 전처리**:

9. **크롤링 성능 개선**:
   - 병렬 크롤링 기능을 추가하고, 중복 크롤링 이슈를 해결하여 크롤링 속도를 크게 향상시켰습니다.
