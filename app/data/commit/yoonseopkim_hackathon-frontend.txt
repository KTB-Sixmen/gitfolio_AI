Summary:
**프로젝트 요약**

이 프로젝트는 동화책을 생성하고 품평할 수 있는 웹 애플리케이션입니다. 핵심 기능 및 변경 사항은 다음과 같습니다.

1. **로딩 페이지 구현**: 사용자가 동화를 생성하는 동안 로딩 스피너를 표시하도록 수정되었습니다. 애니메이션 효과는 GSAP 라이브러리를 사용하여 구현되었습니다.

2. **API 호출 개선**:
   - HTTP 요청 시, 하드코딩된 URL 대신 `process.env.REACT_APP_API_URL`을 사용하여 환경 환경변수를 통한 API 호출을 표준화했습니다.
   - Axios를 사용해 데이터를 가져오고 필터링하여 특정 story ID에 해당하는 동화를 불러옵니다.

3. **UI/UX 개선**:
   - CSS 파일을 통해 폼, 버튼, 그리고 페이지 레이아웃을 조정하여 사용자 경험을 개선했습니다.
   - 각 섹션의 헤더와 입력 필드에 대한 디자인을 직관적으로 수정하여 깔끔한 인터페이스를 제공합니다.
   - 슬라이더 컴포넌트를 추가하여 시작 페이지에서 동적인 이미지 아카이브를 구현했습니다.

4. **모바일 반응형 디자인**: CSS 미디어 쿼리를 사용하여 다양한 화면 크기에 맞춰 적절하게 표시될 수 있도록 했습니다.

5. **리뷰 및 공유 기능**: 사용자가 동화를 읽고 평가할 수 있도록 별점 시스템을 구현했습니다. 사용자 인터페이스에서 리뷰 버튼을 제공하여 평가하기 쉽게 하였습니다.

6. **라우팅 및 네비게이션**: React Router를 사용하여 각 페이지 간의 네비게이션을 담당합니다.

7. **CI/CD 설정**: GitHub Actions를 통해 Netlify에 자동으로 배포되도록 워크플로우를 설정했습니다.

이 애플리케이션은 전체적으로 사용자 친화적인 인터페이스를 바탕으로 동화 생성과 공유가 용이한 플랫폼을 제공하며, 관련 테스트 코드와 상태 관리 기능이 포함되어 있습니다. 수집된 데이터는 각각의 동화책을 효율적으로 관리할 수 있게 해줍니다.
