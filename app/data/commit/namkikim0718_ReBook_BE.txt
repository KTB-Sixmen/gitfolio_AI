### 프로젝트 요약

#### 1. **프로젝트 개요**
- **주제:** 클라우드 기반 중고 전공 서적 거래 플랫폼
- **대상:** 대학 재학생 및 졸업생
- **목표:** 사용자 간의 신뢰성 높은 전공서적 중고 거래 환경 제공

#### 2. **기술 스택**
- **Frontend:** React, Vite
- **Backend:** Java, Spring Boot, Spring Security
- **데이터 저장소:** Redis
- **API 통신:** STOMP, FastAPI
- **AI/ML:** PyTorch, Pandas, KcELECTRA
- **Infra:** Docker, AWS
- **협업 도구:** Notion, Figma, GitHub

#### 3. **주요 기능**
- **회원 및 인증 관리:** 소셜 로그인 및 이메일 인증 지원
- **상품 관리:** 이미지와 함께 상품 등록/수정/삭제, 검색 필터 기능
- **챗 기능:** 사용자 간 1:1 채팅과 AI 기반 사기 의심 메시지 경고 제공
- **페이지네이션:** 커서 기반 페이지네이션 적용으로 성능 개선

#### 4. **개발 및 아키텍쳐**
- **서버 아키텍쳐:** Docker 및 AWS를 통한 클라우드 구현
- **데이터 저장 방식:** Querydsl을 활용한 동적 쿼리 생성
- **파일 업로드 관리:** S3를 통한 이미지 파일 저장 및 관리

#### 5. **트러블슈팅**
- **쿼리 파라미터 가독성 저하 문제:** DTO를 사용하여 @RequestParam 대신 @ModelAttribute로 해결
- **페이지네이션 성능 저하 문제:** 커서 기반 페이지네이션 적용하여 성능 약 98.68% 개선.
- **파일 업로드 시 에러:** Nginx 설정 및 application.yml 수정으로 해결.

#### 6. **추가 개선 사항**
- **회원 정보 관리:** 회원이 작성한 글 조회 기능 추가
- **공통 코드 및 DTO 관리:** 상품 관련 DTO 및 에러 코드 정리.

이 프로젝트는 대학 생태계 내에서 중고 서적 거래를 위한 효율적이고 안전한 플랫폼을 제공하기 위한 노력의 일환으로, 다수의 기술 스택과 기능이 통합되어 사용자 편의성을 극대화하고 있습니다.
