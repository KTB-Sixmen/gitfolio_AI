Summary:
프로젝트 요약:

1. **기본 기능**:
   - 카카오톡 기반의 챗봇 시스템을 구성.
   - 챗봇과의 대화를 위한 UI 및 UX 구현, 사용자가 입력한 메시지를 처리하고 AI 응답을 가져오는 기능 포함.

2. **위젯 기능**:
   - 통합신청센터와 다양한 위젯(멘토링, 회의실, 도서) 추가 및 드래그앤드롭 기능 구현.
   - 달력 위젯을 통한 일정 관리 기능 제공.

3. **상태 관리**:
   - React Query와 Zustand를 사용하여 서버 상태 관리 및 전역 상태 관리.
   - 초기 데이터 저장 및 상태 관리를 위한 custom hooks 구현.

4. **API 통신**:
   - Weather API와의 통신을 통해 현재 날씨 정보와 주간 날씨 예보를 가져오는 기능 추가.
   - RESTful API를 사용하여 사용자 요청에 대한 응답 처리 및 데이터 전송.

5. **UI/UX 개선**:
   - Tailwind CSS 및 styled-components를 활용하여 반응형 디자인 및 직관적인 사용자 인터페이스 구현.
   - 마크다운 기능을 통해 사용자 대화의 포맷 지정 기능 추가.

6. **버그 수정 및 리팩토링**:
   - 발생한 여러 버그 수정 및 코드 리팩토링을 통해 코드 가독성 및 유지보수성 향상.
   - 로그인 세션 관리 및 인증 기능 구현.

7. **패키지 관리 및 프로젝트 설정**:
   - 필요한 라이브러리 설치 및 Tailwind CSS 설정 최적화.
   - 프로젝트 초기 구조 세팅 및 필요한 설정 파일 수정.

이 프로젝트는 풀스택 개발자로서의 역량을 보여줄 수 있는 훌륭한 기회였으며, 프론트엔드와 백엔드 모두에서 유의미한 기여를 통해 전반적인 시스템 아키텍처와 사용자 경험을 개선하는 방향으로 작업하였습니다. 이러한 경험을 활용하여 보다 발전된 기능 구현과 더 나은 사용자 경험을 제공할 수 있는 개발자로 성장할 것입니다.
