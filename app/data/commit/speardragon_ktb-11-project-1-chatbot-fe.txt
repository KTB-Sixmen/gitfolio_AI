Summary:
이 프로젝트는 카카오테크 부트캠프를 위한 챗봇 시스템을 구축하는 것을 목표로 하고 있으며, 다양한 기능으로 구성된 위젯들을 포함하고 있습니다. 아래는 주요 내용 요약입니다:

1. **위젯 통합**: 여러 개의 위젯(멘토링, 도서 예약, 회의실 예약 등이 추가됨)이 통합되어 사용자가 필요한 기능을 손쉽게 이용할 수 있게 보강되었습니다.
   
2. **드래그 앤 드롭 기능**: 사용자가 위젯의 배치를 드래그 앤 드롭으로 조정할 수 있는 기능이 추가되었습니다. 이는 사용자 경험을 증진시키는 요소로, `@hello-pangea/dnd` 라이브러리를 사용하여 구현되었습니다.

3. **구글 폼 통합**: `GoogleformWidget` 컴포넌트를 통해, 통합신청센터 링크가 추가되었습니다.

4. **반응형 디자인**: 모든 컴포넌트는 반응형으로 디자인되어 다양한 화면 크기에서 적절하게 표시됩니다. 예를 들어, `Sidebar`와 `Header`가 적절히 배치되고 크기가 조정됩니다.

5. **마크다운 지원**: `ReactMarkdown`을 사용하여 입력된 메시지를 마크다운 형식으로 표시하고, 코드 블록을 적절히 강조할 수 있는 기능이 추가되었습니다.

6. **날씨 정보 표시**: `WeatherWidget`에서는 현재 날씨 정보를 표시하며, 날씨 아이콘은 서버에서 로드되는 방식으로 구현되어 있습니다.

7. **API 통신**: 다양한 API를 이용해 데이터 송수신을 처리하고, 특히 `fetch`를 통해 AI 응답 및 채팅 이력을 관리합니다.

8. **상태 관리**: `zustand`를 이용해 상태 관리를 효율적으로 수행하며, 사용자 데이터 및 로딩 상태를 관리합니다.

9. **코드 품질 개선**: 여러 함수 및 컴포넌트는 보다 가독성이 좋고 유지보수하기 쉽게 리팩토링되었으며, 타입스크립트와 `@tanstack/react-query` 등을 사용하여 최적화되었습니다.

이 프로젝트는 전반적으로 카카오테크 부트캠프 참가자들이 필요한 다양한 기능을 보유한 챗봇 시스템을 구축하기 위한 실습 프로젝트입니다. 각 기능은 사용성과 편리함을 고려하여 디자인 및 구현되었으며, 기술 스택으로는 Next.js, TypeScript, React 등이 활용되었습니다.

- **채팅 기능**: 사용자가 입력한 내용에 따라 챗봇이 응답하는 기능

- **인증 기능**: 카카오 로그인 및 세션 관리
- **캐시 관리**: React Query를 사용해 API 호출 결과를 관리

- 사용자의 편의성을 고려한 UI 구성 변경 및 최적화.

이 프로젝트는 리액트(React) 기반의 채팅 애플리케이션으로, 다음과 같은 주요 기능 및 구조적 요소가 포함되어 있습니다:

1. **토스트 알림 기능**:
   - `ToastTitle` 및 `ToastDescription` 컴포넌트를 통해 사용자에게 알림 메시지를 표시하는 기능이 구현되었습니다.
   - `Toaster` 컴포넌트는 모든 토스트 메시지를 관리하고 표시합니다.

2. **채팅 인터페이스**:
   - `Chat` 컴포넌트는 사용자와 봇 간의 대화를 표시합니다.
   - 마크다운을 지원하여 코드 블록을 포함한 메시지 포맷팅 기능이 포함되어 있습니다.

3. **상태 관리**:
   - `zustand`를 사용하여 채팅 데이터 및 초기 데이터 상태를 관리합니다.
   - 각각의 상태는 별도의 스토어로 관리되어, 코드의 가독성과 유지보수성을 높입니다.

4. **UI 컴포넌트 및 스타일링**:
   - `Tailwind CSS`를 사용하여 빠르고 효율적인 스타일링을 구현했습니다.
   - 다양한 UI 구성 요소들이 재사용 가능하게 정의되어 있습니다(예: `Button`, `Input`, `Avatar`).

5. **로그인 기능**:
   - 카카오 OAuth 인증을 통한 로그인 기능이 구현되어 있습니다. 세션 쿠키가 없을 경우 로그인 페이지로 리다이렉트됩니다.

6. **다양한 설정 파일**:
   - 프로젝트 환경 설정을 위한 `.env.example` 및 `next.config.mjs`와 같은 파일이 포함되어 있습니다.
   - ESLint와 Prettier를 사용하여 코드 품질을 유지합니다.

7. **적용된 라이브러리 및 도구**:
   - `@radix-ui/react`와 같은 UI 라이브러리 및 마크다운 렌더링을 위한 `react-markdown` 등이 포함되어 있습니다.
   - 코드 품질 및 포맷 관리를 위한 TypeScript, ESLint, Prettier가 설정되어 있습니다.

8. **정의된 커뮤니케이션 스크립트**:
   - 사용자와 봇 간의 대화를 위해 `dummyMessages.ts` 파일에 시뮬레이션된 메시지들이 정의되어 있습니다.
