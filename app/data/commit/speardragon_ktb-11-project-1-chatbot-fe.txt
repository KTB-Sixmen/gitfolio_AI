Summary:
이 프로젝트는 카카오테크 부트캠프를 위한 챗봇 웹 애플리케이션으로, 다양한 기능의 위젯을 통합하여 사용자에게 더 나은 경험을 제공하는 것을 목표로 하고 있습니다. 주요 기능과 변경 사항을 요약하면 다음과 같습니다:

1. **통합신청센터 링크 추가**: 사용자가 통합신청센터로 쉽게 접근할 수 있도록 여러 이미지와 함께 링크가 추가되었습니다.

2. **위젯 기능 강화**: 
   - 새로운 위젯(예: 도서 예약 위젯, 멘토링 위젯, 회의실 예약 위젯 등)이 추가되어 사용자가 다양한 기능을 직관적으로 이용할 수 있게 되었습니다.
   - 위젯의 드래그 앤 드롭 기능이 구현되어 사용자가 위젯의 위치를 자유롭게 조정할 수 있습니다.

3. **반응형 디자인**: 다양한 화면 크기에서의 사용자 경험을 향상시키기 위해 반응형 디자인을 적용했습니다. 이는 모바일 및 데스크톱 환경 모두에서 사용할 수 있도록 설계되었습니다.

4. **스케줄 관리**: 
   - 캘린더 위젯이 추가되어 사용자가 자신이 예약한 일정을 관리할 수 있게 되었습니다.
   - 특정 날짜에 대한 스케줄 정보가 포함된 요청을 처리하여 일정 확인 및 관리를 용이하게 했습니다.

5. **마크다운 지원**: 사용자 메시지에 마크다운을 지원하여, 사용자가 입력하는 내용에 대해 포맷팅 기능을 제공했습니다. 이를 통해 더 깔끔하고 읽기 쉬운 메시지를 구성할 수 있습니다.

6. **API 통합**: 
   - API 요청을 통해 사용자와 AI 간의 채팅 데이터를 가져오는 기능이 추가되어 실시간으로 대화에 반응할 수 있게 했습니다.
   - 외부 서비스와의 통신을 통해 관련 데이터를 불러오는 새로운 기능들이 구현되었습니다.

7. **코드 구조 개선**: 
   - 각기 다른 기능을 모듈화하여 코드 가독성을 높이고 유지보수를 용이하게 했습니다.
   - 예를 들어, 각 위젯과 관련된 컴포넌트 및 스타일을 기능마다 분리하여 관리했습니다.

이 프로젝트는 React와 TypeScript를 기반으로 개발되어 있으며, Next.js 프레임워크를 활용하여 SSR(서버 사이드 렌더링)을 구현했습니다. 사용된 주요 라이브러리에는 `react-query`, `styled-components`, `lucide-react` 등이 포함되어 있습니다.

결론적으로, 이 프로젝트는 사용자가 여러 편리한 기능을 통해 보다 향상된 경험을 제공받을 수 있도록 설계되었으며, 개발자들은 웹 애플리케이션 설계 및 구현에 있어 체계적인 접근 방식을 취하고 있는 것으로 보입니다.

이 프로젝트는 카카오 부트캠프를 위한 대화형 챗봇 애플리케이션으로, 사용자가 질문을 입력하고 AI가 답변을 실시간으로 제공하는 기능을 포함합니다. 프로젝트의 주요 특징 및 기술 스택은 다음과 같습니다:

1. **기술 스택**:
   - **Next.js**: 서버 사이드 렌더링 및 정적 사이트 생성을 위한 React 프레임워크.
   - **React**: 사용자 인터페이스를 구성하는 UI 라이브러리.
   - **TypeScript**: 정적 타입을 지원하는 JavaScript의 상위 집합 언어.
   - **Zustand**: 상태 관리를 위한 경량 라이브러리.
   - **React Query**: 서버 상태 관리를 위한 데이터 패칭 및 캐싱 라이브러리.
   - **Tailwind CSS**: 유틸리티 기반 스타일링을 위한 CSS 프레임워크.
   - **Sonner**: 사용자 알림을 위한 라이브러리.

2. **기능 요청 및 시나리오**:
   - 사용자 로그인 및 인증 기능.
   - 다양한 대화 스타터 제공: 사용자가 자주 묻는 질문에 대한 추천 메시지 입력.
   - 실시간 대화 기록 관리 및 AI 응답 표시.
   - 날씨 정보 제공 및 UI 위젯 구현.
   - 커서 로딩 애니메이션을 통해 사용자 인터페이스를 보다 직관적으로 제공.

3. **구현된 컴포넌트**:
   - **초기 대화 화면**: 사용자가 자주 묻는 질문을 선택하거나 입력할 수 있는 메시지 입력 컴포넌트.
   - **대화 기록 컴포넌트**: 이전 대화 내용을 표시하고 새로운 메시지를 추가할 수 있는 스크롤 가능한 영역.
   - **위젯 컴포넌트**: 날씨 정보 및 교통 정보를 표시하는 UI 요소.
   - **상태 관리 기능**: Zustand와 React Query를 사용하여 상태를 관리하고 데이터 페칭.

4. **코드 리팩토링 및 보강**:
   - 불필요한 파일 및 코드 삭제로 구조를 정리하여 코드 유지보수성을 높임.
   - UI 개선: 사용자 경험을 개선하기 위해 스타일 및 애니메이션을 적용.

5. **기타 고려사항**:
   - **에러 처리**: API 호출 시 에러 처리 로직을 추가하여 신뢰성을 높임.
   - **로딩 상태 표시**: 비동기 데이터 로딩 중 로딩 컴포넌트를 통해 사용자에게 피드백 제공.

전반적으로 이 프로젝트는 다양한 기술을 통합하여 사용자 친화적인 방식으로 대화형 AI 시스템을 구현하고 있으며, 대화 흐름 및 UI/UX 최적화를 위해 지속적으로 리팩토링 작업이 이루어졌습니다.

프로젝트 개요:

이 프로젝트는 React와 Next.js를 사용하여 웹 기반 챗봇 인터페이스를 개발하는 것입니다. 주요 기능으로는 사용자와 챗봇 간의 대화를 지원하고, 다양한 UI 요소를 통합하여 반응형 플랫폼을 구현하고 있습니다.

### 주요 요소

1. **Toast 컴포넌트**:
   - `Toast`: 알림 메시지를 표시하는 기본 컴포넌트로, 제목, 설명 및 행동 버튼을 포함합니다.
   - `ToastProvider`, `ToastViewport`: 여러 Toast를 관리하는 컴포넌트로, 사용자에게 알림을 제공합니다.
   
2. **챗 UI**:
   - `Chat` 컴포넌트: 사용자와 봇 간의 메시지를 출력하는 UI로, 메시지 전송 입력란 및 사용자의 입력을 처리하는 로직을 포함합니다.
   - 메시지는 React Markdown을 이용하여 렌더링되며, 코드 블록을 구문 강조 처리하는 기능도 포함되어 있습니다.

3. **상태 관리**:
   - Zustand 라이브러리를 사용한 상태 관리로, 초기 데이터 및 세션 에러 등의 상태를 관리합니다.

4. **사용자 인증**:
   - 간단한 미들웨어를 통해 사용자의 세션을 체크하여 로그인 페이지로 리다이렉션하는 로직이 포함되어 있습니다.
   - 카카오 로그인 버튼과 같은 인터페이스를 통해 외부 인증 환경과 통합됩니다.

5. **UI 및 스타일링**:
   - Tailwind CSS를 사용하여 디자인이 적용되고, 다양한 UI 컴포넌트를 통해 사용자 경험을 향상시키고 있습니다.
   - 구성 요소들은 주로 Radix UI 라이브러리를 통해 작성되어 있습니다.

### 기술 스택
- **프론트엔드**: React, Next.js, Tailwind CSS, Zustand
- **UI 디자인**: Radix UI
- **개발 도구**: TypeScript, ESLint, Prettier

### 결론
이 프로젝트는 뛰어난 사용자 경험을 제공하는 챗봇 인터페이스를 구축하는 것을 목표로 하며, 구조적이고 유지보수가 용이한 방식으로 설계되어 있습니다. 각기 다른 컴포넌트와 상태 관리를 통해 사용자 피드백을 실시간으로 제공하고, 다양한 UI 구현으로 챗봇과의 상호작용을 원활하게 하고 있습니다.
