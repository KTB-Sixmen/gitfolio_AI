Summary:
이 프로젝트는 레스토랑 추천 시스템을 구현하기 위한 웹 애플리케이션으로, 사용자가 위치와 키워드를 기반으로 음식점을 추천받을 수 있도록 설계되었습니다. 이 시스템은 FastAPI를 사용하여 API를 생성하고, 다양한 머신러닝 모델을 활용하여 리뷰 데이터를 분석 및 활용합니다. 

### 주요 기능 및 수정 사항:
1. **주소 반환 개선 및 추천 식당 수 조정**:
   - 사용자의 위도와 경도로부터 주소를 얻어오고, 주소에서 동네 이름을 추출하여 입력 키워드와 조합하여 검색합니다.
   - 추천된 레스토랑 리뷰는 클러스터링 되어 상위 10개의 추천이 이루어집니다. 만약 추천 수가 10개를 초과하면 상위 5개와 하위 5개만 출력하도록 수정함.

2. **리뷰 크롤링 및 데이터 처리**:
   - Selenium과 BeautifulSoup 라이브러리를 활용하여 레스토랑 리뷰를 크롤링하며, 수집된 데이터는 모델에 입력하기 위해 전처리됩니다. 
   - 리뷰에서 가게 정보를 추가로 추출할 때 주소 반환 메시지와 함께 주소를 수정하는 등의 개선이 이루어졌습니다.

3. **앙상블 모델 구현**:
   - KcELECTRA와 BiLSTM 모델을 사용하여 각 리뷰의 긍정적 점수를 예측하고, 이를 종합하여 가게의 신뢰도 점수를 계산합니다.
   - 각 모델의 예측 결과는 가중치를 두고 결합되어 최종 점수를 계산하는 방식으로 구현되었습니다.

4. **성능 최적화**:
   - 리뷰 수에 따른 신뢰도를 로그 스케일로 가중치를 적용하여 계산하는 방식으로 개선하였습니다.
   - UMAP과 HDBSCAN을 활용한 클러스터링 기법 적용하여 리뷰 내용을 요약할 수 있는 기능을 추가하였습니다.

5. **코드 정리 및 리팩토링**:
   - 불필요한 주석 제거 및 코드 구조를 개선하여 가독성 향상에도 기여하였습니다.
   - 버전 관리에 있어서 의존성 라이브러리의 버전 소스를 정리하여 유지 관리의 편리성을 증대시켰습니다.

### 결론:
이 프로젝트는 실시간 데이터 수집과 머신러닝을 활용한 레스토랑 추천 시스템으로, 사용자의 요구에 맞춰 데이터 수집, 처리 및 모델링을 거쳐 최종적인 추천 결과를 도출하도록 설계되었습니다. 이는 웹 서비스 및 데이터 분석 전체 과정을 포함한 복합적인 기술을 사용하여 이루어졌으며, 개발자는 선진적인 알고리즘적 접근과 효율적인 데이터 관리 능력을 보유한 전문가로 판단됩니다.

이 프로젝트는 AI 기반의 음식점 리뷰 랭킹 시스템을 구축하는 데 중점을 둡니다. 주요 개발 사항을 다음과 같이 요약할 수 있습니다:

1. **데이터 수집 및 전처리**:
   - 여러 음식점의 리뷰 데이터를 수집하고, 이를 CSV 파일로 저장합니다.
   - 크롤링한 리뷰 데이터를 전처리하여 필요한 정보(리뷰 텍스트, 별점 등)를 추출하고 정제합니다.
   - 리뷰 텍스트는 형태소 분석을 통해 필터링되어 분석에 적합하도록 가공됩니다.

2. **모델 구축**:
   - BERT 및 BiLSTM을 활용한 감정 분석 및 리뷰 랭킹 모델을 개발하였습니다.
   - 질의 텍스트를 입력받아 긍정적/부정적 평가 점수를 예측하는 모델을 구축하고, 각각의 리뷰에 대한 점수를 계산합니다.
   - 모델의 성능 평가를 위해 정확도, 정밀도, 재현율, F1 score 등을 계산하며, 평가 결과는 데이터 셋 세분화에 반영됩니다.

3. **API 개발**:
   - FastAPI 프레임워크를 사용하여 음식점 추천 API를 구현하였습니다. 이 API는 위치 기반으로 음식점을 검색하고 리뷰를 처리하여 추천 결과를 반환합니다.
   - 사용자 요청에 대해 리뷰를 수집하고 랭킹화된 결과를 제공하는 자세한 경로를 정의하였습니다.

4. **모델 앙상블**:
   - KcELECTRA와 BiLSTM 모델을 앙상블하여 최종적인 리뷰 점수를 계산하는 방법을 구현했습니다. 이 과정에서 두 모델의 예측 값을 가중 평균하여 신뢰도를 반영합니다.

5. **구글 드라이브 연동**:
   - Google Colab을 통해 작업하는 경우 Google Drive에 데이터를 저장하고, 모델의 가중치를 직접 추출하는 기능이 도입되었습니다.

6. **성능 개선 및 오류 처리**:
   - 데이터 전처리 과정에서 발생할 수 있는 NaN 데이터를 처리하는 로직을 추가하고, 예외 발생 시 적절한 피드백을 로그로 남기는 기능이 구현되었습니다.

7. **프로젝트 구조 및 관리**:
   - 여러 파일과 폴더 구조를 통하여 모듈화된 방식으로 코드가 작성되었고, 코드의 가독성을 높이기 위해 주석을 효과적으로 활용하였습니다.

이 프로젝트는 AI 및 머신러닝 분야에 대한 깊은 이해와 FastAPI 및 데이터 처리 기술에 대한 숙련도를 필요로 합니다. 이를 통해 이를 통해 음식점 추천 시스템의 정확성과 사용자 경험을 향상시키고 있습니다.

이 프로젝트는 맛집 리뷰 데이터를 수집하고 분석하는 AI 기반의 서비스로 보입니다. 주요 기능은 다음과 같습니다:

1. **데이터 수집 및 크롤링**:
   - 카카오 맵에서 음식점 정보를 크롤링하여 리뷰를 수집합니다.
   - Selenium을 이용하여 웹 페이지를 탐색하고, 리뷰를 추출하는 로직이 구현되어 있습니다.

2. **데이터 전처리**:
   - 수집된 리뷰 데이터를 정제하고, 형태소 분석을 통해 한국어 텍스트를 전처리합니다.
   - 불용어 제거, 특수 문자 제거 등 다양한 전처리 기법을 사용하여 모델 학습에 적합한 형태로 변환합니다.

3. **모델링과 감정 분석**:
   - 수집된 리뷰를 기반으로 TF-IDF 벡터화 및 로지스틱 회귀 모델을 사용한 감정 분석 모델을 학습합니다.
   - 각 리뷰에 대해 긍정적 또는 부정적인 레이블을 부여하고, 최종적으로 리뷰를 랭킹화하여 저장합니다.

4. **리뷰 랭킹 및 저장**:
   - 코사인 유사도를 기반으로 리뷰를 비교하고, 가중치를 적용하여 최종 점수를 계산하고 랭킹화합니다.
   - 이를 CSV 파일로 저장하여 결과를 관리합니다.

5. **API 서버 구현**:
   - FastAPI를 사용하여 서버를 구축하고, 사용자 요청에 따라 리뷰 데이터를 반환하는 API 엔드포인트를 제공합니다.
   - 소셜 로그인을 구현하여 사용자가 카카오 계정으로 인증할 수 있도록 하였습니다.

6. **유저 관리 및 QnA 기능**:
   - 사용자 정보를 관리하고, QnA 기능을 추가하여 사용자 질문에 답변할 수 있는 시스템을 구현했습니다.

7. **테스트 구현**:
   - 각 기능 및 유닛테스트를 통해 코드의 품질을 확보하고 있습니다. 

프로젝트의 목적은 사용자가 특정 지역의 음식점 리뷰를 조회하고, 이를 기반으로 의사결정을 도와주는 앱 및 서비스로 보입니다.

- **전처리 과정**: 텍스트 정제, 형태소 분석
- **모델링**: 감정 분석 및 리뷰 랭킹화

- **유저 관리**: 소셜 로그인 및 질문답변 시스템 구현

### 프로젝트 요약

이 프로젝트는 **Spring Boot**와 **React**를 기반으로 한 **카카오 소셜 로그인 기능**을 구현한 웹 애플리케이션입니다. 주요 기능과 구성 요소는 다음과 같습니다:

#### 1. **사용자 관리 및 인증**
- **UserRepository**: 사용자 정보를 CRUD 처리하는 Spring Data JPA 인터페이스.
- **Refresh Token 관리**: 사용자의 `refreshToken`을 업데이트하는 쿼리 메소드 제공.
- **CustomUserDetails 구현**: 사용자 세부사항을 담고 있으며 OAuth2 및 OIDC 인증을 처리.

#### 2. **소셜 로그인 기능**
- **BasicAuthenticationProvider** 및 **CustomAuthenticationProvider**: 카카오 소셜 로그인 인증을 처리하는 Spring 시큐리티 컴포넌트.
- **JwtUtil**: JWT 생성 및 검증을 위한 유틸리티 클래스.

#### 3. **프론트엔드 구현**
- **React**와 **Material-UI**를 사용한 SPA(Single Page Application) 구조.
- **Vite**를 사용한 빌드 및 개발 환경 설정.
- 다양한 페이지 구성: Welcome, Page1, Page2 등, 각 페이지는 라우트 기반으로 구성.

#### 4. **오류 처리 및 상태 관리**
- **Recoil**을 사용하여 상태 관리를 구현.
- 에러 핸들링 컴포넌트 및 알림 시스템을 통해 사용자의 오류 경험을 개선.

#### 5. **크롤링 기능**
- 카카오 맵 API를 사용하여 리뷰 데이터 수집하는 모듈도 포함.
- **Selenium**을 이용한 웹 크롤링 스크립트를 작성하여 음식점 리뷰를 수집하고 정보 구조화.

#### 6. **기타 요건**
- **JWT** 및 **비밀번호 암호화**: BCrypt를 사용하여 비밀번호 보호.
- **환경 변수 관리**: `.env` 파일을 통한 프로젝트 환경 설정.

### 기술 스택
- **백엔드**: Spring Boot, Spring Security, JPA, Hibernate
- **프론트엔드**: React, TypeScript, Material-UI, Vite
- **기타**: JWT, RESTful API, Recoil, Axios, Selenium (크롤링)

이 프로젝트는 카카오 계정을 통한 소셜 인증과 여러 페이지를 가진 사용자 친화적인 인터페이스를 제공하여 웹 애플리케이션의 기본적인 사용자 경험을 강화하는 데 중점을 두고 있습니다.
