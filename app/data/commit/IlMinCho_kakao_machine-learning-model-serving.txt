Summary:
이 프로젝트는 카카오 맵 API를 활용하여 음식점 리뷰 데이터를 크롤링하고, 이 데이터를 기반으로 리뷰 분석 및 식당 추천 시스템을 구축하는 것을 목표로 하고 있습니다. 아래는 주요 특징 및 기능을 요약한 내용입니다.

1. **데이터 크롤링**:
   - 카카오 맵을 사용하여 특정 지역의 음식점 정보를 크롤링하고 각 음식점에 대한 리뷰를 수집하는 기능을 구현했습니다.
   - 크롤링 속도 개선을 위해 슬립 시간 최적화 및 병렬 크롤링을 적용하였습니다.

2. **리뷰 전처리 및 분석**:
   - 크롤링한 리뷰 데이터를 전처리하여 사용자가 이해하기 쉬운 형태로 변환합니다.
   - Komoran 형태소 분석기를 통해 텍스트를 토큰화하고 불용어를 제거하여 각 리뷰의 핵심 내용을 추출합니다.

3. **모델 개발**:
   - BiLSTM 및 KoBERT 모델을 사용해 리뷰에 대한 감성 분석 기능을 구축했습니다. 이를 통해 리뷰의 긍정/부정 점수를 평가합니다.
   - 전처리된 데이터셋은 학습 및 테스트를 위해 분할되어 사용됩니다.

4. **API 서버 구축**:
   - FastAPI 프레임워크를 이용하여 API 서버를 구축하고, 클라이언트에서 리뷰 데이터를 요청할 수 있도록 엔드포인트를 제공합니다.
   - 입력 데이터 모델을 정의하여 API 요청 시의 데이터 형식을 엄격하게 관리합니다.

5. **결과 저장**:
   - 크롤링한 데이터 및 모델의 예측 결과를 CSV 파일 형식으로 저장하는 기능이 포함되어 있어, 후속 분석이 용이합니다.

6. **에러 처리**:
   - 다양한 예외 처리를 통해 크롤링 과정 중 발생할 수 있는 오류들을 효과적으로 대응합니다.

이러한 기능들은 음식점 추천 시스템의 정확성을 높이고 사용자에게 유용한 정보를 제공하기 위해 설계되었습니다. 개발자는 카카오 맵 API와 Python을 이용한 데이터 크롤링, 기계 학습 모델링, API 구축 및 데이터 처리를 포함한 다양한 기술 스택에 대한 높은 이해도를 가지고 있으며, 실제 활용 가능한 AI 기반 시스템을 개발하는 능력을 보여주고 있습니다.
