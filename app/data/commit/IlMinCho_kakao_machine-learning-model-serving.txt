Summary:
프로젝트 요약 (식당 추천 시스템):

1. **프로젝트 개요**:
   - 이 프로젝트는 사용자의 위치와 키워드를 기반으로 식당을 추천하는 AI 시스템입니다. 주 기능은 크롤링을 통해 식당의 리뷰를 수집하고 이를 분석하여 추천 결과를 제공하는 것입니다.

2. **주요 기능**:
   - **리뷰 크롤링**: 카카오 맵에서 특정 지역의 식당 정보를 크롤링하여 식당 이름, 평점, 주소 및 리뷰를 수집합니다.
   - **리뷰 분석**: 수집된 리뷰를 감정 분석하는 모델을 통해 긍정적 및 부정적 점수를 계산하고, 이 정보를 기반으로 식당을 랭킹화합니다.
   - **키워드 기반 추천**: 사용자가 입력한 키워드와 위치 정보를 사용하여 추천 식당을 필터링합니다.
   - **API 구축**: FastAPI를 사용하여 외부에서 요청을 받아 식당 정보를 반환하는 API를 구성합니다.

3. **모델링 및 분석**:
   - 프로젝트에서는 **KoBERT** 및 **BiLSTM** 모델을 통해 리뷰 데이터를 분석하였습니다. 사용자의 리뷰에 대한 평점을 예측하고, 이를 기반으로 식당의 긍정 점수와 랭킹을 결정합니다.
   - 클러스터링 기법을 통해 유사한 리뷰를 그룹화하고 더 나은 추천 품질을 도모합니다.

4. **크롤링 성능 개선**:
   - 크롤링 속도를 개선하기 위해 병렬 처리 및 WebDriverWait를 활용하여 불필요한 시간 지연을 최소화하였습니다.
   - 리뷰 페이지에서 '더보기' 버튼을 클릭하여 더 많은 리뷰를 수집하는 로직을 구현했습니다.

5. **전처리 및 데이터 저장**:
   - 수집된 데이터를 전처리하여 CSV 파일로 저장하고, 향후 머신러닝 모델 학습에 사용할 수 있도록 준비했습니다.
   - 불용어 처리를 통해 분석의 정확도를 높이고, 사용자에 대한 평균 평점을 계산하여 더 신뢰할 수 있는 추천을 제공하기 위해 데이터를 가공합니다.

6. **기타 기능 및 확장성**:
   - 카카오 소셜 로그인 기능을 추가하여 사용자 인증을 통해 개인화된 서비스를 제공하게 되었습니다.
   - 향후 API 통신 방식을 개선하여 외부 데이터 소스와의 연계를 통한 유연한 시스템 구성을 목표로 하고 있습니다.

이 프로젝트는 AI 기술과 웹 크롤링을 결합하여 실시간으로 유용한 정보를 사용자에게 제공합니다. 데이터 수집, 모델 학습, API 구축 등 포괄적인 개발 과정을 통해 식당 추천이라는 실용적인 서비스를 구현하였습니다.
