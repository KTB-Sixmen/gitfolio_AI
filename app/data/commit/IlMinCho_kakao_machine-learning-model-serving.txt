### 프로젝트 요약

이 프로젝트는 카카오맵을 활용하여 식당 리뷰를 자동으로 크롤링하고, 자연어 처리(NLP)를 이용하여 리뷰 기반의 식당 추천 시스템을 구축하는 것입니다. 주요 기능 및 섹션은 다음과 같습니다:

1. **크롤링 기능**:
   - 카카오맵에서 식당과 해당 리뷰를 크롤링하는 기능을 구현.
   - 페이지 수에 따라 여러 페이지에서 리뷰를 수집하고, 각 리뷰의 상세 정보를 추출합니다.
   - 크롤링 성능을 높이기 위해 병렬 처리를 도입하고, 슬립 시간 조절을 통해 속도를 개선했습니다.

2. **데이터 전처리**:
   - 수집된 데이터를 정제하고 필요한 정보를 뽑아내는 과정을 포함합니다.
   - 자연어 처리 기법을 활용하여 리뷰 텍스트를 전처리하고, 불용어를 제거하여 모델 학습에 적합한 데이터로 변환합니다.

3. **모델 및 추천 시스템**:
   - BERT와 BiLSTM 모델을 통해 리뷰의 감정 분석 기능을 구현하고, 이를 바탕으로 식당의 긍정적인 리뷰 스코어를 계산합니다.
   - 키워드 기반으로 식당 추천 기능을 제공합니다.

4. **API 구축**:
   - FastAPI를 활용하여 식당 추천 API 서비스를 구축했습니다.
   - 요청을 통해 키워드 및 위치 정보를 받고, 해당 정보를 기반으로 추천 결과를 반환합니다.

5. **실행 환경 및 문서화**:
   - 프로젝트에 필요한 패키지 및 라이브러리를 관리하는 requirements 파일을 포함하여, 문서화를 통해 코드 이해를 돕고 있습니다.

### 주요 개선 사항
- 주소 리턴과 관련된 버그 수정
- 추천 식당 개수 조정
- 크롤링시 주소 끊김 문제 해결
- 클러스터링 및 모델 앙상블을 통한 성능 개선

이 프로젝트는 NLP와 웹 스크래핑 기술을 기반으로 하여, 카카오맵의 식당 정보를 실시간으로 활용하고, 사용자에게 개인화된 식당 추천을 제공하는 데 초점을 맞추고 있습니다.
