프로젝트 요약:

이 프로젝트는 한국의 외식업체에 대한 리뷰 정보를 수집하고 이를 기반으로 식당 추천 시스템을 구축하는 것을 목표로 합니다. 주요 기능 및 개발 내용은 다음과 같습니다:

1. **크롤링 기능**:
   - 카카오맵 API를 활용하여 특정 지역의 식당 정보를 수집합니다.
   - 식당 리뷰 크롤링 기능을 구현하여 각 식당에 대한 리뷰를 자동으로 수집하며, 각 리뷰에서 레벨, 후기 개수, 평균 평점 등을 추출합니다.

2. **데이터 전처리**:
   - 수집된 리뷰 데이터를 정제하고 필요한 정보를 추출하는 전처리 과정을 개발했습니다.
   - 전처리 후, 데이터를 CSV 파일로 저장하여 지속적으로 사용할 수 있도록 합니다.

3. **모델 개발**:
   - 리뷰 데이터를 기반으로 한 랭킹 모델을 개발하여 식당의 긍정적 맛 평가를 자동화합니다.
   - BERT 및 KoBERT와 같은 최신 자연어 처리 모델을 활용하여 리뷰의 감정 분석을 수행합니다.

4. **API 구축**:
   - FastAPI를 사용하여 RESTful API를 구현하고, 클라이언트와의 통신을 위한 서버 엔드포인트를 설정했습니다.
   - 사용자 요청에 따라 동네 및 키워드를 기반으로 추천 식당 리스트를 반환하는 기능을 추가했습니다.

5. **성능 최적화**:
   - 웹 크롤링 시, 비동기 작업과 병렬 처리를 통해 성능을 개선하였습니다. 크롤링 속도를 높이기 위해 WebDriverWait 사용하여 요소가 로드될 때까지 대기하는 방법을 적용했습니다.

6. **이슈 및 버그 수정**:
   - 크롤링 중 발생하는 다양한 오류와 문제를 해결하기 위해 코드 리팩토링 및 예외 처리를 강화했습니다.
   - 리뷰 페이지 수가 적거나 없는 경우를 고려하여 적절한 예외 처리를 추가했습니다.

프로젝트는 기본적으로 외식 산업의 데이터 기반 의사 결정을 지원하기 위한 시스템으로, 리뷰 데이터의 정량적 분석을 통해 식당 추천 품질을 향상시키기 위해 지속적으로 발전하고 있습니다. 이 시스템은 다양한 ML/DL 모델과 데이터 처리 기술을 활용하여 현대적인 AI 기반 애플리케이션의 사례를 보여줍니다.
