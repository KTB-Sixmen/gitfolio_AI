Summary:
이 프로젝트는 식당 추천 시스템을 구축하기 위한 것으로, 사용자의 위치와 키워드를 바탕으로 다양한 레스토랑을 추천하는 기능을 포함하고 있습니다. 주요 기능 및 변경사항은 다음과 같습니다:

1. **위치 기반 추천**:
   - 사용자의 위도와 경도를 바탕으로 해당 위치의 주소를 가져오고, 동네 이름을 추출하여 추천 키워드와 결합합니다.

2. **리뷰 크롤링**:
   - 결합된 키워드를 사용해 레스토랑 리뷰를 최대 3페이지(최대 30개 리뷰)까지 크롤링합니다. 리뷰 데이터는 후속 처리 및 분석을 위해 수집됩니다.

3. **리뷰 랭킹 및 클러스터링**:
   - 수집된 리뷰 데이터에 대해 두 가지 모델(KcELECTRA와 BiLSTM)을 사용하여 리뷰의 감정 점수를 예측하고 평균 점수를 계산하여 최종 추천 점수를 산출합니다.
   - 클러스터링 알고리즘인 HDBSCAN을 적용하여 리뷰를 분석하고 주요 클러스터의 키워드를 추출하여 추천 결과에 포함됩니다.

4. **추천 결과**:
   - 추천된 레스토랑 리스트가 사용자의 요청에 따라 상위 및 하위 평가된 레스토랑들을 반환하며, 클러스터링된 키워드 또한 포함됩니다.

5. **리팩토링 및 성능 개선**:
   - 코드의 성능 및 가독성을 높이기 위해 여러 부분에서 리팩토링이 이루어졌으며, 필요 없는 데이터 파일은 삭제되었습니다.
   - 각 모델의 가중치를 조절하여 앙상블 기법을 적용함으로써 더 나은 추천 결과를 도출하고 있습니다.

6. **의존성**:
   - `requirements.txt` 파일을 통해 필요한 라이브러리들이 정의되어 있으며, Hugging Face Transformers와 같은 최신 NLP 모델이 포함되어 있어 자연어 처리 작업을 도와줍니다.

이 시스템은 사용자의 요구에 맞춘 식당 추천 시스템으로, 리뷰 데이터를 기반으로 사용자에게 맞춤형 정보와 신뢰성 있는 추천을 제공하는 것을 목표로 하고 있습니다.

이 프로젝트는 음식점 리뷰 데이터를 수집, 처리 및 분석하는 머신 러닝 기반의 추천 시스템을 구축하는 것을 목표로 하고 있습니다. 아래는 프로젝트의 주요 내용입니다.

1. **리뷰 데이터 수집**:
   - 카카오맵 API 등을 이용하여 음식점 리뷰를 크롤링하고 이를 CSV 파일로 저장하는 기능이 포함되어 있습니다.

2. **데이터 전처리**:
   - 수집한 리뷰 데이터를 전처리하여 불필요한 정보를 제거하고, 레이블을 생성하는 과정이 포함되어 있습니다. 동영상, 감정점수 계산 등을 통해 리뷰를 정리합니다.

3. **모델 개발**:
   - KoBERT 및 KcELECTRA와 같은 사전 훈련된 언어 모델을 활용하여 리뷰의 감정을 분석하고, 특정 음식점의 리뷰 점수를 예측하는 모델을 개발합니다.
   - BiLSTM 모델도 사용하여 리뷰의 감정 점수를 예측하고, 이를 기반으로 음식점을 추천합니다.

4. **API 서버 구축**:
   - FastAPI를 사용하여 클라이언트와 서버 간 통신을 가능하게 하는 RESTful API를 구축했습니다. 이를 통해 추천 요청을 받고, 처리된 결과를 사용자에게 전달합니다.

5. **데이터 시각화 및 결과 분석**:
   - 수집된 데이터를 분석하여 각 음식점에 대한 평점을 시각화하고, 결과를 보고하는 기능이 추가되어 있습니다.

6. **데이터 저장 및 관리**:
   - 리뷰 데이터와 모델 결과를 CSV 및 JSON 형식으로 저장하여 나중에 사용할 수 있도록 합니다.

7. **테스트 및 배포**:
   - 모델의 성능을 테스트하기 위한 테스트 데이터셋을 설정하고, Jenkins와 같은 CI/CD 도구를 통해 배포 파이프라인을 구축합니다.

이 프로젝트는 리뷰 분석 및 추천 알고리즘 개발을 통해 사용자에게 보다 나은 음식점 선택의 경험을 제공하는 것을 목표로 하고 있습니다. 프로젝트는 데이터 수집부터 모델 개발 및 배포까지의 전 과정을 포함하여, 다양한 기술 스택이 활용되었습니다.

이 프로젝트는 음식점 리뷰를 수집하고 분석하여, 사용자에게 랭킹화된 리뷰 정보를 제공하는 AI 기반의 시스템입니다. 여기서는 코드와 커밋 메시지를 통해 프로젝트의 주요 기능과 구성 요소를 요약하겠습니다.

### 주요 기능 및 구성 요소:
1. **데이터 수집 및 크롤링**:
   - 카카오 맵 API를 사용하여 특정 위치의 음식점 정보를 수집하고, 해당 음식점의 리뷰를 크롤링합니다.
   - Selenium을 활용하여 웹 브라우저를 통해 데이터를 자동으로 수집합니다.

2. **데이터 전처리**:
   - 수집된 리뷰 데이터를 전처리하여, 불필요한 텍스트를 제거하고 필요한 정보(별점, 리뷰 텍스트 등)를 추출합니다.
   - 한국어 형태소 분석과 불용어 제거를 통해 데이터를 정제합니다.

3. **모델 학습 및 리뷰 랭킹화**:
   - 로지스틱 회귀 모델을 사용하여 리뷰의 감정 분석을 수행합니다.
   - TF-IDF 벡터화와 평점을 결합하여 리뷰를 랭킹화합니다.

4. **API 구현**:
   - FastAPI를 사용하여 클라이언트와 서버 간의 RESTful API를 구현하였습니다.
   - 리뷰를 요청하고, 결과를 응답하는 엔드포인트를 제공합니다.

5. **유저 인증 및 관리**:
   - 카카오 소셜 로그인 기능을 구현하고, JWT를 이용해 세션을 관리합니다.
   - 유저 정보를 DB에 저장하고 관리하는 Repository와 Service 계층을 구축하였습니다.

### 프로젝트 구조:
- `src/data_processing/`: 데이터 수집 및 전처리 관련 파일
- `request/`: 요청 모델 및 응답 모델 정의
- `controller/`: API 엔드포인트를 처리하는 클래스
- `security/`: 인증 및 권한 관련 처리
- `repository/`: 데이터베이스에 대한 CRUD 연산

### 커밋 메시지 정리:
- **피처 추가**: 리뷰 랭킹화 모델 구현, 리뷰 수집 기능 추가.
- **버그 수정**: 크롤링 이슈 해결, API 오류 처리 개선.
- **리팩토링**: 코드 구조 개선 및 기능 분리.
- **문서화**: README 파일 업데이트 및 커밋 기록 문서화.

### 결론:
이 프로젝트는 음식점 리뷰 데이터의 효율적인 수집, 분석, 모델링을 목표로 하며, 이를 위해 여러 가지 프로그래밍 기술과 라이브러리를 활용하고 있습니다. 웹 크롤링, 머신러닝 모델, RESTful API의 구현 등 다양한 분야의 지식이 결합된 것으로 보이며, 이는 해당 개발자가 다양한 기술적 역량을 지니고 있음을 나타냅니다.

프로젝트 요약:

1. **카카오 소셜 로그인 구현**:
   - 이 시스템은 카카오 API를 활용하여 사용자 인증을 처리합니다.
   - 사용자는 카카오 계정으로 로그인하며, 관련된 JWT(JSON Web Token)를 발급받고 이를 이용하여 인증합니다.

2. **성과 보안 관리**:
   - 사용자 정보(아이디, 비밀번호, 역할 등)를 보호하기 위해 Spring Security를 사용합니다.
   - `CustomUserDetails`, `BasicAuthenticationProvider`, `CustomAuthenticationProvider` 등 클래스가 사용되어 인증 과정을 관리합니다.

3. **JWT 처리**:
   - `JwtUtil` 클래스를 통해 JWT의 생성 및 검증 기능을 구현합니다.
   - 리프레시 토큰을 관리하기 위한 기능도 제공하여, 체계적인 사용자 인증이 이루어집니다.

4. **데이터베이스 관리**:
   - Spring Data JPA를 활용하여 사용자 정보를 DB에 저장하고 업데이트합니다.
   - `UserRepository`를 통해 사용자 조회, 업데이트 기능이 포함되어 있습니다.

5. **오류 및 예외 처리**:
   - `JwtAuthEntryPoint`, `JwtAccessDeniedHandler`와 같은 클래스가 예외 처리를 통해 사용자에게 적절한 오류 메시지를 제공합니다.
   - 사용자 경험을 개선하기 위한 다양한 상황의 검증 로직이 포함되어 있습니다.

6. **프론트엔드 관련**:
   - React 기반의 프론트엔드가 구성되어 있으며, Material-UI 라이브러리를 통해 UI 요소를 구성합니다.
   - 다양한 페이지 및 컴포넌트가 구현되어 있어 사용자에게 편리한 인터페이스를 제공합니다.

7. **지속적인 개선 사항**:
   - 코드 내에는 사용자 경험 개선을 위한 TODO 주석이 다수 존재하며, 크롤링 기능과 관련된 개선도 필요함을 명시하고 있습니다.

8. **크롤링 기능**:
   - `kakao-review-data-crawling.py` 파일을 통해 카카오맵에서 식당 리뷰를 크롤링하는 기능이 구현되어 있습니다.
   - 크롤링 속도와 데이터 품질 개선을 위한 문제 지적이 포함되어 있습니다.

이 프로젝트는 카카오 소셜 로그인을 통한 안전한 사용자 인증 시스템을 구축하고 있으며, 다양한 관리 및 보안 기법을 활용하여 사용자 데이터를 보호하고 있습니다. 또한, 데이터 크롤링 기능을 통해 추가적인 데이터 수집도 가능하게 하고 있습니다. 가장 유효한 비즈니스 로직과 사용자 경험 개선을 위한 다양한 노력이 엿보이는 프로젝트입니다.
