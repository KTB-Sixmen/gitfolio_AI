Summary:
이번 GitHub 커밋에서는 주로 예약 시스템과 관련된 수정 및 기능 추가가 이루어졌습니다. 아래는 주요 작업 내용과 구현 방법에 대한 요약입니다.

### 1. `print()` 함수 삭제
- **파일**: `models/doctor.py`
- **변경 내용**: `pendingrequest` 메소드 내에서 진단을 위해 사용되었던 `print(allappointments)` 문이 삭제되었습니다.
- **결과**: 디버깅 출력이 제거되어 코드가 깔끔해졌습니다.

### 2. 예약 버그 수정
- **파일**: `healthdb.db`, `models/doctor.py`
- **작업 내역**:
  - 예약 상태를 업데이트하는 로직에서 불필요한 `print()` 문이 제거되었습니다.
  - 예약 수정을 위한 로직이 수정되어, 상태가 'inprogress'인 예약만 업데이트합니다.
  - accept 조건을 만족할 경우, 환자 이메일과 의사 이메일에 맞는 예약 정보를 가져와서 해당 예약의 날짜 및 시간 정보를 업데이트합니다.
  
### 3. 테스트 케이스 업데이트
- **파일**: `test_server.py`
- **변경 사항**:
  - 기존 테스트 케이스가 수정되고 새로운 테스트 케이스가 추가되었습니다.
  - 다양한 기능(로그인, 예약 취소, 보고서 업로드 등)에 대한 테스트가 포함되어 있으며, 각 케이스에서 적절한 응답을 검증합니다.

### 4. 의사의 가용 시간 설정
- **파일**: `models/doctor.py`, `server.py`, `templates/patients/book_doctor.html`
- **구현 내용**:
  - 의사의 가용 시간 관리 로직이 추가되어, 의사가 특정 날짜와 시간에 대한 예약 가능 여부를 설정할 수 있게 되었습니다.
  - `/set_availability` 엔드포인트가 추가되어 의사가 가용 시간 정보를 설정할 수 있습니다.
  - 환자가 의사를 예약할 때 해당 가용 정보를 기반으로 예약을 진행합니다.

### 5. 보고서 시스템 추가
- **파일**: `models/reports.py`, 관련 HTML 템플릿 파일
- **변경 사항**:
  - 환자의 보고서를 관리하기 위한 `ReportFile` 클래스가 추가되었습니다. 이를 통해 환자는 자신의 보고서를 업로드하고, 이를 의사와 공유할 수 있습니다.
  - 보고서를 업로드 및 삭제하는 기능이 구현되어, 환자가 이전에 업로드한 보고서를 볼 수 있게 되었습니다.

### 6. UI 및 사용자 경험 개선
- **파일**: HTML 템플릿들
- **변경 사항**:
  - 환자가 보고서를 업로드하고 관리할 수 있는 뷰가 추가되었습니다.
  - 의사에게 전송된 가용 시간이 캘린더에 시각화되는 기능이 구현되어, 사용자들에게 더 나은 인터페이스를 제공합니다.

이와 같은 변경사항들은 시스템의 기능을 향상시키고, 전체적인 사용자 경험을 개선하는 데 기여하였습니다.
