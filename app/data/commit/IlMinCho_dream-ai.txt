Summary:
프로젝트 요약:

1. **프로젝트명**: 드림-아이 (dream-ai)
   - 노년층의 이루지 못한 꿈을 바탕으로 이야기를 생성하고 교육 프로그램 및 직업을 추천하는 서비스입니다. 생성형 AI 기술을 활용하여 개인의 경험과 감정을 바탕으로 한 이야기를 생성합니다.

2. **주요 기능**:
   - 사용자가 과거의 꿈과 경험에 대한 이야기를 작성할 수 있도록 프롬프트를 제공하는 스토리 생성 기능이 포함되어 있습니다.
   - 모델 업그레이드: 기존 `gpt-4o` 모델에서 `gpt-3.5-turbo`로 변경하여 성능 및 비용 효율성을 개선했습니다.
   - API 구성: 이미지 생성 및 이야기를 생성하는 API 엔드포인트를 정의하고, 이를 통해 프론트엔드와 통신합니다.

3. **파일 및 수정 내역**:
   - **README.md**: 프로젝트 설명 및 팀원 목록 업데이트.
   - **llm_service.py**: AI 모델 변경 및 상호작용 스토리 생성 로직 추가. 사용자가 자신의 과거 경험을 바탕으로 이야기를 자연스럽게 이어갈 수 있도록 프롬프트 수정.
   - **ai_server.py**: 스토리 생성 및 이미지 생성 API의 엔드포인트 수정.
   - **es_vecDB_search.py**: Elasticsearch를 활용한 벡터 검색 기능 개선.
   - **es_vecDB_save.py**: 데이터 저장 및 인덱스 매핑 설정 관련 코드 개선.

4. **기타 특징**:
   - 팀원 각각의 역할이 명시되어 있으며, 사용자의 참여와 경험을 기반으로 한 이야기 생성이 중요한 요소로 작용합니다.
   - 전체적으로 사용자 경험을 중시하고, 개인의 감정과 배움을 중심으로 해 나가는 방향에 이루어짐.

이 프로젝트는 생성형 AI와 Elasticsearch를 활용하여 개인화된 스토리 생성 서비스를 제공하며, 다양한 사용자의 꿈과 경험을 바탕으로 의미 있는 데이터를 생성할 수 있도록 돕는 것을 목표로 하고 있습니다.
