Summary:
이 프로젝트는 음식점 리뷰를 분석하고 추천하는 시스템을 구축하는 데 중점을 두고 있습니다. 주요 특징은 다음과 같습니다:

1. **모델과 기술 스택**:
    - Sentence-BERT 및 KcELECTRA 모델을 사용하여 리뷰의 감정을 분석합니다.
    - Elasticsearch를 통해 데이터베이스와 API를 통합하여 리뷰를 효과적으로 검색합니다.

2. **주요 기능**:
    - 리뷰 크롤링: 기본적으로 Yelp와 같은 플랫폼에서 리뷰를 수집하고 이를 데이터베이스에 저장합니다.
    - 클러스터링: HDBSCAN 알고리즘을 사용하여 리뷰를 클러스터링하고, 이를 통해 주요 키워드 및 주제를 추출합니다.
    - 서비스 API: 사용자 요청을 처리하여 음식을 추천하는 REST API를 제공합니다.

3. **다양한 업데이트**:
    - README 파일을 업데이트하여 사용자에게 정확한 정보와 이미지 링크를 제공하고, 필요한 도구 및 환경 설정에 대한 지침을 포함했습니다.
    - 코드는 지속적으로 개선되며, 모델 업로드 및 배치 처리 기능이 포함되어 있습니다.

4. **코드 최적화 및 관리**:
    - API 요청 시 에러 로그를 기록하여 문제를 조기에 발견할 수 있도록 했습니다.
    - 코드 내 불필요한 주석을 제거하여 가독성을 높였습니다.

5. **기술적 문제 해결**:
    - 특정 경고 문제를 해결하고, 코드 내 통합된 모델을 신속하게 업데이트하여 최신 상태를 유지했습니다.

이 프로젝트는 음식점 추천 서비스에 대한 다양한 기능을 통합하고, 머신러닝 모델을 통해 사용자 경험을 최적화하는 것을 목표로 하고 있습니다.
