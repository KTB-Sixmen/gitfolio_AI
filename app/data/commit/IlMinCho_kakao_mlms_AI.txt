Summary:
**프로젝트 요약: 추천 맛집 API 개발**

이 프로젝트는 사용자의 입력(음식 종류와 키워드)을 받아 현재 위치를 기반으로 추천 맛집 리스트를 제공하는 API를 설계하는 내용을 담고 있습니다. 주요 특징은 다음과 같습니다:

1. **입력 및 출력**:
   - 사용자가 위치와 키워드를 입력하면, API는 해당 위치 근처의 추천 맛집 리스트를 반환합니다.
   - 반환되는 리스트에는 가게 이름, 점수, 자주 등장하는 단어들이 포함됩니다.

2. **데이터 처리 및 저장**:
   - 사용자가 입력한 키워드와 위치 정보를 기반으로 Elasticsearch를 사용하여 맛집 데이터를 저장하고 검색합니다.
   - 카카오 맵에서 웹 크롤링을 통해 리뷰 데이터를 수집하여 Elasticsearch에 저장합니다.

3. **모델 및 라이브러리**:
   - 추천 및 랭킹 시스템은 다양한 모델을 포함하며, KcELECTRA와 Sentence-BERT 모델을 활용하여 리뷰 분석과 감정 점수를 평가합니다.
   - FastAPI를 이용하여 API 서버를 구축하고, 데이터 처리 및 응답 시간을 기록하여 성능을 개선합니다.

4. **성능 개선 사항**:
   - 리뷰 분석시 HDBSCAN 클러스터링을 통해 리뷰를 그룹화하고, 각 그룹에서 자주 등장하는 단어를 추출하여 사용자에게 유용한 정보 제공을 목표로 하고 있습니다.
   - 배치 처리를 통해 모델 예측의 효율성을 높이고, 일반적인 병목 현상을 줄여 전체 처리 속도를 개선했습니다.

5. **기타 기술 스택**:
   - Django, Selenium, BeautifulSoup, Elastic search 등이 포함되어 있으며, 이러한 기술들은 데이터 수집 및 저장, API 호출 과정에서 사용됩니다.
   - Python 환경에서 개발되었으며, JDK, PIP 의존성 관리 도구를 사용하여 필수 라이브러리를 설치합니다.

이 프로젝트는 사용자에게 맛집 추천을 통해 향후 방문할 장소를 효율적으로 찾을 수 있도록 돕는 기능을 제공하며, 현대적인 데이터 처리 기술을 활용한 웹 기반 서비스입니다.
