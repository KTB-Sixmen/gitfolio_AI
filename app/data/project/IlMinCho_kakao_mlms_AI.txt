Summary:
### 프로젝트 개요
- 사용자의 입력(음식 종류, 키워드) 기반 맛집 추천 API 설계.
- 위치 기반으로 추천 맛집 리스트 제공 및 정렬 기능 구현.

### 주요 기능 및 작업 내용
1. **추천 맛집 리스트 제공**:
   - FastAPI로 API 엔드포인트 구현.
   - 가게 이름, 점수, 자주 등장하는 리뷰 단어 포함.

2. **근처 맛집 정렬**:
   - 사용자 위치 기반으로 추천 맛집 거리 정렬 로직 작성.

3. **지도 시각화**:
   - 추천 맛집을 지도에 마커로 표시하는 기능 구현.

4. **리뷰 크롤링 및 데이터 저장**:
   - Selenium으로 웹 크롤링 로직 구현.
   - 리뷰 데이터를 Elasticsearch에 저장하도록 설정.

5. **클러스터링 및 랭킹화**:
   - KcELECTRA 모델과 BiLSTM 모델 활용.
   - 리뷰 클러스터링 및 랭킹 로직 적용.

### 문제 및 해결
- **Elasticsearch 설정 문제**: 환경 변수로 DB 접근 정보 구성, 서버 실행 시 서비스 동기화.
- **리뷰 크롤링 실패**: XPATH 경로 동적 설정으로 웹사이트 구조 변화 대응.
- **성능 개선**: ThreadPoolExecutor로 병렬 처리하여 크롤링 속도 향상.

### 성과
- 사용자 입력 바탕의 정확한 맛집 추천 API 제공.
- 지속적인 모델 개선과 데이터 수집 통해 성능 향상 기대.
