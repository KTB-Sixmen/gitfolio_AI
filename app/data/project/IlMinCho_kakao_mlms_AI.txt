## 프로젝트 요약: 음식점 추천 시스템

### 주요 내용 및 기여
1. **기능 및 목적**:
   - 음식점 리뷰 분석 및 추천 시스템 구축.
   - 리뷰 크롤링, 감정 분석, 클러스터링, 추천 기능 포함.

2. **모델 개발**:
   - KcELECTRA, Sentence-BERT 모델 활용.
   - 리뷰 감정 분석 및 점수 산출.
   - 여러 모델 앙상블 방식으로 신뢰성 높임.

3. **데이터베이스 구축**:
   - Elasticsearch 설정 및 API 연결.
   - 사용자 쿼리 처리 효율화.

4. **배치 처리 구현**:
   - KcELECTRA 모델에 배치 처리 적용, 여러 리뷰 동시 평가 가능.
   - 처리 시간 220초에서 26초로 개선.

5. **클러스터링 및 시각화**:
   - HDBSCAN으로 리뷰 데이터 클러스터링, 상위 키워드 추출.
   - 지도 상에 추천 맛집 위치 시각화.

### 문제 해결 및 결과
- **예외 처리 적용**: 데이터 크롤링 및 전처리 중 발생한 오류 해결.
- **모델 성능 조정**: 하이퍼파라미터 튜닝으로 성능 최적화.
- **응답 속도 개선**: 쿼리 응답 시간 단축 및 사용자 경험 향상.

### 결론
- 머신러닝 모델 실제 활용 사례 경험.
- 데이터 수집, 클러스터링, 추천 알고리즘의 중요성 인식.
- 문서화 및 코드 관리 능력 강화.
