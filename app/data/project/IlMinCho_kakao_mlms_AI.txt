Summary:
### 프로젝트 개요:
- 사용자 입력을 바탕으로 현재 위치 근처 추천 맛집 제공 API 설계

### 주요 기능
1. **사용자 입력 처리**: 
   - 위경도 및 키워드 수용
2. **맛집 추천 및 클러스터링**:
   - 현재 위치 기준 추천 리스트 정렬
   - 리뷰 내 키워드 클러스터링
3. **리뷰 데이터 크롤링**:
   - Elasticsearch에서 리뷰 확인 및 카카오 API를 통한 웹 크롤링
4. **감성 분석**:
   - KcELECTRA, BiLSTM 모델 사용
5. **앙상블 기법 적용**: 
   - 모델 예측 결과 결합 후 랭킹화
6. **Visuallization**:
   - 지도에 맛집 위치 표시

### 기술 스택
- Backend: FastAPI
- DB: Elasticsearch
- 데이터 수집: Selenium
- ML 모델: KcELECTRA, BiLSTM
- 데이터 처리: Pandas, scikit-learn, Numpy

### encountered issues 및 해결
- **크롤링 실패**:
  - 웹 구조 변경 → ThreadPoolExecutor로 병렬 처리 개선
- **모델 정확도 부족**:
  - 전처리 및 앙상블 기법 적용으로 최적화

### 결과
- 지역 기반 맛집 추천 시스템 구축, 사용자 편의 향상
