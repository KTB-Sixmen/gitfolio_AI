Summary:
### 프로젝트 개요
- 다양한 문제 해결을 위한 Python 스크립트 집합
- 데이터 구조(트리, 배열) 및 알고리즘(탐색, 정렬, 수학적 계산)
- 각 문제에 대한 테스트 케이스 처리 및 결과 출력

### 주요 기능 및 작업한 부분

1. **소수 및 수론 문제 해결**
   - `get_primes` 함수: 에라토스테네스의 체 이용해 소수 리스트 생성
   - 성능 개선: 알고리즘 최적화 및 테스트 케이스 확장

2. **트리 탐색 및 조작**
   - 이진 트리 구성: 전위, 중위 순회로 후위 순회 출력
   - `dfs`, `lca` 함수 구현: 깊이 탐색 및 가장 가까운 조상 찾기

3. **후위 표기식 변환 및 계산**
   - 중위 표현을 후위 표현으로 변환하는 알고리즘 구현
   - 효율적인 계산 로직 적용

4. **문자열 처리**
   - 특정 패턴 검색 로직 추가: 데이터 추출 및 계산 목적
   - 오류 체크 및 간격 확인 로직 구현

5. **상태 계산**
   - 사회적 역할 기반 시뮬레이션: 상태 간의 관계 설정
   - 값 변화 로직 최적화

### 문제 해결 과정 및 처리
- 다양한 입력 처리: 테스트 케이스 기반 구현
- `count_view_unit`: 조망 계산 로직 적용
- 에러 처리 및 입력 유효성 검사 로직 강화

### 성과 및 결과
- 알고리즘 및 데이터 구조 이해 증진
- 코드 최적화 능력 향상
- 알고리즘 대회 및 문제 해결 플랫폼 활용 가능성 증가

### 해결된 문제 및 이슈
- 스트림 입력 관리: 데이터 구조 적절히 선택
- 성능 저하 방지: 다양한 시도 및 수정 작업 진행

### 결론
- 알고리즘 및 데이터 구조 활용 문제 해결 기초 다짐
- 코드 작성 및 최적화에 중점 두며 실질적 문제 해결 목표

### 코드 기여 요약
- **문단속 및 문자열 처리**: 오류 체크 및 공백 확인 로직 추가
- **DFS 및 BFS 사용**: 그래프 최장 경로 및 물 분배 계산 로직 구현
- **트리 문제 해결**: 이진 트리 후위 순회 및 단절점 문제 접근
- **성능 개선 시도**: 재귀 깊이 제한, 노드 방문 최적화 적용
- **에러 핸들링 및 테스트 케이스**: 입력 값 검증, 다양한 케이스 테스트
- **추가 기능**: 소수 및 조합 생성 알고리즘 구현

### 프로젝트 특징
- 다양한 알고리즘 문제 포괄적으로 다룸

- 반복적 접근법 및 효율적 자료구조 사용을 통한 성과 향상
