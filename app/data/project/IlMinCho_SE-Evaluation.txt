Summary:
**프로젝트 개요**  
- 검색 모델 평가를 위한 코드  
- 다양한 검색 알고리즘(QL, BM25, DPR) 성능 비교 및 분석

**주요 기능 및 구현 세부사항**  
1. **파일 입력 및 데이터 처리**  
   - 검색 알고리즘 평가 결과 읽기 및 데이터 처리  
   - 평균 정밀도(AP) 계산, 데이터프레임 정리  

2. **평가 지표 계산**  
   - NDCG@20, MRR, P@10, R@10, F1@10 등 다양한 지표 계산  
   - 정밀도-재현율 곡선 생성으로 성능 비교  

3. **아웃풋 생성**  
   - 평가 결과 출력 파일 저장  
   - 성능 지표를 통한 종합 분석 제공  

4. **문제 및 해결**  
   - 파일 읽기 및 데이터 처리 시 예외 처리 구현  
   - 부동소수점 정밀도 문제 관리 위한 코드 추가  

5. **결과 시각화**  
   - Matplotlib로 성능 비교 그래프 생성  

**해결 방법 및 개발 과정**  
- 데이터 처리 중 발생할 수 있는 예외 처리 코드 추가  
- 부동소수점 문제를 고려한 자료형 관리  
- 최종 결과를 시각적으로 представление하기 위해 추가 컴포넌트 구현  

**코드 기여 요약**  
- 파일 입력, 데이터 처리 및 평가 지표 계산 부분 구현  
- 예외 처리 및 데이터 형식 정리 코드 작성  
- Matplotlib를 사용한 시각화 그래프 개발  
- 결과적으로, 모델의 성능을 명확히 비교할 수 있는 자료 제공  
- 각 검색 알고리즘의 효과적인 사용 통찰 제공  

이 프로젝트를 통해 AI 및 머신러닝 기술에 기여하고, 검색 시스템의 성능 최적화 지원.
