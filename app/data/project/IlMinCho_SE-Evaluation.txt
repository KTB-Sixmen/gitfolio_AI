### 주요 기능 및 작업 내용:
1. **파일 읽기 및 데이터 추출**:  
   - 모델 성능 지표(AP) 추출.

2. **데이터 포맷팅**:  
   - 비교를 위한 데이터 정리.
   - 데이터프레임 변환 구현.

3. **정밀도-재현율 곡선 시각화**:  
   - Matplotlib 활용.
   - 각 모델 성능 비교 시각화.

4. **NDCG 및 기타 평가 메트릭**:  
   - ndcg20 및 eval 함수로 NDCG, MRR, P@k, R@k 계산.
   - 통계치 계산 및 파일 저장.

5. **결과 리포팅**:  
   - 성능 지표를 파일에 기록.
   - 질의별 평가 결과 및 전체 성능 요약 출력.

### 이슈 발견 및 해결 방법:
- **성능 비교 구조 제공**:  
   - 모델 간 성능 비교 위한 체계 확보.
  
- **예외 처리 로직**:  
   - 평가 과정에서 발생할 수 있는 에러 처리 구현.

- **검증 로직 활용**:  
   - 데이터 처리 중 오류(예: 0 나누기) 방지.
