Summary:
### 프로젝트 개요: ReBook_BE

- **주제**: 클라우드 기반 중고 전공 서적 거래 플랫폼
- **대상**: 대학 재학생 및 졸업생

### 목표
- 편리한 중고 거래 환경 제공
- 신뢰성 높은 거래 플랫폼 구축

### 기술 스택
- **Frontend**: React, Vite
- **Backend**: Java, Spring Boot, Spring Security, Redis, Querydsl, STOMP, Netflix Eureka
- **AI/ML**: Fast API, PyTorch, Pandas, KcELECTRA
- **Infra**: Docker, AWS, Ansible, Terraform, Prometheus, Grafana, Jenkins
- **Collaborative**: Notion, Figma, Github

### 주요 기능
1. **회원 및 인증 관리**
   - 소셜 로그인, 이메일 인증
   - 마이페이지 관리

2. **상품 관리**
   - 등록, 수정, 삭제, 이미지 관리
   - 필터링, 검색 기능

3. **채팅 기능**
   - 실시간 1:1 채팅
   - AI 모듈로 사기 경고

### 트러블 슈팅
1. **쿼리 파라미터 가독성 문제**: DTO 사용 및 Querydsl 동적 쿼리 생성 적용.
2. **페이지네이션 성능 개선**: 커서 기반 페이지네이션 도입, 98.68% 성능 향상 (151ms → 2ms).
3. **파일 업로드 에러**: Nginx 및 application.yml 설정 조정으로 해결.

### 성과
- 긍정적 사용자 피드백
- 안정성 및 가독성 개선으로 사용자 경험 향상

### 개인 기여 및 해결 과정
- **회원 관리**: 소셜 로그인 및 이메일 인증 기능 구현.
- **상품 관리**: 상품 등록/수정 로직에 대한 DTO 설계 및 구현.
- **페이지네이션 성능 개선**: 커서 기반 페이지네이션 설계를 통한 성능 최적화.
- **문서화**: README.md 문서 업데이트 및 개발 가이드 제공.

개발 중 발생한 여러 문제들을 해결하기 위해 구체적인 기술적 접근 방식을 사용하였고, 결과적으로 사용자 경험을 크게 향상시킨 점이 notable accomplishments.
