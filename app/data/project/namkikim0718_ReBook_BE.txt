### 프로젝트 개요: ReBook_BE

**주제**: 클라우드 기반 중고 전공 서적 거래 플랫폼  
**대상**: 대학 재학생 및 졸업생  
**목표**: 신뢰성 높은 전공서적 중고 거래 환경 제공  

### 기술 스택
- **Frontend**: React, Vite
- **Backend**: Java, Spring Boot, Spring Security
- **데이터 저장소**: Redis
- **API 통신**: STOMP, FastAPI
- **AI/ML**: PyTorch, Pandas, KcELECTRA
- **Infra**: Docker, AWS
- **협업 도구**: Notion, Figma, GitHub

### 주요 기능
1. **회원 및 인증 관리**: 소셜 로그인, 이메일 인증
2. **상품 관리**: 상품 등록/수정/삭제, 검색
3. **챗 기능**: 1:1 채팅, AI 기반 사기 메시지 경고
4. **페이지네이션**: 커서 기반 적용

### 개발 및 아키텍쳐
- **서버 아키텍쳐**: Docker 및 AWS 기반 클라우드 설계
- **쿼리 처리**: Querydsl로 동적 쿼리 생성 
- **파일 관리**: S3 통한 이미지 파일 관리

### 트러블슈팅
1. **쿼리 가독성 저하**: DTO 사용하여 @RequestParam 대신 @ModelAttribute로 개선
2. **페이지네이션 문제**: 커서 기반 페이지네이션 적용, 성능 98.68% 개선
3. **파일 업로드 에러**: Nginx 및 application.yml 수정

### 추가 개선 사항
- **회원 정보 관리**: 작성한 글 조회 기능 추가
- **DTO 및 코드 정리**: 상품 관련 DTO 및 에러 코드 정리

이 프로젝트는 중고 서적 거래를 위한 안전하고 효율적인 플랫폼을 제공하고, 사용자 편의성을 극대화하였습니다. 

### 코드 기여 요약
- **회원 인증 관리**: 소셜 로그인 및 이메일 인증 로직 구현
- **상품 관리 기능**: 상품 등록 및 검색 필터 기능 개발
- **채팅 기능**: 1:1 채팅 모듈 개발 및 AI 경고 시스템 구현
- **트러블슈팅**: 페이지네이션 향상 및 이미지 업로드 문제 해결

프로젝트에서 발생한 문제들은 적절히 해결하였고, 이러한 과정에서 사용자의 요구에 빠르게 대응할 수 있는 안정된 구조를 구축하였습니다.
