Summary:
### 프로젝트 개요
- 웹 애플리케이션 `ReBook`: 제품 등록, 정보 관리, 채팅 기능 제공.

### 주요 기능 및 작업
1. **회원 관리 시스템**
   - 사용자 등록 및 로그인 구현.
   - JWT 인증 로직 추가 및 리팩토링.

2. **제품 관리 시스템**
   - **제품 등록 및 관리**: 
     - S3 이미지 저장 기능 추가.
     - 중복 파일명 생성 로직 구현.
   - **검색 및 필터링**:
     - QueryDSL을 통한 동적 검색 기능 구현.
     - 커서 기반 페이지네이션 변경으로 성능 개선.

3. **채팅 시스템**
   - WebSocket을 이용한 실시간 메시지 전송 기능 구현.
   - Redis를 활용한 메시지 처리.

### 문제 및 해결책
- **토큰 인증 문제**: JWT 검증 로직 추가.
- **에러 핸들링**: GlobalExceptionHandler 설정으로 일관된 오류 처리.
- **CORS 설정**: 크로스 도메인 요청 허용하여 API 접근성 개선.

### 결과
- 사용자 관리와 제품 등록, 채팅 기능이 통합된 사용자 친화적 플랫폼 구축.
- 시스템의 확장성 및 유지 보수성을 고려한 클린 아키텍처 적용.
