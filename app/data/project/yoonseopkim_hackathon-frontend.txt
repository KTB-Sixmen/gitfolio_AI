Summary:
**프로젝트 개요:**
- React 기반의 동화 생성 웹 애플리케이션.
- 키워드와 메시지를 기반으로 동화 창작 및 각색.
- 최종 결과물은 책 형태로 표시.

**주요 기능 및 작업 내용:**

1. **이야기 생성**
   - API 연동: Axios 사용.
   - JSON 변환 및 데이터 로깅으로 오류 해결.

2. **이야기 각색**
   - 사용자 입력을 통한 각색 기능 구현.
   - 하드코딩된 URL 수정 및 환경 변수 사용.

3. **책 페이지 회전**
   - react-pageflip 라이브러리를 활용한 페이지 전환 구현.

4. **로딩 스피너**
   - GSAP을 사용하여 애니메이션 효과 구현.

5. **리뷰 시스템**
   - 별점 시스템 개발 및 UI 디자인 개선.

6. **슬라이드 갤러리**
   - Slick carousel을 사용하여 이미지 슬라이더 구현.

7. **UI/UX 개선**
   - CSS를 통해 레이아웃 조정, 반응형 디자인 적용.

8. **라우팅 및 네비게이션**
   - React Router로 SPA 구조 내비게이션 구현.

9. **CI/CD 설정**
   - GitHub Actions로 Netlify 자동 배포 설정.

**문제 및 해결:**
- 데이터 형식 변화로 API 오류 발생 → JSON 변환 후 로깅으로 해결.
- CORS 문제 → 서버 측 설정으로 해결.

**결과:**
- 직관적인 사용자 경험 제공.
- 부모와 자녀가 함께 참여 가능하도록 설계.
- 테스트 코드 및 상태 관리 포함.
