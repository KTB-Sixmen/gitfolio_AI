- React 기반 동화 생성기 웹 애플리케이션  
- 사용자 맞춤형 동화 생성 및 각색 기능 제공

주요 기능 및 작업 내용:

1. **동화 생성 및 각색**:  
   - 사용자 키워드로 동화 생성 기능 구현  
   - POST 요청으로 동화 ID 반환 처리  

2. **페이지 라우팅**:  
   - `react-router-dom` 사용, 다양한 페이지 내비게이션 구현  
   - 동적 경로로 동화 내용 표시  

3. **페이지 플립 인터페이스**:  
   - `react-pageflip` 라이브러리 기반 페이지 전환 효과 제공  
   - 동화 내용과 이미지 연동  

4. **API 연동**:  
   - `axios`를 통한 외부 API (JSONPlaceholder) 이미지 불러오기 구현  
   - 상태 관리 훅(`useState`, `useEffect`)로 데이터 관리  

5. **사용자 인터페이스**:  
   - CSS 및 React 컴포넌트 조합으로 UI 설계  
   - 로딩 애니메이션으로 사용자 피드백 제공  

6. **리뷰 시스템**:  
   - 사용자 별점 리뷰 기능 추가  

7. **로딩 애니메이션**:  
   - GSAP 라이브러리로 로딩 애니메이션 구현

- **페이지 상태 관리**:
