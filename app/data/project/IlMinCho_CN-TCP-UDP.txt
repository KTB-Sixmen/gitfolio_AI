Summary:
프로젝트 개요:
- **프로젝트 이름**: CN-TCP-UDP
- **기능**: TCP 및 UDP 클라이언트/서버 프로그램 개발
    - TCP 클라이언트/서버 (2개)
    - 신뢰성 있는 UDP 클라이언트/서버 (2개)
    - 비신뢰성 UDP 클라이언트/서버 (2개)
- **참조 자료**: Python 소켓 프로그래밍 링크 제공

주요 기능 및 작업 내용:
1. **UDP 클라이언트** (`udp_client`):
   - 파일 각 줄 읽기 및 서버 전송
   - 응답 오류 처리 및 재전송 메커니즘 구현
   - 타임아웃 관리 및 상태 코드에 따른 결과 출력

2. **UDP 서버** (`udp_server`):
   - 클라이언트 요청 처리 및 수학적 연산 수행
   - 패킷 손실 시뮬레이션 구현
   - 오류 코드 반환 및 정상 요청에 대한 응답 처리

3. **TCP 클라이언트** (`tcp_client`):
   - 요청 서버 전송; 신뢰성 있는 통신 구현
   - UDP와 유사한 요청 처리 방식 사용

4. **TCP 서버** (`tcp_server`):
   - 클라이언트 요청 수신 및 처리
   - 입력 형식 검증 및 오류 처리

문제 및 해결 방법:
- **시간 초과 문제**: UDP의 비신뢰성으로 인한 요청 시간 초과 관리.
  - → 재전송 매커니즘으로 해결.
  
- **패킷 손실 문제**: 랜덤 패킷 드롭 기능 구현.
  - → 신뢰할 수 없는 통신 재현.

결과:
- 안정적인 소켓 프로그래밍 이해.
- TCP와 UDP 프로토콜 차별성 경험.
- 클라이언트-서버 모델 관련 심화 학습.

개발 프로세스 및 문제 해결:
- 안정성을 위한 예외 처리 기법 적용.
- 요구 사항에 맞춘 클라이언트 및 서버 기능 구현.
