Summary:
### 프로젝트 개요
- UDP 및 TCP 프로토콜을 이용한 클라이언트-서버 통신 구현.
- 신뢰성 있는 UDP, 비신뢰성 UDP, TCP 클라이언트 및 서버 포함.

### 주요 기능
1. **UDP 클라이언트 (신뢰성/비신뢰성)** 
   - 요청 파일에서 데이터 전송.
   - 서버 응답 수신 및 상태 코드 출력.
   - 비신뢰성 UDP 클라이언트 재전송 메커니즘 구현.
  
2. **TCP 클라이언트**
   - 요청 파일 데이터 서버 전송.
   - 서버 응답 및 결과 출력.
  
3. **UDP 서버 (신뢰성/비신뢰성)**
   - 계산 요청 수신 후 결과 반환.
   - 비신뢰성 UDP 서버 패킷 손실 시뮬레이션.
   - 오류 코드 반환(올바르지 않은 형식 및 피연산자).

4. **TCP 서버**
   - 연결 수신 및 요청에 따른 응답 반환.
   - 잘못된 요청 형식에 대한 에러 코드 반환.

### 에러 처리
- 입력 오류 및 연결 문제 메시지 구현.
- 비어 있는 파일 및 부족한 라인 처리 오류 메시지 제공.
- 서버: 잘못된 데이터에 에러 코드(620, 630) 반환.

### 결론
- 다양한 소켓 프로그래밍 페러다임 사용.
- UDP: 패킷 손실 관리, TCP: 안정적 연결 제공.
- 신뢰성 있는 커뮤니케이션 모델 구축 사례.

### 프로젝트 요약
