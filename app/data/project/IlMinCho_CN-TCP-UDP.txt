Summary:
프로젝트 개요:
- 클라이언트-서버 아키텍처 기반의 소켓 프로그래밍
- TCP 및 UDP 통신으로 기본 수학 연산 처리

주요 기능:
1. **TCP 및 UDP 클라이언트-서버 구현**
   - TCP: 신뢰성 있는 연결로 요청 및 결과 처리
   - UDP: 패킷 손실 시뮬레이션, 비연결형 전송

2. **수학 연산 처리**
   - +, -, *, / 연산 수행 및 결과 반환
   - 잘못된 입력 시 오류 코드 전달

3. **오류 처리 및 재전송**
   - UDP 클라이언트 타임아웃 발생 시 재전송
   - 서버의 패킷 드롭 기능으로 에러 핸들링 검증

4. **파일 입력**
   - 형식에 맞는 파일에서 최대 7개 요청 읽기

5. **사용자 친화적인 인터페이스**
   - 입력 형식 안내 메시지 출력

6. **예외 처리**
   - 파일 읽기, 소켓 통신 등 다양한 예외 처리

문제점 및 해결 방안:
- 데이터 형식 오류 및 수치 변환 실패에 대한 예외 처리 메커니즘 구축
- UDP 패킷 드롭 시뮬레이션으로 클라이언트의 에러 핸들링 개선

성과:
- TCP, UDP 프로토콜 이해도 향상
- 실시간 통신 시스템에서 데이터 전송 신뢰성 및 효율성 습득
- 클라이언트-서버 통신 처리 방식 경험
