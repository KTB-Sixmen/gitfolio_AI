Summary:
프로젝트 개요:
- TCP 및 UDP 프로토콜 기반의 클라이언트-서버 계산기 애플리케이션 구현.
- 주요 기능: 신뢰성 있는/없는 통신, 수학 연산 처리, 에러 관리.

작업한 주요 기능:
1. **프로토콜 구성**:
   - TCP 클라이언트/서버 설정 완료.
   - 신뢰성 있는 UDP 클라이언트/서버 기능 구현, 패킷 재전송 로직 추가.
   - 비신뢰성 UDP 설정, 패킷 드롭 기능 실험.

2. **수학 연산**:
   - 덧셈, 뺄셈, 곱셈, 나눗셈 처리 로직 구현.
   - 에러 코드 (200, 620, 630) 반환 로직 추가.

3. **에러 처리**:
   - 타임아웃 및 포맷 오류 발생 시 예외 처리 로직 구현.

4. **사용법 구현**:
   - 파일 입력 기능과 응답 출력 콘솔 구현.

문제 해결:
- 타임아웃 문제: 소켓 연결 시 적절한 예외 처리 추가.
- 포맷 오류: 입력 형식 검증 로직 보강.

결과:
- 프로젝트 통해 TCP/UDP의 차이와 다양한 에러 처리 방식 이해.
- 네트워크 프로그래밍에 대한 실습과 이해 증진.

프로젝트 요약:
1. **프로젝트 명칭**: CN-TCP-UDP
2. **주요 기능**: 
   - TCP 클라이언트/서버 (2개)
   - 신뢰성 UDP 클라이언트/서버 (2개)
   - 비신뢰성 UDP 클라이언트/서버 (2개)
3. **문서화**: README.md로 프로젝트 설명, Python 소켓 프로그래밍 링크 제공.
4. **변경 사항**: README 파일 정리 및 기능 명확화.

이 프로젝트는 Python을 통한 네트워크 프로그래밍 학습의 중요성을 강조한 것.
