### 프로젝트 요약

**프로젝트 목표**: 카카오 API와 머신러닝을 이용한 음식점 추천 시스템 구축

**주요 작업 내용**:

1. **AI 통신 및 추천 시스템**:
   - 리뷰 크롤링 최적화: 로딩 시간 개선
   - 사용자 위치 및 키워드 기반 추천 제공.

2. **데이터 수집 및 전처리**:
   - 카카오 API를 통해 주소 변환 및 데이터 크롤링.
   - 데이터 정제 및 전처리 과정 추진.

3. **리뷰 분석 및 모델 학습**:
   - BERT 및 LSTM 모델을 통한 감정 분석 구현.
   - 여러 모델을 앙상블하여 성능 향상.

4. **클러스터링 및 시각화**:
   - 리뷰 데이터를 클러스터링하여 주요 키워드 시각화.
   - 데이터 분석 결과를 통해 추천 품질 개선.

5. **CI/CD**:
   - Docker 및 CI/CD 적용하여 배포 효율화.

### 문제 해결 및 개선 사항
- **크롤링 성능 문제**: 병렬 크롤링 도입으로 속도 개선 (5분 → 1분).
- **모델 성능 향상**: 앙상블 기법 사용으로 추천 정확도 강화.
- **API 리팩토링**: 데이터 반환 방식 개선 및 클러스터링 결과 추가.

### 결과
- 사용자 친화적인 추천 인터페이스 개발.
- 고객 경험 향상 및 데이터 수집의 신뢰성 증가.

### 전문 기술적 요소
- FastAPI를 통한 API 서비스 구축.
- 자연어 처리 기법을 활용한 리뷰 텍스트 처리.
- 클러스터링과 모델 앙상블을 통한 성능 최적화 추가.

이 프로젝트는 데이터 사이언스와 소프트웨어 개발의 융합적 접근 방식의 좋은 사례로, 개인화된 선택을 통한 사용자 경험을 개선하는 데 중점을 두었습니다.
