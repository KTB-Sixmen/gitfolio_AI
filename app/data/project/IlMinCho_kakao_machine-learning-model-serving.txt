### 프로젝트 개요
이 프로젝트는 Kakao 기술에 기반한 머신러닝 모델 서빙 시스템으로, 레스토랑 리뷰 데이터를 처리하고 추천 기능을 제공하는 API 개발 목표.

### 주요 기능 및 담당 부분

1. **리뷰 데이터 크롤링**
   - **문제**: 페이지 로딩 및 동적 요소로 인해 크롤링 오류 발생.
   - **해결**: Selenium 활용하여 문제 해결.
   - **결과**: 안정적으로 리뷰 데이터 수집.

2. **AI 기반 추천 시스템**
   - **문제**: 초기 모델 성능 미비.
   - **해결**: 데이터 전처리 및 토큰화 추가.
   - **결과**: 추천 정확도 향상.

3. **집합적 모델 적용**
   - **BI-Sesterom 및 KcELECTRA 모델 사용**.
   - **결과**: 리뷰 정확한 분류 및 신뢰도 제공.

4. **리뷰 시각화 UI**
   - 사용자 피드백 반영하여 UI/UX 개선.
   - **결과**: 사용자 친화적 인터페이스 제공.

5. **사용자 인증 및 권한 관리**
   - Spring Security로 인증 시스템 구현.
   - **결과**: 안전한 사용자 데이터 관리.

### 문제 및 해결
- **크롤링 성능 개선**: 병렬 크롤링 기능 추가.
- **모델 성능 향상**: 앙상블 기법 활용.
- **UI/UX 최적화**: 피드백 기반 개선.

### 결과
- 최종 사용자에게 레스토랑 추천 시스템 운영.
- 관리자 데이터 인사이트 강화.
- 데이터 수집 및 처리 속도 상당히 개선.

### 프로젝트 요약
- **목표**: 실시간 데이터 수집 및 머신러닝 기반 레스토랑 추천.
- 다양한 대해: 크롤링, 데이터 전처리, 추천 모델링, API 구현 포함.
- 성공적으로 사용자 맞춤형 서비스 및 운영 효율성 개선.

이 프로젝트는 데이터 처리 및 머신러닝 모델 관리에 대한 전문가적인 접근으로 성과를 이루었습니다.
