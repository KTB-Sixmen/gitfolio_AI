Summary:
### 프로젝트 개요
- 카카오 머신러닝 모델 서빙 시스템.
- 음식 레스토랑 추천 및 리뷰 AI 처리 웹 애플리케이션.

### 주요 기능별 작업 내역

1. **AI 추천 시스템**
   - 사용자의 위치 데이터와 키워드 기반 추천.
   - 리뷰 데이터 크롤링 및 분석.
   - **구현한 부분**: BERT 및 BiLSTM 모델로 리뷰 점수 예측.

2. **리뷰 크롤링**
   - 카카오 맵 API 활용하여 리뷰 자동 수집.
   - **해결한 이슈**: 크롤링 속도와 데이터 누락 문제 개선.
   - **개선 내용**: 크롤링 로직 최적화 및 pageable 크롤링으로 문제 수정.

3. **RESTful API 구축**
   - FastAPI를 이용한 다양한 엔드포인트 구현.
   - **구현한 부분**: 레스토랑 추천 및 리뷰 분석 API.

4. **데이터 전처리 및 모델링**
   - 수집된 리뷰 데이터 전처리 및 모델 학습.
   - **구현한 부분**: 데이터 클리닝 및 레이블링 process 담당.

5. **유저 관리 및 보안**
   - JWT 인증 및 사용자 권한 관리 구현.
   - 관리자와 사용자 인터페이스 분리.

### 문제 해결 및 결과
- **버그**: 로딩 시간으로 인한 리뷰 데이터 누락.
  - 해결: 크롤링 로직 최적화.
  
- **모델 성능 저하**: 초기 정확도 낮음.
  - 해결: 데이터량 증가 및 하이퍼파라미터 조정.

- 긍정적인 사용자 피드백을 통한 유용성 인정.
- 모델 성능 향상 및 데이터 수집 자동화로 운영 효율성 증대.

### 최종 결과
- 사용자 맞춤형 추천 시스템 구축 완료.
- 지속적인 개선을 통한 성능 및 기능확장 기반 마련.

### 추가 작업 요약

1. **숙소 크롤링 기능 구현**: 수정 후 병렬 크롤링 및 중복 문제 해결.
2. **키워드 기반 추천 시스템 개발**: 리뷰에 키워드 가중치 적용.
3. **모델 앙상블 기법 API 구축**: BiLSTM 및 KcELECTRA 모델 통합.

### 프로젝트 완성도
- FastAPI 기반으로 사용자 경험 향상.
- 다양한 최신 기술 스택 활용으로 품질 높은 시스템 구축.
