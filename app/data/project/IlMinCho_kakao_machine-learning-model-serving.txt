Summary:
### 프로젝트 개요
- 카카오 API 및 머신러닝 기반 음식점 리뷰 분석 및 추천 시스템.
- 사용자가 제공한 위치와 키워드로 음식점 추천 및 관련 리뷰 제공.

### 주요 기능 및 기여
1. **모델 개발**:
   - **KcELECTRA 및 BiLSTM 모델**: 감성 분석을 위한 두 가지 모델 개발 및 성능 향상.
   - **모델 앙상블**: 두 모델 결과 융합하여 최종 추천 점수 산출.

2. **데이터 전처리**:
   - 리뷰 데이터 정제 및 불용어 처리.
   - NaN 값 처리 로직 추가, 데이터 유효성 검사 시행.

3. **추천 시스템**:
   - 리뷰 및 AI 예측 기반 음식점 랭킹 생성.
   - 키워드 기반 가중치 부여로 추천 방법 개선.

4. **API 서버 구축**:
   - FastAPI를 통해 AI 모델과 통신하는 API 엔드포인트 구현.
   - 데이터 전처리 파이프라인 설계 및 구현.

### 주요 이슈 및 해결 사항
- **모델 성능 개선**: 하이퍼파라미터 튜닝 및 다양한 시험 데이터를 통한 성능 검증.
- **크롤링 안정성**: Selenium의 `WebDriverWait` 사용으로 리뷰 로딩 문제 해결.
- **데이터 전처리 문제**: 결측치 처리 및 데이터 일관성 유지.

### 성과
- **정확한 추천 제공**: 높은 정확도로 음식점 추천 및 사용자 요구 충족.
- **데이터 수집 자동화**: 카카오 맵에서 반복 작업 감소, 안정적인 데이터 수집.
- **유연한 구조**: FastAPI와 Spring Boot 활용, 쉽게 유지 관리 및 확장 가능한 구조.

이 프로젝트는 실제 AI 기반 추천 시스템을 구현하는 데 중요한 기여를 했으며, 사용자의 품질 높은 선택을 지원함.
