Summary:
## 프로젝트 개요
- 머신러닝 기반 레스토랑 추천 웹 애플리케이션.
- API를 통해 사용자에게 맞춤형 추천 서비스 제공.

### 주요 기능
1. **레스토랑 추천 API**:
   - 사용자 위치 및 키워드 기반 추천.
   - BERT, BiLSTM 모델로 리뷰 분석 및 점수화.
   - 클러스터링된 리뷰 키워드 제공.
  
2. **리뷰 크롤링**:
   - KakaoMap API 이용하여 리뷰 데이터 수집.
   - Selenium으로 데이터 수집 자동화.

3. **Q&A 시스템**:
   - 사용자 질문 관리 기능.
   - 관리자가 질문 답변 가능.

4. **사용자 관리**:
   - JWT를 통한 사용자 인증 및 권한 관리.

### 내가 작업한 부분 
1. **리뷰 크롤링 최적화**:
   - Selenium 사용하여 크롤링 안정화.
   - 중복 리뷰 데이터 문제 해결 및 85,000개 리뷰 수집 완료.

2. **모델 성능 개선**:
   - KcELECTRA로 모델 변경 및 데이터 레이블링 수정.
   - BiLSTM 모델 사용으로 리뷰 점수 예측 및 추천 향상.
  
3. **클러스터링 알고리즘 적용**:
   - HDBSCAN을 통해 리뷰 클러스터링 및 키워드 추출 개선.
  
4. **API 엔드포인트 구축**:
   - AI 서버와 연동하여 데이터 처리 파이프라인 구축.

5. **보안 및 인증 관리**:
   - JWT 구현으로 인증 체계 강화.
   - Spring Security를 통해 사용자 정보 보호.

### 문제 및 해결 방안
- **크롤링 속도 문제**: 
   - 병렬 처리로 속도 5분 → 1분 단축.
  
- **모델 정확도 문제**:
   - 하이퍼파라미터 튜닝으로 성능 개선.

- **보안 취약점**:
   - JWT로 인증 강화, 취약점 제거.

### 성과
- 사용자 피드백 긍정적, 추천 시스템의 유용성 확인.
- 구조적 개선으로 코드 모듈화 및 유지 보수 용이.
- CI/CD 파이프라인 구축으로 안정적 배포 실현.

## 결론
- 머신러닝, 데이터 전처리, API 구축 통합.
- 사용자 맞춤형 추천 시스템 제공의 실질적 성과 달성.
