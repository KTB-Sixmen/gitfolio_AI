Summary:
### 프로젝트 개요
- 머신러닝 기반 음식점 추천 및 리뷰 분석 서비스.
- 사용자 입력에 따른 추천 기능과 리뷰 감정 분석 제공.
- Python, Java 사용; Docker로 컨테이너화.

### 주요 기능 및 본인 기여
1. **리뷰 분석 구현**:
   - KcELECTRA 및 BiLSTM 모델 활용.
   - 긍정/부정 점수 계산 및 리뷰 랭킹 생성.
   
   **문제**: 초기 모델 정확도 낮음.
   **해결**: 재전처리 및 가중치 조정.
   **결과**: 감성 분석 성능 상승.

2. **HDBSCAN 클러스터링 적용**:
   - 리뷰 클러스터링 기법 도입.
   
   **문제**: 응답 시간 지연.
   **해결**: API 리팩토링과 크롤링 양 조절.
   **결과**: 응답 시간 1~3분으로 단축.

3. **키워드 기반 추천 시스템**:
   - 사용자 키워드 입력을 통한 추천 기능 구현.
   
   **문제**: 추천 정확도와 키워드 품질 간의 딜레마.
   **해결**: 키워드 평가 알고리즘 개선.
   **결과**: 사용자 맞춤 추천 강화.

4. **AI 모델 API 엔드포인트 구축**:
   - 데이터 전처리 파이프라인 구성 및 API 구현.
   
   **문제**: API 통신 불안정.
   **해결**: 예외 처리 및 재시도 로직 구현.
   **결과**: API 안정성 및 사용자 경험 향상.

5. **모델 성능 개선**:
   - KoBERT 모델 프리트레이닝, 레이블링 수정.
   
   **문제**: F1 스코어 낮음.
   **해결**: 데이터 품질 향상.
   **결과**: F1 스코어 71로 개선.

### 결론
- 프로젝트의 핵심은 리뷰 데이터의 효과적 크롤링 및 분석.
- 머신러닝 모델 성능 향상으로 신뢰성 있는 추천 시스템 구현.
- 향후 모델 지속 개선 및 다양한 데이터源 통합 예정.
