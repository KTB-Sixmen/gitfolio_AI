Summary:
### 프로젝트 개요
- **목적**: 음식점 추천 시스템 구축 및 리뷰 감정 분석.
- **기술 스택**: Python, FastAPI, Java, Spring Boot, KcELECTRA, BiLSTM, Selenium, BeautifulSoup.

### 주요 기능 및 기여
1. **감정 분석 모델 개발**:
   - KcELECTRA 및 BiLSTM 앙상블 기법 활용하여 리뷰의 감정을 분류.
   - 모델 변경 및 F1 점수 개선 작업 수행.

2. **추천 시스템 강화**:
   - 리뷰 키워드 기반으로 식당 추천 점수 강화.
   - 상위/하위 리뷰 클러스터링 기능 구현.

3. **API 엔드포인트 구축**:
   - AI 서버와 연동되는 API 개발하여 신속한 감정 분석 지원.
   - 사용자 요청에 따른 추천 식당 리스트 반환 로직 작성.

4. **데이터 전처리 및 분석**:
   - 85,000개 리뷰 수집 후 전처리 및 레이블링 진행.
   - 텍스트 데이터 정제 및 형태소 분석 기법 적용.

5. **모델 성능 최적화**:
   - KoBERT 프리트레인 모델을 사용하여 성능 재정비.
   - 리뷰 데이터 기반으로 지속적인 모델 개선 작업 진행.

6. **이슈 해결 및 안정성 강화**:
   - 크롤링 과정에서 발생한 네트워크 오류 처리 로직 개선.
   - 중복 크롤링 이슈를 해결하고, 성능 개선을 위한 병렬 크롤링 기능 추가.

### 성과
- 사용자에게 정확한 음식점 추천 제공.
- AI 기반 리뷰 분석으로 데이터 활용성 향상.
- 웹 크롤링 최적화를 통해 성능 개선 및 안정성 확보.

프로젝트를 통해 리뷰 분석 및 추천 시스템 개선에 중점을 두어, 기술적 난제를 해결하고 실질적인 성과를 도출함.
