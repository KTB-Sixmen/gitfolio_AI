## 프로젝트 요약: Kakao Tech Bootcamp 챗봇

### 프로젝트 개요
- Kakao Tech Bootcamp에서 챗봇 애플리케이션 개발.
- 사용자와 AI 간 대화 기반의 플랫폼.

### 주요 기능
1. **프론트엔드 기술 스택**:
   - TypeScript, Node.js, Next.js, React, Tailwind CSS, Zustand
2. **챗봇 기능**:
   - 실시간 AI 응답 스트리밍 및 사용자 대화 데이터 관리.
   - 키워드에 따른 AI 추천 제공.
3. **보안 및 효율성**:
   - React Query로 서버 상태 관리 및 사용자 알림 기능 추가.
   - Next.js API Routes로 서버 사이드 로직 구현.
4. **스케줄 및 날씨 정보 기능**:
   - 날씨 정보 및 주간 예보 제공.
   - 월별 일정 확인 서비스.

### 이슈 및 해결
- **상태 관리 및 성능 병목 현상**: Zustand로 전역 상태 관리, 성능 개선.
- **실시간 데이터 처리**: API 비동기 처리 및 상태 관리 최적화.
- **UI/UX 개선**: Tailwind CSS 활용, 반응형 디자인 구현.

### 결과 및 성과
- 현대적이고 유지보수 가능한 코드 작성.
- 사용자 요구 사항에 맞춘 다양한 기능 구현.
- 팀워크, 협업 경험 강화 및 문제 해결 능력 향상.
