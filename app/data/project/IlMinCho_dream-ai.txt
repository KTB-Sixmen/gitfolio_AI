Summary:
### 프로젝트 개요
- 노년층의 꿈을 주제로 생성형 AI 이야기 및 이미지 생성 서비스.
- '꿈을 이룬 나' 주제의 교육 프로그램 및 직업 추천.

### 주요 기능
1. **스토리 생성**:
   - Elasticsearch에서 관련 문서 검색.
   - LLM으로 적합한 스토리 생성.
   - 프롬프트 단계를 통한 점진적 이야기 발전.

2. **이미지 생성**:
   - DALL-E API로 스토리 관련 이미지 생성.

3. **서버 아키텍처**:
   - FastAPI로 RESTful API 구축.
   - Sentence-BERT 모델을 통한 직업 정보 벡터화 및 검색.

### 개발 중 문제 및 해결
- **문제**: API 연동 시 엑세스 키 오류 및 HTTP 500 오류 발생.
- **해결**: 예외처리 강화 및 환경변수 관리 개선.

### 결과 및 성과
- 사용자 꿈 실현을 위한 교육 및 직업 추천 플랫폼 구축.
- 지속적인 기능 개선과 스토리 및 이미지 품질 향상.

프로젝트 요약:

   - 노년층의 이루지 못한 꿈 기반 이야기 및 직업 추천 서비스.

2. **주요 기능**:
   - 사용자 경험과 감정을 담은 스토리 생성 기능 제공.
   - 모델 업그레이드를 통해 성능 및 비용 효율성 개선.
   - 이미지 및 이야기 생성 API 정의로 프론트엔드와 통신.

3. **파일 및 수정 내역**:
   - **README.md**: 프로젝트 설명, 팀원 목록 업데이트.
   - **llm_service.py**: AI 모델 변경 및 상호작용 스토리 생성 로직 추가.
   - **ai_server.py**: 스토리 및 이미지 생성 API 엔드포인트 수정.
   - **es_vecDB_search.py**: Elasticsearch 벡터 검색 기능 개선.
   - **es_vecDB_save.py**: 데이터 저장 및 인덱스 매핑 설정 개선.

4. **기타 특징**:
   - 사용자 참여와 경험을 기반으로 한 이야기 생성.
   - 개인의 감정과 배움을 중심으로 한 방향성 유지.

- 생성형 AI 및 Elasticsearch를 활용해 개인화된 스토리 생성 서비스를 제공, 꿈과 경험에 기반한 데이터 생성 촉진.
