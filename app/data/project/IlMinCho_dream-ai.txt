Summary:
## 프로젝트 개요
- **프로젝트 명**: 드림 AI (dream-ai)
- **목적**: 생성형 AI 기술을 통해 노년층의 꿈을 실현하도록 돕는 서비스.

## 주요 기능
1. **AI 모델 개발**:
   - 기존 `gpt-4o`를 `gpt-3.5-turbo`로 변경하여 처리 성능 개선.
   - 스토리 생성 프롬프트 최적화로 사용자 경험 개선.

2. **API 설계**:
   - 이미지 생성 엔드포인트 경로 수정("/api/image" -> "/generate-image/").
   - 스토리 생성 API 구축 및 요청/응답 구조 설계.

3. **Elasticsearch 통합**:
   - 데이터 검색 기능을 통해 관련 문서 유추 및 스토리 생성 지원.
   - 벡터 검색 최적화로 사용자 입력에 대한 정확도 개선.

## 문제 해결 및 성과
- **모델 교체로 인한 성능 향상**: 
   - 보다 빠르고 정확한 응답 제공, 사용자 만족도 증가.
  
- **API 경로 변경**:
   - 서비스 접근성 및 직관성 강화, 사용자 피드백 긍정적.

- **버그 수정**:
   - API 키값 관련 이슈 해결로 보안성 강화 및 안정성 확보.
  
## 결과
- 프로젝트 전체적인 시스템 안정성 및 효율성 향상.
- 사용자 맞춤형 경험 제공으로 서비스 가치 증대.
- 노년층의 꿈 실현을 위한 향후 발전 가능성 확보.

## 팀원 및 역할
- 주요 기여: AI 모델 개발, API 설계 및 데이터 흐름 최적화.
- 협업을 통한 신뢰 구축 및 프로젝트 성공률 증가.

## 앞으로의 방향성 
- 사용자 피드백 기반으로 지속적인 모델 개선 및 기능 고도화.
