Summary:
이 프로젝트는 Node.js로 구축된 퀴즈 애플리케이션의 서버 및 프론트엔드 관련 작업을 다루고 있음. 

**프로젝트 개요:**
- Node.js와 Express를 활용하여 퀴즈 애플리케이션의 서버를 구축하고 HTML 프론트엔드를 개발한 프로젝트.
- JWT와 MongoDB, MySQL을 통해 사용자 인증 및 데이터를 관리함.

**주요 역할:**
- **기능 구현**: 
  - Express 서버 설정을 통해 REST API와 정적 파일 제공.
  - Bootstrap을 활용한 사용자 인터페이스 구현.
  - 주기적 퀴즈 생성 및 관리 기능 개발.

- **Pull Request 개선사항**:
  - 여러 기능 추가 및 수정이 포함된 PR 제출.
  - 쿠키 시간 변경 및 에러 수정으로 사용자 경험 개선.
  - 게스트 로그인 도입 및 UI 개선으로 접근성 향상.

- **커밋을 통한 변화**:
  - 기존 기능 복원 및 UI 개선으로 사용자 편의성 증대.
  - JWT 토큰 관리 방식을 변경하여 보안 강화.
  - 배치 작업의 설정을 별도로 분리하여 코드 가독성 향상.

**배운 점**:
- 사용자 인증과 데이터 처리에 대한 이해도 향상.
- 코드 리팩토링 및 테스트 케이스 추가로 품질 향상.
- 기능 개선과 에러 수정 과정을 통해 학습한 교훈.

결론적으로, 이 프로젝트는 사용자 인증 및 퀴즈 관리 기능의 안정성을 개선하며, 코드 품질과 프로젝트 관리의 중요성을 배울 수 있는 기회가 되었음.
