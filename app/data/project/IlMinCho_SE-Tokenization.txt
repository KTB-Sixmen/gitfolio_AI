Summary:
**프로젝트 개요**  
- 텍스트 처리 및 분석 코드  
- 주요 기능: 토큰화, 불용어 제거, 형태소 분석, 입출력 처리, 데이터 시각화  

### 주요 기능
1. **토큰화**  
   - 공백 기반 및 복잡한 방식 채택  
   - 웹사이트 링크, 특수 문자 처리  

2. **불용어 제거**  
   - 정해진 목록 기반 불필요한 단어 제거  

3. **형태소 분석**  
   - 포터 스테머 사용  

4. **입출력 처리**  
   - Gzip 파일 입출력 및 다양한 형식으로 결과 출력  

5. **데이터 시각화**  
   - 고유 단어 수와 총 토큰 수의 관계 그래프 생성  

### 주요 분석 결과
- 주요 단어 빈도수 분석  
- 주요 인물 및 소재와의 상관관계 추론  

### 문제점 및 해결책
- 일반 단어로 인해 분석 방해  
  - 불용어 목록 수정, 'i', 'you' 추가  

### 실제 출력
- "-tokens.txt": 처리된 토큰 리스트, 통계 정보  
- "-stats.txt": 빈도가 높은 단어 및 수량 기록  
- 고유 단어와 총 단어 수 관계 그래프 생성  

---

**개발 과정 및 문제 해결**

```
- 프로젝트 제목 'Search Engines-Tokenization'에서 'NLP-Tokenization'으로 변경  
- 텍스트 질문 포맷 수정 및 불필요 내용 삭제  
- TREC GOV2 컬렉션의 그래프 정보를 기반으로 'Sense and Sensibility' 그래프 생성  
- 'Sense and Sensibility'의 빈번한 단어 분석, 특정 단어 불용어 지적  
- Heaps 법칙 확인, 토큰 수 증가 시 고유 토큰 수 증가 경향 분석  
```

**개인 구현 부분**
- 불용어 목록 수정 및 주요 단어 분석 과정 주도  
- 데이터 시각화 기능 구현, 그래프 생성 및 통계 정보 제공  
- Heaps 법칙 분석 관련 데이터 정리 및 결과 도출  

이 프로젝트는 자연어 처리 기술을 활용한 문학 작품 분석에 초점. 데이터 시각화 및 텍스트 분석 방법론 탐구.
