Summary:
이 프로젝트는 8-퍼즐 문제 해결을 위한 탐색 알고리즘 구현입니다. 주요 특징은 다음과 같습니다.

### 주요 기능
1. **퍼즐 보드 클래스 (`EightPuzzleBoard`)**:
   - 상태 구현: 타일 이동 메서드 포함.
   - 위치 관리: x, y 좌표로 유효한 이동 상태 생성.

2. **탐색 알고리즘**:
   - **BFS**: 최단 경로 탐색.
   - **균일 비용 탐색**: 상태 전이 비용 고려.
   - **탐욕적 탐색**: 다양한 휴리스틱을 통한 상태 평가.
   - **A* 탐색**: 휴리스틱과 비용 결합.

3. **결과 출력**:
   - 알고리즘 결과를 테이블 형식으로 정리.

### 문제 및 해결
- **휴리스틱 문제**: Greedy Search에서 논리적 오류 발생.
- **디버깅**: 상태 전이 비용 재검토 및 수정.

### 최종 결과
- 다양한 알고리즘을 통한 8-퍼즐 문제 해결 제시.
- 각 알고리즘의 효율성 비교 가능.
- AI 모델 기초로 활용 가능.


하신 작업에 대한 요약:

``` 
1. **모델 개발**: A* 알고리즘 및 각 탐색 알고리즘을 구현했습니다.

4. **성능 비교**: 알고리즘 성능 지표를 체계적으로 정리하여 사용자 친화적 결과 도출.
```
