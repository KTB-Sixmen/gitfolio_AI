## 프로젝트 요약: AI-8Puzzle

### 프로젝트 개요
- **목표**: 8퍼즐 문제 해결을 위한 다양한 알고리즘 구현.
- **사용된 알고리즘**: 
  - A* (astar-h1, astar-h2, astar-h3)
  - 너비 우선 탐색(BFS)
  - 탐욕 알고리즘 (greedy-h1, greedy-h2, greedy-h3)
  - 균일 비용 탐색(ucost)

### 주요 기능
- **solve_puzzle 함수**: 알고리즘 선택 후 문제 해결 시작.
- **결과 정보**: 경로, 경로 비용, 생성된 상태 수, 탐색된 상태 수 포함.

### 주요 클래스
- **퍼즐 상태 클래스**: EightPuzzleBoard, 탐색 알고리즘 클래스(BreadthFirstSolver 등).
- **우선순위 큐/FIFO 큐 클래스**: 상태 관리.

### 문제 및 해결 방안
- **버그 발생**: Greedy 알고리즘에서 특정 휴리스틱(h3) 계산 오류.
- **해결 방안**: 휴리스틱 검토 및 수정. 추가 테스트 필요.

### 업데이트 내역
- **문서화**: README.md 수정으로 알고리즘 성능 표 추가.
- **성능 비교**: 각 알고리즘의 길이, 비용, 탐색 노드 수, 확장 노드 수 정보 명시.

### 성과 및 결과
- 다양한 알고리즘 성능 비교 가능.
- 문제 해결 능력 향상 및 효율적 알고리즘 분석 플랫폼 제공.

## 코드 기여 요약
- **주요 기능 구현**: solve_puzzle 함수 및 결과 형식화.
- **문서 작업**: 알고리즘 성능 표를 포함한 README.md 수정.
- **버그 수정**: Greedy 알고리즘 휴리스틱 개선.

이 프로젝트는 8퍼즐 문제를 해결하는 다양한 알고리즘을 비교하고, 효율적인 문제 해결 방법을 모색하는 데 중점을 두고 있습니다.
