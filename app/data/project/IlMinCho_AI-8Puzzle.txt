Summary:
프로젝트 개요: **AI-8Puzzle**
- 8퍼즐 문제 해결 위한 다양한 검색 알고리즘 구현
- 목표 상태("012345678")로 가기 위한 경로 탐색
- 사용된 알고리즘:
  - 너비 우선 탐색 (BFS)
  - 균일 비용 탐색 (Uniform-Cost Search)
  - 탐욕적 알고리즘 (Greedy Search)
    - 히유리스틱 1: 잘못된 타일 개수
    - 히유리스틱 2: 맨해튼 거리
    - 히유리스틱 3: 가중 맨해튼 거리
  - A* 탐색 알고리즘

주요 기능:
- 우선순위 큐 (Priority Queue) 이용한 상태 관리
- 퍼즐 상태 클래스 (EightPuzzleBoard) 구현, 다음 상태 생성 메서드 포함
- 검색 알고리즘 클래스 각각 구현, 공통 메서드 인터페이스 제공
- 결과 비교 및 출력 기능 포함

### 문제 및 해결 방법:
- **히유리틱 #3 오류**: GreedySolver의 h3 히유리틱 구현 오류, 상태 검사 조건 미비
- 오류 수정 후 정확한 결과 도출

### 결과:
- 다양한 검색 전략으로 퍼즐 해결
- 경로 길이, 비용, 탐색한 상태 수 등 비교 가능한 출력 성과 도출
- 알고리즘 성능 평가 유용성 확인

프로젝트 요약:

  - Solvers: 각 탐색 전략 구현 클래스 모음
