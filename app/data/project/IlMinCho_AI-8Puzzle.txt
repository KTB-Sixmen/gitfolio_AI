Summary:
프로젝트 개요:
- 8퍼즐 문제 해결을 위한 탐색 알고리즘 구현

### 주요 기능
1. 퍼즐 표현
   - `EightPuzzleBoard` 클래스로 8퍼즐 상태 표현
   - 빈 칸 '0'으로 표시

2. 탐색 전략
   - 너비 우선 탐색(BFS): `BreadthFirstSolver` 구현
   - 균일 비용 탐색: `UniformCostSolver` 구현
   - 탐욕적 탐색: `GreedySolver` (잘못된 타일 수, 맨해튼 거리 사용)
   - A* 탐색: `AstarSolver` 구현, 효율적 탐색

3. 결과 보고
   - 탐색 전략 결과 정리 및 출력 기능

4. 테스트 케이스
   - `get_test_puzzles`로 다양한 난이도의 퍼즐 제공

### 발견된 문제 및 해결
- h3 휴리스틱 관련 오류 발생
- 디버깅 및 알고리즘 최적화 통해 해결

### 최종 성과
- 다양한 탐색 알고리즘 구현 학습
- 알고리즘 선택 중요성 인지
- 효율적 탐색을 위한 휴리스틱 적용 방법 습득

### 문제 해결 및 개발 과정
```
문제: h3 휴리스틱 오류로 인해 탐욕적 알고리즘 불안정
해결: 상세한 디버깅 및 알고리즘 최적화
결과: 알고리즘 안정성 향상, 휴리스틱 적용 개선
```

### 사용자 코드 기여 요약
- BFS, 균일 비용, 탐욕적, A* 탐색 구현
- h3 관련 문제 해결 및 알고리즘 최적화
- 다양한 테스트 퍼즐 제공해 코드의 신뢰성 및 유용성 증가
