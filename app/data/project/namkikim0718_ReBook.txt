**프로젝트 개요: ReBook**

ReBook은 클라우드 기반의 중고 전공 서적 거래를 위한 e-커머스 플랫폼으로, 대학 재학생 및 졸업생을 대상으로 신뢰성 높은 거래 환경을 제공합니다.

### 주요 기능 및 제 기여:
1. **회원 및 인증 관리 시스템**
   - 카카오 소셜 로그인 구현: 인증 코드 관리 및 JWT 토큰 발급.
   - 이메일 인증 모듈 개발: 사용자 등록 후 인증 메일 전송 로직 작성.
   - 마이페이지: 사용자 정보 조회 및 수정 기능 개발.

2. **상품 관리**
   - 상품 등록/수정/삭제 API 설계: 이미지 업로드 처리 및 데이터 검증 로직 포함.
   - 검색 필터: Querydsl을 이용한 동적 쿼리 작성, 사용자 요구에 맞는 검색 기능 구현.

3. **채팅 기능**
   - 1:1 채팅 시스템 설계: STOMP 프로토콜을 이용한 실시간 메시징 기능 개발.
   - AI 모듈 통합: PyTorch로 작성한 의심 메시지 판별 로직 통합, 경고 시스템 기능 추가.

### 문제 및 해결 방안:
- **회원 인증 오류 문제**: JWT 만료 오류 발생 -> 리프레시 토큰 기반 재인증 로직 추가.
- **상품 검색 성능 저하**: 데이터 양 증가에 따른 검색 성능 문제 -> Redis 캐싱 도입, 쿼리 성능 개선.
- **채팅 실패 문제**: 서버 부하로 인한 메시지 수신 실패 -> WebSocket 연결 재시도 로직 구현.

### 결과:
- 사용자 인증 및 상품 관리 모듈 안정성 향상.
- 1:1 채팅 기능으로 사용자 간의 소통 원활화.
- 전체 시스템의 신뢰성 및 사용자 만족도 증가.

ReBook 프로젝트는 대학생과 졸업생의 중고 전공 서적 거래를 안전하고 편리하게 만들어, 기술적 도전과 해결 과정을 통해 성공적으로 완수되었습니다.
