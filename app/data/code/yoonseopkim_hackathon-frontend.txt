Summary:
프로젝트 개요:

이 프로젝트는 React 기반의 동화 생성 웹 애플리케이션으로, 사용자가 새로운 이야기를 만들거나 기존 이야기를 각색할 수 있는 기능을 제공한다. 사용자는 입력된 키워드와 메시지를 기반으로 동화를 창조하거나, 기존 동화를 각색할 수 있으며, 최종적으로 생성된 이야기는 책 형태로 보여진다.

주요 기능:

1. **이야기 생성**: 사용자가 입력한 키워드와 교훈을 기반으로 새로운 동화를 생성하는 기능.
2. **이야기 각색**: 기존 동화를 제목과 특정 조건을 바탕으로 새롭게 각색하는 기능.
3. **책 페이지 회전**: 동화를 페이지 형태로 보여주는 HTMLFlipBook 라이브러리를 이용하여 책장을 넘기는 인터페이스 제공.
4. **로딩 스피너**: 이야기를 생성하는 동안 로딩 상태를 나타내는 애니메이션 제공.
5. **리뷰 시스템**: 생성된 동화에 대해 온라인 리뷰를 남길 수 있는 기능.
6. ** 슬라이드 갤러리**: 시작 페이지에서 여러 이미지를 슬라이드 형식으로 보여주는 UI.

사용 기술:
- React.js 및 React Router: SPA(Single Page Application) 구조로 페이지 내비게이션 구현.
- Axios: API와의 HTTP 요청 처리.
- GSAP: 애니메이션 처리를 위한 라이브러리.
- react-pageflip: 책 페이지 변환 효과 제공.
- Slick carousel: 이미지 슬라이드 기능.

개발 과정에서 겪었던 문제와 해결:
- API 요청 처리 중 데이터 형식의 변화로 인해 오류가 발생했으나, 이를 JSON으로 변환하고 세부 사항을 로깅하여 문제를 해결했다.
- 도메인 간 요청 제한(CORS) 문제를 서버 측에서 설정을 통해 해결했다.

결과:
이 프로젝트의 결과로, 사용자는 인터랙티브한 방식으로 동화를 생성하고 표현할 수 있으며, 직관적인 UI/UX를 통해 쉽게 사용할 수 있는 웹 애플리케이션이 구현되었다. 이러한 기능들은 부모와 자녀가 함께 참여하며 재미를 느낄 수 있도록 설계되었다.
