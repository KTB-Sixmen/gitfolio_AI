## 프로젝트 요약: Kakao Tech Bootcamp 챗봇

### 개요
이 프로젝트는 Kakao Tech Bootcamp의 챗봇 애플리케이션으로, 사용자가 대화할 수 있는 인터페이스를 제공합니다. Next.js와 React를 기반으로 하며, TypeScript를 사용하여 안정성을 높였습니다. chat 기능 외에도 사용자 프로필 관리, 주소 업데이트 및 날씨 정보 제공 등의 다양한 서비스를 통합하고 있습니다.

### 주요 기능
1. **챗봇 인터페이스**: 사용자가 입력한 메시지에 대한 응답을 처리할 수 있는 챗봇 기능.
2. **API 호출**: 상태 관리 라이브러리인 React Query와 Zustand를 사용하여 데이터를 효율적으로 관리하고, API로부터 데이터를 가져오고 있습니다.
3. **프론트엔드 기술 스택**:
   - **TypeScript**: 정적 타입 제공
   - **Node.js**: JavaScript 런타임
   - **Next.js**: 서버 사이드 렌더링 및 정적 사이트 생성
   - **React**: UI 구성 요소 구축
   - **Tailwind CSS**: 스타일링
4. **모바일 반응형 디자인**: Tailwind CSS를 통해 유틸리티 퍼스트 방식으로 스타일링하여 다양한 화면 크기에 적응합니다.
5. **다양한 상태 관리**: 사용자 세션 상태, 로딩 상태 및 초기 데이터 관리를 위해 여러 Zustand 스토어를 구성했습니다.
6. **날씨 정보 제공**: 외부 API를 통해 오늘의 날씨와 주간 예보를 조회할 수 있는 기능을 포함하고 있습니다.

### 문제 및 해결
- **로그인 세션 관리 문제**: 서브스크립션을 통해 세션 오류를 관리하여 적절한 시점에 사용자에게 알림을 제공하도록 설정했습니다.
- **초기 데이터 처리**: 사용자가 대화를 시작할 때 AI의 응답을 효과적으로 업데이트할 수 있도록 초기 데이터 스토어를 구성했습니다.

### 결과
이 프로젝트는 사용자에게 직관적이고 반응성 있는 챗봇 경험을 제공하며, 다양한 API와 통합하여 실시간으로 정보를 제공하는 기능을 갖추고 있습니다. 또한 유지보수와 확장이 용이한 코드 구조로 잘 설계되었습니다.
