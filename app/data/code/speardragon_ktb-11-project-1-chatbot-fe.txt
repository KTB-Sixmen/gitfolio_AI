Summary:
### 프로젝트 요약: Kakao Tech Bootcamp 챗봇

**목적**: 
Kakao Tech Bootcamp 챗봇은 사용자가 쉽게 소통할 수 있는 인터페이스를 제공하여 다양한 정보에 접근할 수 있도록 돕는 목적으로 개발되었습니다.

**주요 기능**:
1. **채팅 기능**: 
   - 사용자는 대화방에서 메시지를 주고받으며 실시간으로 AI와 상호작용할 수 있습니다.
   - 메시지는 서버로 스트리밍되어 처리되며, 다양한 상태 관리와 업데이트가 가능합니다.

2. **데이터 관리**:
   - Zustand를 이용한 상태 관리로, 사용자 세션 정보, 초기 데이터 저장, 스켈레톤 로딩 상태 등을 관리합니다.
   - React Query를 통해 REST API와 상호작용하며, 데이터 패칭 및 오류 처리를 간편하게 구현합니다.

3. **일정 및 날씨 조회**:
   - 사용자는 개인 일정 및 주간 날씨 정보를 조회할 수 있으며, 필요한 정보를 API를 통해 제공합니다.

4. **CSS 스타일링**:
   - Tailwind CSS를 사용하여 반응형 디자인을 구현하고, 코드의 일관된 스타일을 유지합니다.

5. **버전 관리**:
   - GitHub를 통한 버전 관리를 통해 협업을 원활하게 하며, Issue 및 Bug 리포트를 활용하여 피드백을 받고 있습니다.

**기술 스택**:
- **프레임워크**: Next.js, React
- **언어**: TypeScript, JavaScript
- **상태 관리**: Zustand, React Query
- **CSS 프레임워크**: Tailwind CSS
- **API**: OpenAI API 사용

**시작 방법**:
1. 레포지토리 클론
   ```bash
   git clone https://github.com/kakaotech-bootcamp-11/ktb-11-project-1-chatbot-fe.git
   cd ktb-11-project-1-chatbot-fe
   npm install
   npm run dev
   ```
2. 프로덕션 빌드 및 배포
   ```bash
   npm run build
   npm run start
   ```

**주요 이슈 및 해결**:
- 사용자 세션 관리와 데이터 패칭 중 발생했던 오류를 React Query와 Zustand로 해결했으며, 적절한 에러 처리 로직을 구현하여 사용자 경험을 향상시켰습니다.
- 챗봇 메시지 전송 시 발생하는 네트워크 오류를 감지하고 사용자에게 관련 알림을 제공하도록 설계했습니다.

본 프로젝트는 다양한 기술적 난제를 해결하며, 사용자의 편리한 정보 접근을 목표로 하는 실용적인 웹 어플리케이션입니다.
