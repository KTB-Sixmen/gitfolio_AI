Summary:
이 프로젝트는 다양한 정보 검색 모델의 평가를 수행하는 스크립트로, QL(퀵시스템), BM25, DPR(문서 패러프레이징)을 사용하여 질의에 대한 정밀도, 재현율, NDCG, 평균 정밀도 등을 계산하는 기능을 포함하고 있습니다. 주요 기능들은 다음과 같습니다:

1. **파일 읽기 및 데이터 추출**: 
   - "ql.eval", "bm25.eval", "dpr.eval" 파일에서 평가 결과를 읽고 각 모델의 성능 지표(AP: Average Precision)를 추출합니다.
   - 또한 "preciRecall_ql.txt", "preciRecall_bm25.txt", "preciRecall_dpr.txt" 파일로부터 정밀도와 재현율 데이터를 읽습니다.

2. **데이터 포맷팅**:
   - 각 모델의 성능을 비교하기 위해 필요한 정보(질의, AP 값, 모델 간의 비율)를 정리하여 데이터프레임으로 변환합니다.

3. **정밀도-재현율 곡선(plotting)**:
   - Matplotlib 라이브러리를 사용하여 각 모델에 대한 정밀도-재현율 곡선을 시각화하여 모델의 성능을 비교합니다.

4. **NDCG 및 기타 평가 메트릭**:
   - ndcg20, eval이라는 두 개의 함수로 구성되어 NDCG (Normalized Discounted Cumulative Gain), MRR (Mean Reciprocal Rank), P@k, R@k 등을 계산합니다.
   - 각 모델의 성능을 측정하기 위해 관련된 통계치를 계산하고 결과를 파일에 저장합니다.

5. **결과 리포팅**:
   - 최종적으로 계산된 성능 지표를 파일에 쓰고 출력하여, 각각의 질의에 대한 세부적인 평가 결과를 제공하고 전체 성능도 요약합니다.

### 프로젝트 결과 및 이슈:
- 모델 간의 성능을 효과적으로 비교할 수 있는 구조를 제공하였으며, 평가 과정에서 발생할 수 있는 예외를 처리하는 로직을 포함했습니다.
- 데이터 처리 과정에서 발생하는 오류 및 이상값(예: 0으로 나누기)을 방지하는 검증 로직을 사용했습니다.
- Plotting으로 시각화를 통해 사용자가 각 모델의 성능을 직관적으로 이해할 수 있도록 지원했습니다.

### 결론:
이 프로젝트는 정보 검색 시스템의 성능을 정량적으로 평가할 수 있는 유용한 도구로, 다양한 검색 알고리즘의 효율성을 비교하고 성능을 개선하는 데 기여할 수 있습니다. 모델 개발과 관련한 AI 분야에서 성능 분석의 기초를 제공할 수 있는 중요한 기술로 활용될 수 있습니다.
