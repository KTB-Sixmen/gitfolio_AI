Summary:
이 프로젝트는 8퍼즐 문제를 해결하기 위한 여러 가지 탐색 알고리즘을 구현한 것으로, 다양한 접근 방식을 통해 퍼즐의 초기 상태에서 목표 상태로의 이동 경로를 찾는 것을 목표로 합니다. 다음은 프로젝트의 주요 특징과 구성 요소입니다.

### 주요 특징
1. **목표 상태 정의**: `GOAL_STATE`는 '012345678'로 설정되며, 퍼즐의 완전한 목표 상태를 나타냅니다.
   
2. **탐색 전략**:
   - **너비 우선 탐색(BFS)**: `BreadthFirstSolver` 클래스를 통해 BFS 방식으로 탐색을 수행합니다.
   - **균일 비용 탐색(Uniform Cost Search)**: `UniformCostSolver` 클래스를 사용해 각 이전 상태로의 전이 비용을 고려하여 탐색합니다.
   - **탐욕적 탐색(Greedy Search)**: 여러 가지 휴리스틱(이동한 타일 개수, 맨하탄 거리 등)을 활용하여 탐색할 수 있도록 `GreedySolver` 클래스를 제공합니다.
   - **A* 탐색**: `AstarSolver` 클래스에서는 탐욕적 탐색에서 사용되는 휴리스틱을 포함하여 총 비용을 최소화하는 경로를 발견합니다.

3. **결과 출력**: 각 탐색 전략의 성능을 비교하기 위해, `print_table` 함수를 통해 길이, 비용, 탐색한 상태 수 등의 결과를 정리하여 출력합니다.

4. **퍼즐 보드 클래스**: `EightPuzzleBoard` 클래스는 퍼즐의 상태를 나타내며, 타일의 위치와 움직임을 관리합니다. 이 클래스는 주어진 문자열(`${board_string}`)로 초기화되어 타일의 이동을 가능한 상태로 생성합니다.

### 발견된 문제점
- **휴리스틱 3의 오류**: 프로젝트에서 구현한 Greedy 탐색 알고리즘 중 한 가지인 휴리스틱 3(h3)에 문제가 발생하였습니다. 이 문제가 해결되지는 않았으며, 그로 인해 알고리즘의 결과가 예기치 않게 나타나는 경우가 있었습니다. 추가적인 디버깅이 필요합니다.

### 결론
이 프로젝트는 퍼즐 풀이 알고리즘의 다양한 전략을 비교할 수 있는 기반을 제공합니다. 각 클래스는 특정 탐색 방법을 구현하고 있으며, 퍼즐의 상태를 효과적으로 추적하여 최적의 경로를 찾는 데 초점을 맞추고 있습니다. 추가적인 테스트를 통해 발견된 문제를 해결하고, 퍼즐의 상태에 따른 성능을 더 개선할 수 있는 여지가 있습니다.
