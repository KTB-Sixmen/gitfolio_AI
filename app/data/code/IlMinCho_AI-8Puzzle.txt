Summary:
이 프로젝트는 8퍼즐 문제 해결을 위한 다양한 탐색 알고리즘을 구현한 코드입니다. 주요 내용은 다음과 같습니다:

### 주요 기능
1. **퍼즐 표현**: `EightPuzzleBoard` 클래스를 통해 8퍼즐의 상태를 표현합니다. 퍼즐은 9자리 문자열로 나타내며, 빈 칸은 '0'으로 표시됩니다. 각 상태는 타일 이동을 통해 생성된 후속 상태를 생성할 수 있습니다.

2. **탐색 전략**:
   - **너비 우선 탐색(BFS)**: `BreadthFirstSolver` 클래스를 사용하여 최단 경로를 찾습니다.
   - **균일 비용 탐색(Uniform Cost Search)**: `UniformCostSolver` 클래스를 통해 최소 비용 경로를 탐색합니다.
   - **탐욕적 탐색**: `GreedySolver`는 다양한 휴리스틱 기법(잘못된 타일 수, 맨해튼 거리, 가중 맨해튼 거리)을 사용하여 탐색합니다.
   - **A* 탐색**: `AstarSolver`는 휴리스틱을 결합하여 효율적으로 상태를 탐색합니다.

3. **결과 보고**: 각 탐색 전략에 대한 결과를 정리하여 출력하는 `print_table` 함수와, 각 전략의 성능을 비교할 수 있는 기능을 포함합니다.

4. **테스트 케이스**: `get_test_puzzles` 함수를 통해 다양한 난이도의 테스트 퍼즐을 제공합니다.

### 발견된 문제 및 해결
- 코드에 대해 여러 휴리스틱 (특히 h3)에서 에러가 발생하는 경우 확인되었습니다. 이로 인해 일반적인 탐욕적 알고리즘의 작동이 불안정해지는 문제가 있었습니다. 해당 문제를 해결하기 위해 
각 헷갈리는 점에 대한 디버깅을 진행하고 알고리즘의 동작을 최적화해야 합니다.

### 최종 성과
이 프로젝트를 통해 다양한 탐색 알고리즘의 구현 방법을 배울 수 있었으며, 8퍼즐 문제를 해결하는 데 있어 알고리즘 선택의 중요성을 이해하게 되었습니다. 또한, 효율적인 탐색을 위해 휴리스틱 방식을 적절하게 적용하는 방법을 익혔습니다. 

이 코드는 AI 알고리즘의 기초를 다지고, 복잡한 문제를 해결하기 위한 전략적 사고를 기르는 데 매우 유용한 사례로 작용할 수 있습니다.
