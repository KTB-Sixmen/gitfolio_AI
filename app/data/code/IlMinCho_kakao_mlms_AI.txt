Summary:
이 프로젝트는 사용자의 입력(음식 종류 및 키워드)을 받아, 현재 위치 기반으로 추천 맛집 리스트를 제공하는 API입니다. 주요 특징은 다음과 같습니다:

1. **입력 및 추천 기능**:
   - 사용자는 음식 종류와 위치 정보를 제공하여 API를 호출합니다.
   - API는 추천 맛집 리스트를 제공하며, 각 맛집에는 가게 이름, 주소, 점수 및 클러스터링된 키워드가 포함됩니다.

2. **데이터 처리**:
   - 사용자 요청 시, 입력된 위치에서 음식점 리뷰 데이터를 Elasticsearch에 저장하고 기계 학습 모델을 통해 분석합니다.
   - Crawling을 통해 음식점 리뷰 데이터를 수집하고, 이를 전처리하여 사용할 수 있도록 준비합니다.

3. **모델**:
   - 프로젝트는 KcELECTRA 및 BiLSTM 모델을 사용하여 리뷰의 감정을 예측하고, 이를 기반으로 음식점의 점수를 매깁니다.
   - 이 두 개의 모델을 앙상블하여 가장 신뢰할 수 있는 점수를 도출하는 방식이고, 최종 점수는 리뷰 수와 키워드 언급 수에 따라 가중치를 적용하여 계산됩니다.

4. **클러스터링**:
   - 리뷰 데이터는 HDBSCAN을 사용하여 클러스터링됩니다. 이 과정에서 가장 큰 군집에서 자주 언급되는 단어들을 추출하여 추천 결과에 포함시킵니다.

5. **시각화 및 정렬**:
   - 추천 맛집 리스트는 사용자의 위치 근처에서 접근 가능한 순서로 정렬되어 반환됩니다.
   - 반환된 리스트는 지도 상에 시각적으로 표시할 수 있습니다.

6. **환경 설정**:
   - Python 3.10 이상, JDK 1.7 이상, FastAPI 라이브러리 및 Elasticsearch 데이터베이스의 설치가 필요합니다.
   - `pip install -r requirements.txt`를 통해 필요한 패키지를 설치하고, 메인 서버 파일을 `uvicorn ai_server:app --reload` 명령어로 실행합니다.

### 문제 해결 및 결과
- 데이터 크롤링 처리 및 리뷰 전처리 과정에서 발생했던 오류들은 예외 처리를 통해 우회하며 해결했습니다.
- 다양한 리뷰 데이터 처리 후, 모델의 성능을 평가하여 필요시 하이퍼파라미터를 조정했습니다.
- 최종적으로 사용자의 입력에 따라 정확한 맛집 추천 리스트를 출력하면서 만족스러운 결과를 도출했습니다.

이 프로젝트를 통해 머신러닝 모델의 실제 활용 사례와 데이터 수집, 클러스터링 및 추천 알고리즘의 중요성을 배울 수 있었습니다.
