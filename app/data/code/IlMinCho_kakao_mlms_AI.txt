Summary:
이 프로젝트는 사용자의 입력(음식 종류와 키워드)을 받아 현재 위치 기반으로 맛집을 추천하는 API를 설계한 것입니다. 주요 기능과 구조는 다음과 같습니다:

### 주요 기능
1. **추천 맛집 리스트 제공**: 사용자에게 위치 기반으로 추천 맛집을 가게 이름, 점수, 리뷰에서 자주 등장하는 단어를 포함하여 제공합니다.
2. **근처 맛집 정렬**: 추천된 맛집은 사용자가 현재 위치에서 가까운 순서로 정렬되어 응답됩니다.
3. **지도 시각화**: 추천된 맛집은 지도 상에 표시될 수 있습니다.
4. **리뷰 크롤링 및 데이터 저장**: 사용자 입력을 바탕으로 해당 음식점의 리뷰를 크롤링하여 Elasticsearch에 저장합니다.
5. **클러스터링 및 랭킹화**: 수집된 리뷰를 클러스터링하고, 여러 모델을 통해 가게를 랭킹합니다.

### 기술 스택
- **FastAPI**: 웹 API 구축을 위한 프레임워크 사용.
- **Elasticsearch**: 데이터의 저장 및 검색을 위한 DB.
- **Python 3.10+**: 코드 작성 언어.
- **Selenium**: 음식점 리뷰 크롤링을 위한 웹 자동화 도구 사용.
- **HDBSCAN, UMAP**: 클러스터링을 위한 머신러닝 기법 사용.

### 코드 구조
- FastAPI를 통해 API 수신:
    - `/api/v1/stores/ai` 엔드포인트에서 음식점 추천 호출.
- 리뷰 크롤링 및 데이터 처리:
    - 리뷰 데이터를 크롤링하여 Elasticsearch에 저장.
    - 리뷰 데이터 전처리 후 감정 분석 및 클러스터링 수행.
- 머신러닝 모델:
    - KcELECTRA 및 BiLSTM 모델을 활용하여 리뷰 점수를 예측하고 추천 맛집을 랭킹.

### 문제 및 해결
- 초기 Elasticsearch 설정 문제: 환경 변수를 통해 DB 접근 정보를 지정하고, 서버 실행 시 Elasticsearch 서비스 동기화를 주의.
- 리뷰 크롤링 실패: 웹사이트 구조 변화 대응을 위해 XPATH 경로를 동적으로 설정하는 방법 적용.
- 성능 향상 위한 데이터 병렬 처리: ThreadPoolExecutor를 사용하여 여러 페이지를 동시에 크롤링하여 속도 개선.

### 성과
프로젝트는 성공적으로 구현되어, 사용자 입력을 바탕으로 관련된 맛집을 빠르고 정확하게 추천할 수 있는 API를 제공하며, 향후 지속적인 모델 개선과 데이터 수집을 통해 더욱 향상된 결과를 기대할 수 있습니다.
