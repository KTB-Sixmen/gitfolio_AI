Summary:
이 프로젝트는 사용자의 입력(음식 종류와 키워드)을 기반으로 현재 위치에 적합한 맛집을 추천하는 API를 설계하는 것입니다. 이 API는 FastAPI를 사용하여 구현되었으며, ElasticSearch를 데이터베이스로 활용하여 리뷰와 가게 정보를 처리합니다. 다음은 프로젝트의 주요 내용 요약입니다.

### 핵심 기능
1. **리뷰 크롤링**:
   - Kakao Maps를 통해 특정 지역의 음식점 정보를 수집하고, 리뷰를 추출하여 ElasticSearch에 저장합니다.
   - Selenium을 사용하여 웹페이지에서 정보를 자동으로 크롤링합니다.

2. **리뷰 분석 및 랭킹**:
   - BiLSTM 및 KcELECTRA 모델을 활용하여 리뷰의 감정을 분석하고, 음식점의 순위를 매깁니다.
   - 리뷰 데이터의 전처리와 감정 점수 계산 과정을 포함합니다.

3. **위치 기반 추천**:
   - 사용자로부터 좌표 입력을 받아 해당 지역의 가게명을 추출하고 키워드를 결합합니다.
   - 가게 리뷰 데이터를 사용하여 키워드 기반 추천을 수행하고, 추천 리스트를 정렬하여 반환합니다.

4. **API 엔드포인트**:
   - `/api/v1/stores/ai` 경로를 통해 추천 레스토랑 정보를 제공하며, 요청 본문에서 포함된 위도, 경도, 키워드를 사용합니다.

5. **데이터 저장 및 처리**:
   - 수집된 리뷰와 관련 정보를 ElasticSearch에 저장하여 효율적으로 관리합니다.
   - CSV 파일 형식으로 데이터를 저장하고 나중에 사용할 수 있도록 합니다.

### 문제 및 해결
- **데이터 수집 시 오류**: 웹 크롤링 과정에서 특정 요소를 찾지 못하거나 페이지가 로드되지 않는 경우가 발생했습니다. 이를 해결하기 위해 적절한 대기 시간 및 예외 처리를 추가했습니다.
- **모델 훈련 및 평가**: BiLSTM과 KcELECTRA 모델을 학습시키는데 필요한 데이터 전처리 과정에서 발생할 수 있는 오류를 방지하기 위해 데이터 검증 절차를 추가했습니다.

### 결과
- 사용자가 요청한 조건에 맞는 추천 맛집 리스트를 시각적으로 표시할 수 있는 기능이 구현되었습니다.
- 감정 점수를 반영하여 리뷰 데이터를 기반으로 가게의 신뢰도를 평가할 수 있게 되었습니다.

이 프로젝트는 음식에 대한 리뷰 분석, 추천 시스템, 그리고 웹 크롤링 기술을 통합하여 실질적으로 사용 가능한 맛집 추천 API를 만들고자 하였습니다.
