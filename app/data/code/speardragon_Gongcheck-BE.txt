Summary:
아래는 주어진 코드의 요약 및 주요 특징(상황, 결과)과 전체적인 개요입니다.

### 요약
이 코드는 TypeScript로 작성된 NestJS 기반의 애플리케이션 구성 파일 및 관련 모듈들입니다. 주요 내용으로는 데이터베이스 연결(ORM) 설정, API 엔드포인트 정의, 사용자 인증 및 세션 처리 방식 등이 포함됩니다.

### 주요 특징
- **상황**: 다양한 기능(예: 책 관련, 사용자의 책 갈무리, 설문 조사 등)을 제공하는 웹 애플리케이션.
- **결과**: 사용자의 데이터를 처리하고, 책 관련 정보를 관리하며, 설문 조사와 피드백 기능을 제공하여 사용자 경험을 향상시킴.

### 전체적인 개요
1. **ESLint 설정** (`.eslintrc.js`):
   - TypeScript 코드에 대한 린트 규칙을 정의.
   - Prettier와 통합하여 코드 스타일을 일관성 있게 유지.

2. **애플리케이션 엔드포인트**:
   - 사용자 작업(책장 생성, 피드백 제출 등)을 처리하는 컨트롤러와 서비스 모듈 정의.
   - API의 세부사항을 명세하고 각종 오류 처리를 포함.

3. **TypeORM을 이용한 데이터베이스 연결**:
   - MySQL 데이터베이스와의 연결을 설정하고, 엔티티 정의.
   - 사용자, 책, 책장, 설문 조사 등 다양한 데이터 모델링 제공.

4. **CRUD 작업을 위한 서비스 및 레포지토리**:
   - 애플리케이션의 비즈니스 로직을 처리하는 서비스 클래스와 데이터베이스 작업을 수행할 레포지토리 추상화 구현.

5. **세션 및 사용자 인증 처리**:
   - 사용자 세션을 관리하고 인증되지 않은 요청에 대한 예외 처리를 수행.

6. **유닉한 파일 저장 및 업로드 기능**:
   - 사용자가 책장을 등록할 때 업로드된 이미지를 서버에 저장하고 관리하는 인터셉터 구현.

7. **테스트**:
   - Jest를 이용한 단위 테스트 및 e2e 테스트 구조 제공, 각 모듈의 동작을 검증.

이 코드는 사용자의 책 관련 정보와 피드백을 관리하는 기능을 중심으로 구성되어 있으며, NestJS 구조를 활용하여 효율적으로 모듈화되어 있습니다.
