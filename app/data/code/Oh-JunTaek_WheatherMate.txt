## 프로젝트 개요: WheatherMate

**WheatherMate**는 사용자가 날씨 정보를 기반으로 일정을 관리할 수 있는 애플리케이션입니다. 사용자는 약속을 잡는 시점에서 비가 오는지 확인할 수 있으며, 비가 예고될 경우 알림을 받을 수 있습니다. 또한, 일정을 저장하고 사진을 추가하여 추억을 담아둘 수 있는 기능도 제공합니다.

### 주요 기능
1. **날씨 API 연동** - 실시간 기상 정보 제공
2. **도시 선택** - 사용자가 위치에 따른 날씨 정보를 조회 가능
3. **구글 로그인** - 소셜 로그인을 통한 접근 편리성
4. **일정 미리보기** - 날짜 선택 시 저장된 일정 확인 가능
5. **네비게이션 메뉴** - 알림, 정보, 설정 등의 접근을 용이하게 함
6. **사진 저장 기능** - 일정과 함께 사진도 저장 가능

### 업데이트 로그

- 2023/10/04: 프래그먼트 기능 활성화 및 네비게이션 메뉴 추가

### 발견된 버그 및 수정 사항
- 구글 로그인 오류 해결
- 알람 기능 롤백
- 기온 표시 문제 수정

**발견된 주요 버그:**
1. 버튼 오류 및 페이지 가시성 문제
2. 홈 화면 흐리기 효과 미적용
3. 날씨 반영 미흡 (날짜 아이콘)

### 향후 계획
1. 메뉴 레이아웃 개선
2. 알람 기능 추가
3. 저장된 사진에 대한 시각적 표시(달력에 빨간 점/파란 점 추가)
4. 반복 일정 생성 모듈 개발
5. 미세먼지 정보 통합

**결론:** WheatherMate는 날씨와 일정을 통합하여 사용자의 생활 편의를 도모하는 애플리케이션으로, 계속해서 기능 추가 및 버그 수정을 통해 발전할 계획입니다.
