### 프로젝트 개요
- **목적**: Gitfolio 테마를 활용하여 개인 또는 팀의 포트폴리오 웹사이트 구축.
- **기능**:
  - GitHub에서 호스팅된 프로젝트의 정보 조회.
  - 사용자 맞춤형 디자인 및 레이아웃 제공.
  - 간편한 배포 및 업데이트 기능.

### 주요 포인트
- **사용 기술**: HTML, CSS, JavaScript 등 웹 개발의 기본적인 기술 사용.
- **데이터 관리**: GitHub API를 통한 동적 데이터 수집.
- **구성 요소**: 프로젝트 리스트, 사용자 정보, 기술 스택 등.

### 문제 해결
- GitHub API와의 통신에서 발생한 인증 문제 해결을 위해 OAuth 사용.
- 사용자 인터페이스(UI) 개선을 위해 CSS 프레임워크 도입.

### 결과
- 사용자 친화적인 포트폴리오 웹사이트 성공적으로 구축.
- 다양한 기기에서의 반응형 디자인 적용으로 접근성 향상.
