Summary:
이 프로젝트는 Python을 활용한 UDP 및 TCP 클라이언트-서버 애플리케이션을 구현하는 것입니다. 다음은 프로젝트의 주요 특징과 흐름입니다.

### 주요 구성 요소:
1. **UDP 클라이언트** (`udp_client`):
   - 주어진 파일에서 최대 7개 줄을 읽어와 UDP 서버에 전송합니다.
   - 서버로부터 응답을 받고, 성공적인 결과나 오류 메시지를 출력합니다.
   - 타임아웃 처리 및 재전송을 구현하여 신뢰성을 높였습니다.

2. **UDP 서버** (`udp_server`):
   - 클라이언트로부터 요청을 받고 각 요청에 대해 산술 연산을 수행합니다.
   - 패킷 손실을 시뮬레이션하기 위해 확률적 패킷 드롭 기능을 제공합니다.
   - 처리할 수 없는 요청 형식에 대해 적절한 오류 코드를 반환합니다.

3. **TCP 클라이언트** (`tcp_client`):
   - 파일에서 읽은 요청을 TCP 서버에 전송하고, 응답을 대기하여 결과를 출력합니다.

4. **TCP 서버** (`tcp_server`):
   - 클라이언트의 TCP 연결 요청을 수락하고 요청을 처리합니다.
   - 기본적으로 UDP 서버의 기능을 유사하게 구현하여 요청 형식에 따라 결과를 계산합니다.

### 오류 처리 및 기능:
- 각 클라이언트와 서버는 오류가 발생했을 때 적절한 오류 코드를 반환하여 고객 피드백을 관리합니다.
- 산술 연산에 대한 유효성 검사를 통해 부적절한 입력에 대해 적절하게 처리합니다.

### 개선 사항:
- UDP 클라이언트의 재전송 로직은 최대 2초까지 타임아웃을 설정하고 있으며, 만약 서버가 응답하지 않는 경우 `DEAD` 상태 메시지를 출력합니다.
- 요청을 위한 입력 파일의 형식 검증을 통해 파일 내용이 부족하거나 형식이 잘못된 경우 적절한 메시지를 출력하도록 했습니다.

### 결론:
이 프로젝트는 Python 소켓 프로그래밍을 통해 신뢰성이 낮은 UDP와 신뢰성이 높은 TCP의 차이를 이해하고, 각 프로토콜에 대한 기본적인 클라이언트-서버 모델을 구현할 수 있는 좋은 예시입니다. 데이터 전송에서의 신뢰성과 오류 처리 측면에서 중요한 개발 학습을 제공하며, 패킷 손실 같은 네트워크 변수를 이해하는 데 도움이 됩니다.
