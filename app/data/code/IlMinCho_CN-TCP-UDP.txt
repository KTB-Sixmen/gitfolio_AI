Summary:
**프로젝트 개요: CN-TCP-UDP**

이 프로젝트는 TCP와 UDP 프로토콜을 사용하여 클라이언트와 서버 간의 간단한 산술 연산을 수행하는 프로그램입니다. 총 6개의 프로그램으로 구성되어 있으며, 각 프로토콜에 대해 클라이언트와 서버가 독립적으로 동작하도록 설계되었습니다.

### 주요 기능

1. **TCP 클라이언트와 서버**
   - TCP 클라이언트는 주어진 파일에서 최대 7줄의 입력을 읽어 서버에 요청을 보냄.
   - 서버는 요청을 받아 적절한 산술 연산을 수행하고 결과를 반환하며, 유효성 검사를 통해 오류를 처리함.

2. **신뢰할 수 있는 UDP 클라이언트와 서버**
   - 신뢰성 있는 UDP 클라이언트는 요청을 보내고 응답을 기다리며, 결과를 수신하여 출력함.
   - 서버는 데이터의 유효성을 검사하고 적절한 응답을 반환함.

3. **신뢰할 수 없는 UDP 클라이언트와 서버**
   - 클라이언트는 허용된 최대 지연 시간 내에 응답을 받지 못하면 재전송을 시도함.
   - 서버는 설정된 확률에 따라 네트워크 패킷을 드롭하여 UDP의 불안정성을 시뮬레이션함.

### 에러 처리 및 유효성 검사
- 입력 데이터의 형식과 데이터 타입을 확인하여 번역 에러 및 잘못된 연산 코드를 처리.
- 서버는 산술 연산 중 0으로 나누기 및 잘못된 문자열 처리 등의 예외 상황을 적절하게 관리.

### 사용법
- 각 클라이언트 프로그램은 파일 이름을 인자로 받아서 실행됨.
- UDP 서버는 패킷 드롭 확률과 시드를 설정하여 실행됨, 이로 인해 실행 시 동작 방식이 달라짐.

### 결론
이 프로젝트는 Python의 소켓 프로그래밍을 활용하여 TCP와 UDP 통신의 기초를 이해하는 데 도움이 되는 실습 예제입니다. 클라이언트와 서버 간의 통신 방식의 차이를 보여주는 유용한 코드이며, 에러 처리가 적절하게 구현되어 있어 안정적인 동작을 보장합니다.
