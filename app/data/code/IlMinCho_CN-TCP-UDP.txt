Summary:
이 프로젝트는 UDP와 TCP 프로토콜을 사용하여 클라이언트-서버 간의 통신을 구현한 것으로, 두 가지 주요 유형의 서버 및 클라이언트를 포함합니다: 신뢰성 있는 UDP, 비신뢰성 UDP, 그리고 TCP. 각각의 기능에 대한 요약은 다음과 같습니다.

### 주요 기능
1. **UDP 클라이언트 (신뢰성 및 비신뢰성)**
   - 파일에서 요청을 읽어와 7줄까지 서버에 전송합니다.
   - 각 요청에 대해 서버로부터 응답을 받고 상태 코드에 따라 결과를 출력합니다.
   - 비신뢰성 UDP 클라이언트는 타임아웃을 재설정하여 요청을 재전송하는 메커니즘을 구현합니다.

2. **TCP 클라이언트**
   - UDP와 유사하게, 파일에서 수치를 읽어 서버에 전송합니다.
   - 서버 응답을 받고 결과를 화면에 출력합니다.

3. **UDP 서버 (신뢰성 및 비신뢰성)**
   - 계산 요청을 받고, 요청에 대한 결과를 반환합니다.
   - 비신뢰성 UDP 서버는 패킷 손실을 시뮬레이션하여 작업의 불확실성을 나타냅니다 (확률 값을 기반으로 패킷 드롭 발생).
   - 모든 수학 연산은 사칙연산으로, 올바른 형식이 아니거나 피연산자가 정수가 아닐 경우 적절한 오류 코드를 반환합니다.

4. **TCP 서버**
   - 연결을 수신하고 요청에 따라 적절한 응답을 반환합니다.
   - 요청이 올바른 형식이 아닐 경우 에러 상태 코드를 반환합니다.

### 에러 처리
- 클라이언트와 서버 모두 오류 처리를 구현하여 잘못된 입력이나 연결 문제에 대한 적절한 메시지를 출력합니다.
- 클라이언트가 파일이 비어있거나 라인이 부족할 경우 오류 메시지를 제공합니다.
- 서버는 잘못된 데이터 형식이나 계산 오류에 대해 명확한 에러 코드(620, 630)를 리턴합니다.

### 결론
이 프로젝트는 다양한 페러다임의 소켓 프로그래밍을 사용하여 효과적인 통신 시스템을 구현하고 있습니다. UDP의 경우 비신뢰적인 메커니즘을 사용하여 패킷 손실을 관리하며, TCP는 보다 안정적인 연결을 제공합니다. 실제 적용에서는 서버의 가용성과 정상적인 응답을 유지할 수 있는 기능이 중요한데, 이러한 측면에서 클라이언트-서버 간의 신뢰성 있는 커뮤니케이션 모델을 실현한 사례가 됩니다.
