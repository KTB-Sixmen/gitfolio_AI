Summary:
이 프로젝트는 UDP 및 TCP를 사용하여 신뢰 가능한 및 신뢰할 수 없는 클라이언트-서버 통신을 구현하는 파이썬 프로그램입니다. 전체적인 구조는 클라이언트와 서버 사이의 기본적인 수학 연산 요청과 응답을 처리합니다. 이 프로젝트의 주요 기능 및 구성 요소는 다음과 같습니다.

### 주요 기능:
1. **UDP 클라이언트** (`udp_client`):
   - 지정된 파일의 각 줄을 읽고, 해당 줄을 서버에 전송합니다.
   - 최대 7줄까지 전송하며, 각 요청에 대해 응답을 기다립니다.
   - 응답받은 데이터의 상태코드에 따라 결과를 출력합니다.
   - 타임아웃을 특정 시간 범위 내에서 관리하며, 요청이 실패할 경우 재전송을 시도합니다.

2. **UDP 서버** (`udp_server`):
   - 클라이언트로부터 요청을 받아 수학적 연산을 수행합니다.
   - 패킷 손실을 시뮬레이션하여 일정 확률로 요청을 드롭합니다.
   - 요청 형식이 올바르지 않거나 피연산자가 정수가 아닐 경우 오류 코드를 반환합니다.
   - 정상적인 요청에 대해서는 상태코드와 결과를 반환합니다.

3. **TCP 클라이언트** (`tcp_client`):
   - 서버에 연결하여 파일에서 읽은 요청을 전송합니다.
   - UDP 클라이언트와 유사한 방식으로 동작하나, TCP를 사용하여 더 신뢰성 있는 통신을 보장합니다.

4. **TCP 서버** (`tcp_server`):
   - 클라이언트에서 요청을 수신하고, 수학적 연산을 처리합니다.
   - 입력 형식을 검증하고, 오류 발생 시 적절한 오류 코드를 반환합니다.

### 기술적 세부사항:
- **소켓 프로그래밍**: TCP와 UDP 소켓을 사용하여 클라이언트-서버 모델을 구현했습니다.
- **에러 처리**: 파일 입출력, 소켓 통신에서 발생할 수 있는 다양한 예외 처리 기법을 사용해 안정성을 확보했습니다.

### 문제 및 해결 방법:
- **시간 초과**: UDP의 비신뢰성 때문에 요청 시간 초과를 처리하기 위해 재전송 매커니즘을 구현했습니다.
- **패킷 손실 시뮬레이션**: 랜덤으로 패킷을 드롭하는 기능을 추가하여 신뢰할 수 없는 환경을 재현했습니다.

### 결론:
이 프로젝트는 실습을 통해 소켓 프로그래밍의 기초를 이해하고, UDP와 TCP 프로토콜의 차이를 체험하는 데 유용한 코드 집합입니다. 또한, 수학적 연산을 기반으로 한 클라이언트-서버 모델을 통해 네트워크 프로그래밍의 기본 개념을 심도 있게 배울 수 있는 기회를 제공합니다.
