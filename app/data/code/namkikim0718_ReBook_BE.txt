## 프로젝트 개요 및 요약

이 프로젝트는 **ReBook**이라는 이름의 플랫폼으로, 사용자 간의 물품 거래를 지원하는 시스템입니다. 주된 기능은 회원 가입, 인증, 제품 등록 및 관리, 채팅 기능 등으로 구성되어 있습니다. 이 플랫폼은 Spring Boot 프레임워크를 사용하여 구축되었으며, Redis 및 AWS S3와 통합되어 있습니다.

### 주요 기능

1. **회원 관리**:
   - 회원가입 및 인증 기능.
   - 비밀번호 재설정 및 회원 정보 업데이트 가능.
   - 이메일 인증을 통한 안전한 사용자 등록 과정.

2. **제품 관리**:
   - 사용자가 판매할 제품을 등록할 수 있으며, 제품 이미지 업로드 기능을 지원.
   - 제품 목록 조회, 특정 제품의 상세 정보 조회.
   - 제품 상태 변경(예: 거래 완료, 판매 중지) 및 삭제 가능.

3. **채팅 기능**:
   - 실시간 1:1 채팅 기능을 통해 사용자 간의 원활한 커뮤니케이션 지원.
   - WebSocket을 사용하여 실시간 메시지 전송.

4. **파일 저장소**:
   - S3를 사용하여 제품 이미지 및 프로필 사진 등의 파일을 안전하게 저장하고 관리.

5. **예외 처리 및 인증**:
   - 사용자 인증 및 권한 관리 시스템 구현.
   - 다양한 예외 처리 로직을 통해 안정성 및 사용자 경험 향상.

### 사용 기술 및 아키텍처

- **백엔드**: Java, Spring Boot, Spring Security, JPA
- **데이터베이스**: MySQL
- **Redis**: 세션 관리 및 실시간 데이터 처리
- **AWS S3**: 이미지 저장
- **WebSocket**: 실시간 채팅 기능

### 해결한 문제 및 결과

- 사용자 인증 흐름에 대한 복잡함을 해결하기 위해 JWT(JSON Web Tokens)를 활용하여 Stateless한 인증 시스템을 구현.
- Redis를 사용하여 제품 목록의 paging과 caching을 통해 성능 향상.
- 프론트엔드와의 연동을 위해 RESTful API 설계하여 각 기능별로 명확한 endpoint 제공.

### 발생한 문제

- REST API와 WebSocket이 상호작용하는 과정에서 인증 관련 문제가 발생하여, 인증 토큰을 각 요청에 포함할 수 있도록 필터 시스템을 구현.
- 오류 발생 시 사용자에게 적절한 메시지를 제공하기 위한 글로벌 예외 처리기 구현.

이 프로젝트는 현대적인 웹 애플리케이션 개발에 필요한 다양한 기술과 아키텍처를 활용하여, 사용자에게 안전하고 효율적인 거래 플랫폼을 제공하는데 성공하였습니다.
