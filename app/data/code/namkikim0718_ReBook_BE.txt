Summary:
### 프로젝트 개요: ReBook_BE

- **주제**: 클라우드 기반 중고 전공 서적 거래 플랫폼
- **대상**: 대학 재학생 및 졸업생

### 목표
- 대학생과 졸업생에게 편리한 전공서적 중고 거래 환경 제공
- 사용자 간 직접 거래와 플랫폼의 안전 장치 결합하여 신뢰성 높은 중고 거래 플랫폼 구축

### 기술 스택
- **Frontend**: React, Vite
- **Backend**: Java, Spring Boot, Spring Security, Redis, Querydsl, STOMP, Netflix Eureka
- **AI/ML**: Fast API, PyTorch, Pandas, KcELECTRA
- **Infra**: Docker, AWS, Ansible, Terraform, Prometheus, Grafana, Jenkins
- **Collaborative**: Notion, Figma, Github

### 주요 기능
1. **회원 및 인증 관리 시스템**:
   - 카카오 소셜 로그인 및 이메일 인증 기능
   - 마이페이지에서 회원 정보 관리

2. **상품 관리**:
   - 상품 등록, 수정, 삭제 및 이미지 관리
   - 필터링 및 검색 기능

3. **채팅 기능**:
   - 사용자 간의 실시간 1:1 채팅
   - AI 모듈을 통한 사기 의심 메시지 경고

### 트러블 슈팅
1. **쿼리 파라미터 가독성 저하**: DTO 사용 및 Querydsl 동적 쿼리 생성을 통해 해결.
2. **페이지네이션 성능 저하**: 커서 기반 페이지네이션으로 성능을 98.68% 개선 (151ms → 2ms).
3. **파일 업로드 에러**: Nginx 및 application.yml 설정 변경으로 해결.

### 성과
- 대학생 사용자들로부터 긍정적인 피드백 수집
- 플랫폼의 안정성과 가독성을 높여 사용자 경험을 강화

이 프로젝트는 중고 서적 거래의 안전성과 효율성을 크게 향상시켰으며, 기술 스택의 활용도를 높여 클라우드 기반의 혁신적인 솔루션을 제공하는 데 중점을 두었습니다.
