Summary:
### 프로젝트 개요

이 프로젝트는 카카오 API와 머신러닝 모델을 활용한 음식점 리뷰 분석 및 추천 시스템입니다. 사용자는 특정 위치와 키워드를 제공하면, 해당 지역의 음식점 추천과 관련 리뷰를 받을 수 있으며, 리뷰에 대한 감성 분석과 클러스터링을 통해 상위 음식점들을 랭킹하는 방식으로 작동합니다.

### 주요 기능

1. **AI 통신**: FastAPI를 사용하여 AI 모델과의 통신을 통해 사용자가 제공한 위치와 키워드에 따라 추천 음식점을 반환합니다.

2. **리뷰 크롤링**: Selenium을 사용하여 카카오 맵에서 음식점 리뷰를 자동으로 크롤링하고, 이 데이터를 전처리하여 모델에 활용합니다.

3. **데이터 전처리**: 수집된 리뷰 데이터를 정제하고, 불용어 처리를 수행하여 머신러닝 모델의 입력 데이터로 가공합니다.

4. **모델 개발**:
   - **KcELECTRA 및 BiLSTM 모델**: 두 가지 머신러닝 모델을 통해 감성 분석을 수행하며, 각각의 모델에서 예측한 결과를 융합하여 최종 추천 점수를 산출합니다.
   - **클러스터링**: HDBSCAN을 이용해 리뷰를 군집화하고, 가장 큰 군집에서 자주 언급된 키워드를 추출하여 음식점 추천에 활용합니다.

5. **추천 시스템**: 사용자의 리뷰와 AI 모델의 예측을 기반으로 음식점 랭킹을 생성하고, 이 결과를 사용자에게 표시합니다.

### 주요 이슈 및 해결 사항

- **크롤링 오류**: 리뷰나 페이지가 제대로 отображ통하지 않는 문제를 해결하기 위해 Selenium의 `WebDriverWait`를 사용하여 요소가 로드될 때까지 대기하는 로직을 추가했습니다.
  
- **모델 성능 개선**: KcELECTRA 및 BiLSTM 모델의 성능을 향상시키기 위해 다양한 하이퍼파라미터 튜닝을 진행하고, 여러 시험 데이터를 통해 검증했습니다.

- **데이터 전처리 문제**: 데이터 전처리 과정에서 발생하는 결측치 및 불일치 문제를 해결하기 위해 유효성 검사를 추가하고, NaN 값을 처리하는 로직을 넣었습니다.

### 성과

- **정확한 추천**: 사용자 요청에 따라 높은 정확도로 음식점 추천을 제공. AI 모델의 통합을 통해 리뷰의 감성을 평가하고 이를 기반으로 한 추천이 이루어질 수 있었습니다.

- **자동화된 리뷰 크롤링**: 카카오 맵에서 리뷰 크롤링이 자동화되어 반복적인 작업을 줄이고, 더 많은 데이터를 안정적으로 수집할 수 있게 되었습니다.

- **유연한 구조**: FastAPI와 Spring Boot를 사용하여 백엔드 구조가 유연하고 관리하기 쉬운 형태로 설계되어, 새로운 기능 추가 및 유지 관리가 용이합니다.

이 프로젝트는 음식점 추천 시스템의 효율성을 높이며, 사용자가 보다 나은 선택을 할 수 있도록 도와주는 것을 목표로 하고 있습니다.
