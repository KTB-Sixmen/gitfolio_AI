## 프로젝트 개요

이 프로젝트는 머신러닝 모델을 서버에 배포하고 API를 통해 사용자에게 추천 서비스를 제공하는 웹 애플리케이션입니다. 주된 기능은 사용자 위치 기반으로 레스토랑 추천 및 리뷰 크롤링, 리뷰 데이터 처리 및 랭킹화, 사용자의 질문과 답변을 관리하는 Q&A 시스템입니다.

### 주요 기능
1. **레스토랑 추천 API**: 
   - 사용자의 위치와 키워드를 기반으로 인근의 레스토랑을 추천합니다.
   - BERT와 BiLSTM 모델을 사용하여 리뷰를 분석하고 점수를 매깁니다.
   - 추천된 레스토랑의 상세 정보와 함께 클러스터링된 리뷰 키워드를 제공합니다.

2. **리뷰 크롤링**:
   - KakaoMap API를 사용하여 특정 지역의 레스토랑 리뷰 데이터를 크롤링합니다.
   - 수집된 리뷰 데이터는 서버 측에서 전처리되고 분석됩니다.

3. **Q&A 시스템**:
   - 사용자가 질문을 등록하고 답변을 받을 수 있는 시스템입니다.
   - 관리자는 질문 목록을 조회하고 특정 질문에 대한 답변을 관리합니다.

4. **사용자 관리**:
   - 사용자 인증 및 권한 관리를 통해 일반 사용자와 관리자가 서로 다른 기능에 접근할 수 있도록 합니다.
   - 회원 가입, 로그인, 회원 탈퇴 기능이 포함됩니다.

### 기술 스택
- **백엔드**: Spring Boot, JPA, Java
- **프론트엔드**: React
- **데이터베이스**: MySQL
- **머신러닝**: TensorFlow, Hugging Face Transformers
- **API 통신**: Kakao API

### 문제 및 해결 방안
- **리뷰 데이터 크롤링 문제**: 일부 페이지에서 데이터 크롤링이 원활하지 않은 문제가 발생하였고, 이를 해결하기 위해 Selenium을 사용하여 브라우저를 자동화하고 데이터를 안정적으로 수집하였습니다.
- ** 모델 성능 개선**: 초기 모델의 성능이 낮아 데이터 레이블링 및 하이퍼파라미터 튜닝을 진행하여 정확도를 향상시켰습니다.
- ** 인증 및 보안 이슈**: JWT를 사용하여 사용자 인증을 시행하고, 보안 취약점을 방지하기 위한 다양한 조치를 취했습니다.

### 성과
- **추천 시스템의 정확도 및 사용자 만족도 증가**: 사용자 테스트 결과 추천 시스템이 실제로 유용하다는 피드백을 받았습니다.
- **확장 가능한 구조**: 코드의 모듈화 및 API 설계를 통해 향후 기능 확장이 용이한 구조를 갖추었습니다.
- **안정적인 배포**: CI/CD 파이프라인을 구축하여 코드 변경 사항을 자동으로 배포하고 테스트할 수 있게 하였습니다.

이 프로젝트는 머신러닝과 웹 애플리케이션의 통합을 통한 실질적인 사용자 가치를 제공하는 것을 목표로 하였으며, 성공적으로 여러 기능들을 운영하고 있습니다.
