Summary:
이 프로젝트는 카카오 API와 머신러닝 모델을 이용하여 음식점 추천 시스템을 구축하는 것이 주요 목표입니다. 사용자는 위치 정보와 검색 키워드를 입력하여 추천 음식점의 리스트와 평가를 받을 수 있습니다.

### 주요 기능
- **AI 통신 및 추천 시스템**: 사용자가 입력한 위치와 키워드에 따라 음식점 리뷰를 크롤링하고, 이를 기반으로 가게 추천 결과를 제공합니다.
- **데이터 수집 및 전처리**: 카카오 API를 통해 위치 정보를 주소로 변환하고, 관련된 음식점 리뷰 데이터를 크롤링하여 저장합니다.
- **리뷰 분석 및 모델 학습**: 수집된 리뷰 데이터를 이용하여 BERT 및 LSTM 모델을 사용한 감정 분석을 통해 각 음식점에 대한 평점을 매깁니다.
- **클러스터링 및 시각화**: 음식점 리뷰 데이터를 클러스터링하여 자주 나타나는 단어나 키워드를 시각적으로 분석합니다.
- **CI/CD**: Docker 및 CI/CD를 사용하여 코드 배포 및 환경 관리를 효율적으로 수행합니다.

### 기술 스택
- **프로그래밍 언어**: Python (FastAPI), Java (Spring Boot)
- **머신러닝/딥러닝**: Hugging Face Transformers, TensorFlow/Keras
- **크롤링**: Selenium, BeautifulSoup
- **데이터베이스**: JPA를 통한 관계형 데이터베이스 연동

### 문제 해결 및 개선 사항
- **크롤링 관련 문제**: 로딩 시간이 길어 오류가 발생했던 크롤링 부분을 개선하여, 리뷰 데이터를 안정적으로 수집할 수 있도록 최적화했습니다.
- **머신러닝 모델의 성능**: 여러 후보 모델을 학습시켜 정확도를 높이기 위해 앙상블 방법을 사용하여 최종 추천 결과의 신뢰도를 개선했습니다.

### 프로젝트 결과
- 최종적으로 음식점 추천 시스템이 구현되어, 사용자는 매우 직관적인 인터페이스를 통해 추천받은 음식점과 그에 대한 리뷰를 쉽게 확인할 수 있게 되었습니다. 이를 통해 사용자 경험이 크게 향상되었습니다.

이 프로젝트는 이론과 실제를 결합하여 실질적인 문제를 해결하는 좋은 사례로, 데이터 사이언스와 소프트웨어 개발의 교차점을 보여줍니다.
