Summary:
이 프로젝트는 카카오 머신러닝 모델 서빙 시스템으로, 사용자가 음식 레스토랑을 추천받고 관련 리뷰를 AI를 기반으로 처리하여 제공하는 웹 애플리케이션입니다. 다음은 프로젝트의 주요 포인트입니다:

### 주요 기능
1. **AI 추천 시스템**:
   - 사용자의 위치 기반 데이터와 키워드를 이용해 주변 음식점 추천.
   - 추천된 레스토랑에 대해 리뷰 데이터를 크롤링하고 분석함.
   - BERT 및 BiLSTM 모델을 사용하여 리뷰 점수 예측.

2. **리뷰 크롤링**:
   - 카카오 맵 API를 이용하여 음식점의 리뷰를 자동으로 수집하는 기능 구현.
   - 여러 페이지에 걸쳐 리뷰를 수집하여 사용자에게 다양한 데이터를 제공.

3. **RESTful API**:
   - FastAPI를 사용하여 API를 구현, 다양한 엔드포인트 제공 (예: 레스토랑 추천, 리뷰 분석 등).

4. **데이터 전처리 및 모델링**:
   - 수집된 리뷰 데이터를 전처리하고 모델링 하여 학습 및 예측 과정 제공.
   - 데이터 기반의 추천 시스템 구축 방법론이 포함됨.

5. **유저 관리 및 보안**:
   - 사용자 인증 및 권한 관리 기능 구현 (e.g., JWT 인증).
   - 관리자와 사용자 인터페이스를 구별하여 제공.

### 개발 환경 및 기술 스택
- **백엔드**: Python, FastAPI, TensorFlow
- **프론트엔드**: React.js
- **데이터베이스**: MySQL
- **기타 툴**: Docker, Git, Jupyter Notebook (데이터 분석 및 시각화를 위한)

### encountered Issues and Resolutions
- **버그**: 웹 크롤링 시 로딩 시간 문제로 인해 리뷰 데이터 누락 발생.
  - **해결 방법**: 크롤링 로직을 최적화하고, '더보기' 버튼 클릭 시간 조정으로 해결.
  
- **모델 성능향상**: 초기 모델의 정확도가 낮아, 데이터 양을 늘리고 모델 하이퍼파라미터를 조정.
  - **해결 방법**: 다양한 머신러닝 기법을 적용하여 성능을 향상시킴.

### 성과
- 사용자로부터 긍정적인 피드백을 받으며, 음식점 추천과 리뷰 분석 기능을 통해 유용성을 인정받음.
- 모델의 성능 향상 및 데이터 수집 자동화를 통해 운영 효율성을 높임.

이 프로젝트는 머신러닝과 데이터 크롤링을 통해 사용자 맞춤형 추천 시스템을 구현하는 좋은 예시로, 향후 서비스 고도화 및 추가 기능 개발을 위한 기반이 될 것입니다.
