Summary:
프로젝트 개요:
이 프로젝트는 머신러닝 모델을 기반으로 음식점 추천 및 리뷰 분석 서비스입니다. 사용자는 음식점 리스트를 검색하고, AI 모델을 통해 추천 및 리뷰 분석 결과를 확인할 수 있습니다. 이 시스템은 두 가지 머신러닝 모델을 활용하여 감성 분석과 클러스터링을 수행합니다. 주로 Python과 Java를 사용하여 백엔드와 API를 구축하며, Docker를 통해 컨테이너화하여 배포할 수 있습니다.

주요 기능:
1. **음식점 추천**:
   - 사용자로부터 입력된 위치와 키워드를 기반으로 음식점을 추천합니다.
   - 카카오 API를 사용하여 좌표를 주소로 변환하고, 음식점 정보를 크롤링합니다.

2. **리뷰 크롤링**:
   - Selenium과 BeautifulSoup를 활용하여 카카오 맵에서 음식점 리뷰를 자동으로 수집합니다.
   - 리뷰 데이터를 클리닝하고 전처리하여 유용한 정보를 추출합니다.

3. **감성 분석**:
   - KcELECTRA 모델과 BiLSTM 모델을 사용하여 리뷰의 감성을 분석합니다.
   - 각 리뷰에 대한 긍정적/부정적 점수를 평가하고, 리뷰를 랭킹합니다.

4. **데이터 클러스터링**:
   - HDBSCAN을 사용하여 수집된 리뷰를 클러스터링하고, 클러스터별로 자주 언급되는 키워드를 추출합니다.

5. **사용자 인터페이스**:
   - React를 사용하여 사용자 인터페이스를 구축하고, RESTful API를 통해 백엔드와 통신합니다.

문제 및 해결:
- **크롤링 오류**: 로딩 시간이 길어지면서 크롤링 에러가 발생했던 문제를 해결하기 위해 Selenium의 WebDriverWait을 사용하여 요소가 클릭 가능해지기까지 대기하도록 개선하였습니다.
- **모델 정확도**: 초기 모델이 낮은 정확도를 보였으나, 데이터를 재전처리하고 가중치를 조절하여 성능을 개선했습니다.
- **API 통신의 안정성 문제**: API 호출 시 오류가 발생하는 경우를 대비해 예외 처리를 추가하고, 실패 시 재시도하는 로직을 구현했습니다.

결과:
- 개발한 시스템은 사용자에게 정확하고 유용한 음식점 추천과 리뷰 분석 결과를 제공하며, 머신러닝 모델을 통한 높은 정확도의 감성 분석을 이루어냈습니다.
- 이미지를 포함한 리뷰 데이터를 처리하여 다양한 정보와 키워드를 사용자에게 제공하고, 데이터 시각화를 통해 인사이트를 얻을 수 있도록 하였습니다.

향후 계획:
- 서비스의 사용자 피드백을 반영하여 모델 성능을 더욱 개선하고, 다양한 데이터원에서 정보 모음을 확장할 예정입니다.
- 연속적인 학습과 최신 모델 적용을 통해 추천 정확도를 높이는 방향으로 나아갑니다.
