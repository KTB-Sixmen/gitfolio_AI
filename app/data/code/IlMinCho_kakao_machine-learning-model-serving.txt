Summary:
이 프로젝트는 카카오 맵에 있는 음식점의 리뷰 데이터를 수집하고, AI 모델을 사용하여 해당 리뷰의 감정을 분석하여 음식점을 추천하는 시스템입니다. 아래는 프로젝트의 주요 특징과 내용 요약입니다.

### 프로젝트 개요
- **목적**: 사용자에게 근처 음식점을 추천하고, 리뷰의 감정을 분석하여 음식점 랭킹을 매기는 시스템 구축.
- **기술 스택**:
  - Python, FastAPI: 서버 및 API 구현
  - Java, Spring Boot: 웹 애플리케이션 서버 구성.
  - 머신러닝 모델: KcELECTRA 및 BiLSTM 모델을 사용하여 리뷰 감정 분석.
  - Selenium, BeautifulSoup: 웹 크롤링을 통해 리뷰 데이터 수집.

### 주요 기능
1. **리뷰 수집**:
   - 사용자가 입력한 위치 기반으로 음식점의 리뷰를 크롤링하여 데이터베이스에 저장.
   - Selenium을 사용하여 카카오 맵에서 리뷰 정보 자동 수집.
   
2. **데이터 전처리**:
   - 크롤링된 리뷰 데이터에서 불필요한 부분 제거.
   - 리뷰를 정제하고 형태소 분석을 수행하여 자연어 처리에 적합한 형식으로 변환.

3. **감정 분석**:
   - KcELECTRA 모델과 BiLSTM 모델을 사용하여 리뷰의 긍정, 중립, 부정을 분류.
   - 앙상블 기법을 사용하여 두 모델의 성능을 결합하여 최종 점수 계산.

4. **추천 시스템**:
   - 리뷰의 감정 점수 및 키워드 언급 횟수를 기반으로 음식점의 랭킹을 결정.
   - 상위 5개 및 하위 5개의 리뷰를 클러스터링하여 자주 언급되는 키워드 추출.

5. **웹 인터페이스**:
   - 사용자에게 추천 음식점 및 그에 대한 정보를 제공하는 웹 UI 구성.

### 이슈 및 해결
- **모델 성능**: 초기 모델이 정확도가 낮았으나, 데이터 전처리 및 튜닝을 통해 성능 개선.
- **크롤링 오류**: 리뷰 크롤링 시 네트워크 지연 및 웹페이지 구조 변경으로 인해 발생하던 오류를 처리하기 위해 예외 처리를 추가하여 안정성을 확보.
- **API 연동**: 카카오 API를 활용하여 주소를 좌표 변환 처리하는 로직에서 오류 발생 시 적절한 예외 처리를 통해 사용자에게 피드백 제공.

### 최종 성과
- 사용자와 음식점 간의 상호작용을 개선하여, 음식점 추천의 정확성을 높이고, 사용자의 리뷰 경험을 향상시키는 시스템 구현.
- AI 모델을 통해 리뷰 분석의 성과를 내며, 유의미한 데이터 결과 제공.

이번 프로젝트를 통해 데이터 수집, 머신러닝 모델링, API 연동 등 다양한 기술적인 도전에 성공적으로 대응하였으며, 실질적인 음식점추천 시스템을 구현하였습니다.
