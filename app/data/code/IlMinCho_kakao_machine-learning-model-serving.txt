Summary:
이 프로젝트는 Kakao 기술을 기반으로 한 머신러닝 모델 서빙 시스템으로, 주로 레스토랑 리뷰 데이터를 처리하고 추천 기능을 제공하는 API를 개발하는 것을 목표로 하고 있습니다. 다음은 프로젝트의 주요 요점입니다:

### 주요 기능
1. **리뷰 데이터 크롤링**: 카카오 맵에서 특정 지역의 음식점 리뷰를 자동으로 크롤링하여 수집합니다.
2. **AI 기반 추천 시스템**: 수집된 리뷰 데이터를 이용해 사용자에게 레스토랑을 추천하는 API를 제공합니다. 
3. **데이터 전처리**: 비정형 데이터인 리뷰에 대해 텍스트 전처리를 수행하여 리뷰의 감정을 예측합니다.
4. **감정 분석 모델**: KcELECTRA 및 BiLSTM 모델을 사용하여 긍정적, 부정적, 중립적 리뷰를 분류합니다.
5. **리뷰 시각화**: 수집된 데이터를 기반으로 관리자가 리뷰를 시각화하여 관리할 수 있는 UI를 제공합니다.
6. **사용자 인증 및 권한 관리**: Spring Security를 이용해 사용자 인증 및 권한 관리 기능을 구현하였습니다.

### 기술 스택
- **Backend**: FastAPI (Python), Spring Boot (Java)
- **Database**: JPA(Hibernate) - MariaDB
- **Frontend**: React.js
- **DevOps**: Docker, GitHub Actions
- **Machine Learning**: Tensorflow/Keras

### 문제 및 해결
- **크롤링 오류**: 초기 크롤링 시 페이지 로딩 문제와 동적 페이지 요소 문제로 인해 일부 리뷰 데이터를 크롤링하는 데 오류가 발생했습니다. 이 문제는 Selenium을 사용하여 해결했습니다.
- **모델 성능 개선**: 초기 모델이 만족스러운 성능을 보이지 않아 데이터 전처리 및 토큰화 과정을 추가하여 성능을 개선했습니다.
- **UI/UX 문제**: 사용자 피드백을 반영하여 UI/UX를 개선하여 더 직관적이고 사용하기 쉬운 인터페이스를 제공했습니다.

### 결과
- 프로젝트의 성공적인 배포로 레스토랑 추천 시스템이 실제로 사용자에게 활용되었고, 리뷰 데이터를 통해 사용자 경험이 개선되었습니다.
- 관리자들이 데이터에 대한 통찰을 보다 쉽게 얻을 수 있게 되어 운영 효율성 또한 향상되었습니다.

이 프로젝트는 데이터 수집, 처리, 사용자 인터페이스 및 머신러닝 모델 관리 전반에 걸쳐 통합적으로 작동하여, 결국 사용자에게 보다 나은 서비스를 제공하는 것을 목표로 하고 있습니다.
