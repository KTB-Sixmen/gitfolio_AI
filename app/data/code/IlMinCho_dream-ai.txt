Summary:
### 프로젝트 개요
이 프로젝트는 생성형 AI(LLM, RAG, Diffusion Model)를 활용하여 노년층이 이루지 못한 꿈에 관한 이야기와 이미지를 생성하는 서비스를 제공합니다. 이를 통해 사용자는 '꿈을 이룬 나'라는 주제로 관련된 교육 프로그램 및 직업을 추천받을 수 있습니다.

### 주요 기능
1. **스토리 생성**:
   - 사용자가 입력한 직업과 문구를 기반으로 Elasticsearch에서 관련된 문서를 검색합니다.
   - LLM을 이용해 직업과 상황에 맞는 스토리를 생성합니다.
   - 초기, 중기, 후기, 마무리 단계에서 각각 다른 프롬프트를 통해 점층적으로 이야기를 발전시킵니다.

2. **이미지 생성**:
   - OpenAI의 DALL-E API를 사용하여 스토리와 관련된 이미지를 생성합니다.

3. **서버 아키텍처**:
   - FastAPI를 사용하여 RESTful API를 구축하고, Elasticsearch를 통해 벡터 검색 기능을 구현합니다.
   - Sentence-BERT 모델을 사용하여 직업 정보를 벡터화하고, 이를 기반으로 유사한 문서들을 색인하고 검색합니다.

### 데이터 흐름
- 사용자는 직업 및 관련 텍스트를 입력하여 스토리 혹은 이미지를 요청합니다.
- 시스템은 입력된 데이터를 처리하여 관련 정보를 Elasticsearch에서 조회하고 LLM을 통해 창작 과정을 거칩니다.
- 생성된 이야기는 최종적으로 사용자에게 반환됩니다.

### 팀원 및 역할
다양한 팀원이 프로젝트에 참여했으며 각자 GitHub 링크를 통해 역할을 공유하고 있습니다.

### 개발 중 문제 및 해결
- **문제**: API 연동 중 엑세스 키 문제 및 에러 처리 과정에서 예상치 못한 HTTP 500 오류가 발생하였습니다.
- **해결**: 예외 처리를 강화하여 오류 발생 시 적절한 메시지를 반환하도록 개선하였으며, 환경변수 관리에 꼼꼼하게 접근하였습니다.

### 결과 및 성과
- 프로젝트는 최종적으로 사용자가 자신의 꿈을 실현하기 위한 교육과 직업 추천을 받을 수 있는 유용한 플랫폼으로 자리매김하였습니다.
- 사용자 피드백을 통해 지속적으로 기능을 개선하고 있으며, 생성된 스토리와 이미지의 품질 또한 지속적으로 높아지고 있습니다.
