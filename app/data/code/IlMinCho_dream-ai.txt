Summary:
이 코드는 FastAPI를 사용하여 AI 스토리 생성 및 이미지 생성 웹 애플리케이션을 구현하는 예제입니다. 주요 기능은 다음과 같습니다:

1. **FastAPI 인스턴스 생성**: FastAPI를 사용하여 웹 서버를 설정합니다.

2. **Elasticsearch와 OpenAI 연결 설정**: Elasticsearch와 OpenAI API를 연결합니다.

3. **Pydantic 모델 정의**:
   - `StoryRequest`와 `StoryResponse`: 스토리 생성 요청 및 응답 데이터 구조를 정의합니다.
   - `ImageRequest`: 이미지 생성 요청을 위한 데이터 구조를 정의합니다.

4. **프롬프트 생성 함수**: 직업, 나이, 성별 등을 기반으로 이야기를 생성하기 위한 프롬프트를 만듭니다.

5. **스토리 생성 엔드포인트**: `/ai/story` 엔드포인트에서 직업에 맞는 다큐먼트를 Elasticsearch에서 검색한 후, OpenAI API를 사용하여 스토리를 생성합니다. 에러가 발생하면 HTTP 500 예외를 발생시킵니다.

6. **이미지 생성 엔드포인트**: `/api/image` 엔드포인트에서 OpenAI DALL-E API를 통해 이미지 생성을 수행합니다.

7. **인덱스 생성 및 설정**: Elasticsearch에 사용하는 인덱스를 생성하고 매핑을 설정합니다.

8. **문서 검색 함수**: 주어진 직업에 따라 Elasticsearch에서 유사한 문서를 검색하는 함수를 구현합니다.

9. **버전별 스토리 생성**: 각각의 이야기 단계를 처리하며, 각 단계는 사용자가 입력한 내용을 기반으로 생성된 텍스트를 이어 붙여 진화하는 이야기 체계를 구현합니다.

코드는 주로 스토리 생성과 이미지 생성을 통합하여 인터랙티브한 AI 서비스를 제공하는 데 중점을 두고 있습니다.
